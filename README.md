## 开始使用

1. 首页导入 Excel 成绩表、小题表、CSV 或完整 JSON 备份。首次加入工作区；已有材料可合并或替换。通用表格可手动对应列，替换前保留一次可撤回快照。
2. 从六个入口研究。各入口独立保留班级、考次、筛选与排序；观察窗支持连续查看学生、学科、知识点与单题。
3. 用星标保存研究范围与阅读位置，用摘录保存当时的结果，并在证据报告里记录教师判断。
4. 教学跟进 → 个性化辅导，直接搜索全年级学生，选择学科、考试依据、知识点、训练重点、范围和补充要求，再生成练习。
5. 资料与报告 → 试题中心，查看任务与已保存练习。核对全部题干、答案、解析、评分和图示，确认审题后导出学生/教师版 PDF 或 Word，也可加入教学跟进。
6. 定期下载完整 JSON 备份。换设备、浏览器、域名或清理网站数据前，先备份，再在新环境导入。

## 原表与统计口径

通用 Excel/CSV 自动识别“原分市排名、赋分校排名”等明确范围表头。同一范围多列并存时，默认赋分排名优先，其次通用排名、再次原分排名；映射页显示来源并允许调整。空白保持缺失，不逐行拼用另一列；原表固定格式的列位读取不变。未知文件有格式提示，混合导入会列出跳过的文件。

- 缺失保留缺失，真实0参与统计。满分、完整作答或有效线不足时，不补造得分率、失分和达线结论。
- 原分、赋分、班排、校排和市排分别保留。**校排名是原表提供的校内名次**，不会用班排名次冒充，也不会从不完整导入范围重算。明确的年级/校内排名列按对应口径读取。
- 按实际选定考次分析。分数与相对位置越高通常越好，名次越小越靠前；市校统计范围、科类或班级口径不同，不直接相减制造变化。
- 17班归物理类，18班归历史类，补习仅作备注。外语投影用于同科类分析，英语、日语原始成绩和试卷仍保留。
- 合并按学生身份、考次、班级和学科关联；空白保留已有值、0更新，小题按题号对应。成绩变化会使未同步提供的对应排名失效。
- 未提供知识点不凭得分臆测标签，需结合原题补充；跨考同题号不自动视为同一道题。

## 个性化辅导

支持语文、数学、英语、日语、物理、历史、化学、生物、政治、地理，实际可选科目跟随学生已有材料。各科分别组织知识点、范围、训练重点、题型和补充要求，既可选也可补充；3–12题、5–90分钟使用滑轮，难度分五档。单次考试、多考共性和教师自定依据均可选择，多考只依据明确知识点及真实失分分析，不编造错因。

设置可自动保存草稿、命名为教学模板、从历史练习沿用。不同学生和学科草稿独立，批量准备时逐生保留实际考试依据。云端学科提示词约束四川高考课程范围与题型，允许原创情境和陌生材料，不局限教材原题，禁止大学、竞赛知识成为必备条件。结构、完整性和质量检查不能替代教师学科审定。

公式文档要求一次输出合法JSON，化学公式逐字段检查转义；实验数据表按统一表格格式直接排版。失败任务显示受控的具体格式原因，可修复的格式错误先修原稿，其他内容失败只重做未完成题组。见[化学练习失败排查](docs/GENERATION-FORMAT-2026-10-19.md)。

题文模型先给出图示要求、已知条件和插入位置，图示模型独立规划受约束的 SVG 或复杂插图。支持常见坐标、几何、力学、电路、装置、分子、晶胞、细胞、遗传与地理图表等。浏览器统一绘制，不执行模型输出的任意脚本或 HTML。图示保留锚点和宽度比例，可拖动调整；必要图未完成或题图修改后必须重新核对。图示库用于了解覆盖范围，不能保证每次模型输出都正确。

试题中心支持检索、班级/学科/状态筛选、排序、删除与撤销。已接收任务在云端执行，关闭网页不取消；重连先查询原任务，不静默重复付费请求。显示真实状态、用时、估时和上游提供的流式思考/正文，上游未提供的内容不会编造。未完成的题组或图示有明确的继续/重试操作。

审题确认与文档版本绑定，修改题文/图示会撤销确认，下载再次核对版本。作答处保留适当留白，公式和图示沿用统一预览/导出规则。练后得分、薄弱点和再测可同步关联跟进，保留教师备注及计划状态。

## 模型工作台与数据边界

使用认证器的六位 TOTP 验证教师访问，网页不输入服务地址，也不保存上游 API Key。工作台可独立切换出题/图示/校检模型、思考档位、连接测试、历史选择、每日次数滑轮设置/清零及任务诊断。次数设为0表示不设应用层每日额度，上游套餐、速率、输出预算及云函数时限仍受实际服务约束。

模型目录包含已授权的北辰服务及 Kimi、Gemini、Grok 等适配，目录存在不代表所有型号有余额或均已实测。点击应用仅影响新任务，已有任务冻结原服务与模型，不自动跨提供方回退。Kimi Code 沿用维护者已确认的个人交互用途，使用方式变化应重新核实提供方规则。

正式前端复用已运行的专属腾讯云训练服务，资源名仍为 `-dev`，与北辰运行资源隔离。正式/预览共享训练服务的教师身份、云端配置及额度，**本机材料、草稿和练习目录继续隔离**。由预览迁移到正式：在预览下载完整 JSON 备份，再到正式导入，已有正式资料时先备份并明确合并/替换；不会自动覆盖。

浏览器本地保存成绩、身份、判断、计划、练习和预计算缓存。云端仅接收匿名训练依据及任务参数，不发送学生姓名、班级、身份证、排名和完整成绩。云端任务对象保留14天，模型控制数据独立保存；本机完整备份不包含教师会话和密钥。清理任务不等于撤销已发生的上游调用。

首页关键样式和轻量字体随入口显示，研究模块、完整字体、公式与报表引擎按需加载。导入、合并和索引在 Worker 执行，已处理材料、页面、公式和输出文件可复用；保留透明玻璃、切换与控件动画。阅读设置支持纸面、密度和减少动态偏好，低得分率用深色强调，手机宽表保留字段并横向阅读。

[首页与导入测量](docs/ENTRY-PERFORMANCE-2026-10-16.md)是资源量和本机测量，不是国内所有网络时延保证。当前没有新部署国内镜像；第三方静态镜像不能保证模块、缓存和可用性，不同域名也会隔离本机数据。

## 开发与检查

使用 Node.js 22.9 或更新版本及 npm。锁文件包含固定的 esbuild 与跨平台依赖；标准 `npm ci` 可直接安装，无需外部构建目录。

```sh
npm ci
npm test
npm run build
python3 -m http.server 4175 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4175/`。前端为原生 ES Modules + 静态资源，Node 用于构建/测试，不需常驻前端应用服务器。`npm test` 覆盖数据、导入、排名、训练、存储、模型适配与云端任务。`tests/*.cjs` 另保留需静态服务器和浏览器的专项流程。

浏览器冒烟流程使用当前的12步操作：空首页 → 冲突来源确认后导入 → 六场景 → 学科/学生返回 → 刷新恢复抽屉与研究夹 → 知识点和未知满分 → 报告设置与摘录恢复 → Excel/Word实际下载 → 学生目录 → 完整备份 → 手机布局 → 正常动画及资源检查。保持上面的静态服务器运行，在另一终端执行：

```sh
npx playwright install chromium
AUDIT_URL=http://127.0.0.1:4175 npm run test:smoke
```

也可设置 `CHROMIUM_PATH` 使用本机 Chromium 系浏览器。每次运行使用独立临时浏览器上下文与匿名材料，不调用出题服务；结果、失败截图和下载文件保存在 `.audit-output/`。该冒烟流程已加入 CI 的 `browser-smoke` 作业，首次失败即停止，避免前一步失败后产生无关的连锁报错；其他专项脚本仍单独运行。

修改源码后重建并提交源码、入口 HTML、运行清单和新哈希资源。构建先完成全部编译和入口校验，再写入资源；保留当前资源、最近3次成功发布及7天内已登记发布的完整 JS、Worker 与哈希 CSS 依赖，漏登记时额外保留上代依赖，清理前校验整个保留图；不手工改内容哈希文件。独立页面的共享样式同样使用内容哈希。`npm run runtime:check` 预览清理，发布登记见[资源维护说明](docs/IMPORT-AND-BUILD-MAINTENANCE-2026-10-18.md)。`npm run package:training` 仅同步前后端契约，不部署云函数；后端修改按[部署手册](docs/DEPLOYMENT.md)单独执行。

| 路径 | 职责 |
| --- | --- |
| `index.html`、`app/launch.js` | 首页、加载、恢复入口 |
| `app/data/`、`app/engine/` | 导入存储、身份排名映射、查询、训练契约与状态 |
| `app/scenes/`、`app/ui/` | 六场景、观察窗、报告和辅导界面 |
| `app/io/` | Excel、PDF、Word、公式与图示输出 |
| `app/runtime/`、`assets/`、`styles/`、`vendor/` | 构建资源、字体、视觉与本地依赖 |
| `backend/` | HTTP、异步任务、提示词、模型图示、认证与额度 |
| `tools/`、`tests/`、`docs/` | 构建部署、回归及完整维护记录 |
