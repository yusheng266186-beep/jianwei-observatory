总分分布中的本科线使用蓝色虚线，特控线使用深蓝实线，标签连接到真实分数位置并显示当前范围的达线人数。分线位于柱子上层，人数文字单独置顶，浅色区间帮助阅读；手机保留清楚的线宽与字号，图外的有效线明确说明。详见 [分数线与分布图](docs/THRESHOLD-GUIDES.md)，运行 `npm run test:thresholds` 可复核。

字体按阅读任务组织：思源宋体半粗字重用于页面主标题与重点标题；思源黑体的正常、适中字重用于正文、章节、姓名与操作；IBM Plex Sans 用于成绩、排名、人数及图表数字。通过真实字重、大小与间距形成层级。中文字体自托管，加载不阻塞操作，图表下载内嵌实际字体。详见 [字体与阅读层级](docs/TYPOGRAPHY.md)，可运行 `npm run test:typography` 复核。

## 六个研究入口

| 入口 | 起点 | 工作方式 |
| --- | --- | --- |
| 年级总览 | 四张重要表与一场考试 | 四表入口、临界与阶段线索、可点击班级条形、材料覆盖与考次增量；有效账、学科横向、学生清册各自展开 |
| 班级研究 | 一个班 | 横向实体选班；本场成绩、历次对照、有效与任务；学科卡片、分布及双上线人数可进入具体名单 |
| 试卷研究 | 按考次浏览的一张卷 | 卷面卡片/归档清单；完整小题地图；单题抽屉含各班得分、全体作答、上下题与独立导出；知识点和作答矩阵 |
| 学生研究 | 可组合筛选的学生目录 | 班级按键、研究线索与学科条件直接呈现；双上线/学科短板筛选；卡片/列组表格/分布图；个人阶段轴、抽屉、收藏与2–4人比较 |
| 教学跟进 | 临界对象与已保存行动 | 看板/名单切换，独立按班级、状态、姓名和教学记录检索；下方临界对象发现不影响已有跟进 |
| 资料与报告 | 教学材料与保存的判断 | 六个实体入口分别处理导入与备份、班级任务、有效线、题目资料、考试口径与证据报告 |

各分析使用自己的班级与考次范围，不设置共同的班级、科类、届别筛选。班级使用实体按键，考次使用时间轴，试卷使用卷架，学生通过组合筛选、检索和抽屉预览进入。界面不使用下拉菜单。

**17班并入物理类，18班并入历史类。** 补习仅保留为班级备注，汇总、同科类基准、同类分位和历次分析均包含对应科类的补习班。

## 界面与操作

浅蓝背景、深蓝文字与蓝白玻璃；低分、负向变化使用灰蓝，数值符号和文字保留完整含义。`styles.css` 管理布局，`styles/journey.css` 管理连续研究控件，`styles/glass.css` 统一透明材质、图表样式与响应式视觉。悬浮顶栏、浅色玻璃 Dock 和侧边抽屉形成不同层次，文字与数字不应用模糊。未导入时只有文件入口与玻璃纸张造型，不画虚构成绩。导入后首页按“本场概况—四表研究路径—学生线索—班级与阶段明细”展开，不把所有内容堆在相同方框里。

同一个研究对象内使用稳定 DOM 更新，保留输入焦点、展开的明细、滚动与表格横向位置。Dock 和页内标签的选中底板连续移动，鼠标邻近时有轻微抬升；卡片光泽随鼠标位置变化。跨板块时整个内容区横向退出与进入，页头和 Dock 保持稳定；快速改向从当前帧继续，切换中导航与新页控件保持可用；卡片排列、名单调整和图表数值变化连续衔接，悬停反馈与排列位移独立。侧边抽屉从当前画面进入或退出，页面背景只应用一层模糊。新对象等待加载时明确提示并保护旧页条件，浏览器返回恢复阅读位置。系统减少动态效果偏好覆盖全部动画，触屏不执行鼠标光泽与 Dock 邻近效果。

有多个章节的页面自动提供本页研究导航，点击跳到对应证据，当前章节随阅读位置更新；完整阶段原表可从导航直接展开。导航保留阅读进度与回到页首入口。班级本场页提供学科相对位置与临界学生的研究起点；没有本科有效线时先提供补充入口，不用0人制造临界结论。小题地图、热力矩阵和个人卡片显示得分率颜色说明；缺少明确满分或作答时标明无法计算。图表标签随容器调整字号，长标签保留完整提示；阅读口径折叠保存，减少重复说明。

学生目录支持每人最新成绩或指定考次，不强制把没有该考次的学生替换为别的成绩。生效条件显示在结果上方，能逐个撤销；高级条件在独立抽屉组合。表格有概要、各科成绩、原分排名和全部字段四组列，完整列保留各科学科线、距线和排名。筛选结果明确显示总人数、页码和范围；24/48/96人分页，导出包含全部结果与筛选条件。学生变化使用相邻同科类记录的分位变化，提升/下降以3个分位点为界。卡片、表格与可点击散点图使用相同结果集，补习班不单独分类。

从年级、班级、试卷或跟进名单点击学生，先打开侧边观察窗，保留原页面的筛选、滚动和表格位置。观察窗展示全部阶段、当次学科与小题入口。收藏、2–4人并排对比、共同考次、完整轨迹和对比摘录各自保留。抽屉内从试题进入学生后，可以返回原单题研究。完整个人档案使用横向考次轴与阶段/学科/小题直达按钮，提供小题得分卡片、原始明细、知识点结构及可展开的完整阶段原表。

班级学科提供证据卡片与完整表格，点击学科进入年级横向研究。试卷提供逐题地图、知识点路径及图表、班级小题热力矩阵、全部逐题指标、学生作答矩阵、单题全体作答。题目观察窗直接包含可搜索、分页的全体作答，导出保留当前范围的全部学生；班级热力格子打开该班的题目观察。班级双上线分解显示总分与学科四种组合，可点击人数进入准确名单。跟进发现名单改为完整分页，不再只显示前100人。

## 连续研究与阅读细节

持续打磨的目标是“迅速看清线索，少量操作追到证据，写下判断后回到原处继续”，取舍原则和本轮记录见 [docs/PRODUCT_GOAL.md](docs/PRODUCT_GOAL.md)。

顶栏研究夹保存当前场景的独立条件、阅读位置与抽屉上下文，可命名、检索、重开和删除；最近足迹保留24条。页面的星标与抽屉的“留在研究夹”都可直接保存。跨场景跳转提供返回入口，恢复之前的范围；材料中已不存在的对象或考次会提示补齐，不换成另一组数据。完整 JSON 备份包括研究夹与足迹。

研究夹重开时根据当前材料呈现，证据摘录保存当时的结果。摘录增加研究来源、材料时间、判断保存状态和继续研究入口。导出预览写下判断后自动留存，关闭、Esc、快捷查找和回到研究都会先保存；从摘录编辑后关闭，资料卡片同步呈现新判断。重开同一份未改变的预览会继续已有判断；空白预览不自动新增摘录。显式摘录可以建立新的证据快照。Excel、Word、打印/PDF 保留来源，全部摘录的 Excel 包含每份教师判断及时间。

学生抽屉分为阶段与线索、学科成绩、逐题得分。上一位/下一位沿当前筛选结果、班级、试卷或跟进名单前进；单题研究进入学生后，可返回原题。非输入框与表格区域支持左右方向键切换学生或小题。打开完整档案再回到目录，会恢复目录的位置与筛选。

个人小题的卡片、明细题号和知识点题目均可展开本班同题作答，聚焦当前学生；可继续扩大到全部参考班，并逐层返回。抽屉返回保留表格横向位置。并排比较的当前切面沿用进入时的考次，全部阶段轨迹继续独立保留。目录、观察窗与报告翻页将阅读位置移到新名单入口。

手机目录将当前班级与科类范围收为可展开面板，学科条件进入“细化筛选”；导出全部结果仍可直接操作。生效条件可逐项移除，分数上下界颠倒会明确提示并提供修改入口。完成筛选可直接查看结果。通知移到顶栏下方并可关闭，消息背景不拦截页面点击。

常用筛选可自行命名、保存、再次打开和删除，保存在当前浏览器，并进入完整工作区备份。保存的是条件，下一次打开会根据当前材料重新查找。指定考次尚未导入时会提示，不擅自换成另一场成绩。学生检索支持逗号分隔的多个姓名；中文输入法完成输入后再刷新结果。

宽表格保留第一列与表头，显示当前表格的行列数、横向提示、左右滚动按键与滚动进度。只读表格可展开为宽幅阅读窗，保留当前表格的行列和学生入口。分页目录的阅读窗展示当前页，完整结果继续通过翻页与导出取得。表格中的可编辑字段直接在原页面维护。

报告材料可按内容切换、检索和每页50行完整阅读，不再停留在5行预览。预览检索不改变 Excel、Word、PDF 的完整导出范围。误删跟进、常用筛选或证据摘录后，通知提供9秒撤销入口；材料替换与清空提供独立的撤回入口。

顶栏“阅读设置”可选择舒展/紧凑、通透/纸面与自然过渡/静读。设置保存在当前浏览器，不改变统计口径。图表和热力格子提供悬停与键盘提示，明细展开/收起使用高度过渡，下方内容进入视野时轻柔呈现。手机保留触控范围和底部安全间距。

## 从图表追到具体证据

班级学科图表、剖面卡片和有效表可直接打开本班学科观察窗，分别研究具体学生、历次参照和相关小题。总分与学科达线关系可切换本科/特控口径，按双上线、单侧达线、双未上线、学科临界、缺成绩或口径不全定位名单。概况以本班本场全部记录为范围，条件只筛选名单，不改变同类基准。缺少可判定的双线记录时，双上线显示未知。

知识点条形和标题可打开知识点观察窗，继续看关联题目、各班完整作答和逐人明细。个人完整得分率要求关联题得分与明确满分均齐全；材料不齐保留已填得分，完整得分率与失分留空。班级知识点比较只使用完整可比作答，明确展示可比与材料不全的份数。

学生作答矩阵中的得分格子可以打开该生这道题的观察卡，再进入同题与学生研究。单题名单支持全部、零分、未得满分、满分、未填得分；缺少明确满分时相关条件不可用。单题班级条形直接展开该班这道题的名单，保留原范围作为返回路径。

观察窗顶部显示可返回的证据路径，研究夹也可留存学科、知识点及多层抽屉上下文。学生上一位/下一位沿刚才的实际筛选名单继续，摘录和导出保留对应的完整筛选结果与范围说明。

## 四张重要表

- 班级有效人：有效账与班级有效及任务，含人数任务、增量、统一外语有效、学科有效、双上线、10/20分临界带。
- 个人学科小题得分：试卷全体作答矩阵、单题抽屉与个人小题，保留题号、分值、知识点、得分率和逐题原始分数。
- 班级多次考试对比：时间轴多选考次、共同参考口径、指标趋势、逐人矩阵、分位/排名/分差/学科对照。
- 班级成绩分析单次：原分、赋分、原排名、总分及学科距线、化学+生物本科分差、同科类比较、成绩分布。

资料仓可导出四表分析包，并附学科有效和题目目录。各研究页面能直接导出 Excel、Word，或打印保存 PDF；SVG 图表可导出 SVG/PNG。摘录保存当时的范围与结果，教师判断与研究证据一起保留。

## 导入与保存

支持标准复盘 Excel、单独小题表、CSV、JSON 工作区备份以及原质量分析项目的 GradeDataset JSON。通用表格使用可展开的列对应面板，逐列点选，没有下拉菜单。

文件由独立 Worker 读取。空白工作区首次导入只需点击“加入工作区”；已有材料时可选择合并材料或替换工作区。追加考次和小题按姓名联结；替换前保留一次可撤回的材料快照。先导入真实姓名的成绩原表，再补充小题。

合并时空白保留已有成绩，实际0更新；小题按题号对应，换序不会把旧分数挂到另一道题。主动删除旧数据使用替换。材料、撤回快照和摘录一起保存；保存失败会提示下载完整备份。教师判断输入时保留本机草稿，刷新后恢复尚未完成数据库保存的文字与新摘录。

材料与证据摘录保存在本浏览器 IndexedDB，模块偏好、跟进记录、收藏及对比选择保存在 localStorage。新版本首次打开会迁移同源的旧见微本机材料与跟进记录。完整 JSON 备份包含收藏、对比选择与常用筛选，可以迁移到其他计算机。阅读偏好独立保存在本浏览器。真实工作簿、姓名、身份证与凭据不上传 GitHub。

未导入材料时，六个研究入口统一显示空白工作区与导入说明，不展示具体成绩、学生、班级、考试、跟进或统计数字，也不自动读取匿名样本。旧版本缓存的默认匿名样本不再自动恢复；已导入的本机材料仍会恢复。显式导入的材料带有 `userImported` 标记，匿名化的用户备份也可正常保存和恢复。清空工作区后回到导入引导。

## 统计口径

每名学生按当场考试、自己所属科类的有效线判断，不平均两类有效线。缺失不补0，0分有效，缺失总分保持空白。学科原分与赋分分开保存，原排名保留当次统计范围。

双上线要求同一人的总分和该学科同时达线。共同参考使用所选考次的学生交集。个人档案按学生身份查询全部阶段，班级矩阵按当次实际班级查询。英语与日语在成绩比较中合并为“外语”，直接使用表内折合成绩，不再次折算；同类基准、均分、有效线、双上线、阶段变化和导出均使用这一口径。统一外语线优先使用手工设置的外语线，旧材料采用英语线，英语线缺失时采用日语线。原始语种、个人原分与各自题库完整保留，原分不用于外语综合均分比较。地理与生物保留各自学科；混合选科按每名学生实际记录展开。

小题得分率仅采用明确的题目满分。含星号等不明确分值保持为空。区分度使用原始小题合计的高低分组均分差除以满分，默认各27%，不足6份作答时不显示。可在资料仓编辑满分、知识点和分组比例。

## 工程与部署

原生 ES Modules，无构建依赖。页面入口由经典启动器打开，交互先注册，材料后读取；空白状态先呈现导入引导，已具备材料的研究场景按需加载，单个场景失败保留导入与导航。本机存储读取设置超时。标题、正文说明、图表与数字使用仓库内的授权字体子集，按钮及密集表格保留清晰的界面字体；工作簿库由仓库本地文件提供。
