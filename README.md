# 衡迹 · 教学证据台

网站：https://yusheng266186-beep.github.io/jianwei-observatory/

围绕班级、试卷和学生组织研究的浏览器工作区。新版重新建立页面壳、对象路由、研究状态、查询索引、图表与操作流程。原有九个视图及其界面组件已移除。

## 六个研究入口

| 入口 | 起点 | 工作方式 |
| --- | --- | --- |
| 年级棋盘 | 一场考试 | 物理、历史同时展开；点班级进入画布；有效账、学科横向、年级历次变化、学生清册各自展开 |
| 班级画布 | 一个班 | 本场切面、纵向轨迹、有效达成在同一对象内切换；考试通过时间轴选择 |
| 试卷地图 | 卷架中的一张卷 | 点击题目展开观察窗，查看班级均分、零分/满分、具体学生；切换知识点路径和作答矩阵 |
| 学生档案 | 搜索姓名或班级 | 全部阶段始终保留；时间轴展开当次学科、小题、原排名与距线分差 |
| 跟进清单 | 临界对象 | 按距离与短板发现学生，加入可拖动的待开始/跟进中/已完成看板，记录教学做法 |
| 资料仓 | 教学材料 | 导入、备份、四表分析包、班级档案、任务、有效线、考试目录、题目资料与证据摘录 |

所有分析不设置共同的班级、科类、届别筛选。班级使用实体按键，考次使用时间轴，试卷使用卷架，学生通过检索进入。界面不使用下拉菜单。

**17班并入物理类，18班并入历史类。** 补习仅保留为班级备注，汇总、同科类基准、同类分位和历次分析均包含对应科类的补习班。

## 四张重要表

- 班级有效人：有效账与班级有效达成，含人数任务、增量、英语/日语、学科有效、双上线、10/20分临界带。
- 个人学科小题得分：试卷学生作答矩阵与个人小题，保留题号、分值、知识点、得分率和逐题原始分数。
- 班级多次考试对比：时间轴多选考次、共同参考口径、指标趋势、逐人矩阵、分位/排名/分差/学科对照。
- 班级成绩分析单次：原分、赋分、原排名、总分及学科距线、化学+生物本科分差、同科类比较、成绩分布。

资料仓可导出四表分析包，并附学科有效和题目目录。各研究页面能直接导出 Excel、Word，或打印保存 PDF；SVG 图表可导出 SVG/PNG。摘录保存当时的范围与结果，教师判断与研究证据一起保留。

## 导入与保存

支持标准复盘 Excel、单独小题表、CSV、JSON 工作区备份以及原质量分析项目的 GradeDataset JSON。通用表格使用可展开的列对应面板，逐列点选，没有下拉菜单。

文件由独立 Worker 读取，读完选择合并材料或替换工作区。追加考次和小题按姓名联结；替换前保留一次可撤回的材料快照。匿名样本导入真实成绩时建立真实工作区。先导入真实姓名的成绩原表，再补充小题。

材料与证据摘录保存在本浏览器 IndexedDB，模块偏好与跟进记录保存在 localStorage。新版本首次打开会迁移同源的旧见微本机材料与跟进记录。完整 JSON 备份可以迁移到其他计算机。真实工作簿、姓名、身份证与凭据不上传 GitHub。

默认样本来自标准成绩表的匿名版本；包括历史成绩和原始小题，不含真实姓名、身份证或原始工作簿。

## 统计口径

每名学生按当场考试、自己所属科类的有效线判断，不平均两类有效线。缺失不补0，0分有效，缺失总分保持空白。学科原分与赋分分开保存，原排名保留当次统计范围。

双上线要求同一人的总分和该学科同时达线。共同参考使用所选考次的学生交集。个人档案按学生身份查询全部阶段，班级矩阵按当次实际班级查询。日语与英语、地理与生物分别建立题库；混合选科按每名学生实际记录展开。

小题得分率仅采用明确的题目满分。含星号等不明确分值保持为空。区分度使用原始小题合计的高低分组均分差除以满分，默认各27%，不足6份作答时不显示。可在资料仓编辑满分、知识点和分组比例。

## 工程与部署

原生 ES Modules，无构建依赖。页面入口由经典启动器打开，交互先注册，材料后读取；研究场景按需加载，单个场景失败保留导入与导航。读取本机存储及样本均设置超时。字体使用系统字体，工作簿库由仓库本地文件提供。

发布使用本独立仓库已有的 GitHub Pages 配置：main 分支、根目录。提交后由 GitHub 的 pages-build-deployment 发布。`.nojekyll` 保持静态文件直接发布。

此次重建按委托人的要求不执行页面验收、数据校检、自动业务测试或浏览器截图验收；发布只跟踪 GitHub Pages 部署结果。
