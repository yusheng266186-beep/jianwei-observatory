# 荣县第一中学高三成绩分析

用户要求将“衡迹”直接改为“荣县第一中学高三成绩分析”，并融入所提供的学校校徽。

## 学校身份

- 页头将校名和“高三成绩分析”排成两行，旁边保留完整圆形校徽。窄屏仍显示完整校名；阅读设置等次要操作使用有名称的图标，最窄屏的导入按钮使用短标签。
- 导入页展示校徽与学校名称；数据导入前仍不展示具体成绩、班级、学生或统计样本。
- 浏览器标题、页签图标、触屏收藏图标、研究夹、观察抽屉、打印报告、Word标题、模板、备份与图表文件名统一学校身份。
- 校徽展示资源由用户附图整理为透明背景PNG，含蓝色主体、暖橙圆点、1912与校训。资源位于本仓库，页面不依赖外部图片服务；显示区域提前预留尺寸。
- 全站以校徽深蓝、浅蓝和白色统一视觉，包括标题、导航、按钮、卡片、观察窗、图表与导出图。校徽图像中的橙色保留原样，界面不再额外使用橙色。原有达线标尺、图册与各研究对象的形态继续沿用。

## 实现边界

`app/brand.js` 提供公开站点名称和校徽地址。数据存储继续使用原IndexedDB和localStorage标识，已有学生档案、教师判断、研究范围及跟进不因改名而迁移到空库。材料里的学校、年级和原始文件名仍由实际导入资料决定。

最新模块与样式使用 `layout-v9` 缓存键；未改动的校徽图片继续使用 `school-v6`。页面内校徽、页签图标及打印报告使用同一资源地址，避免重复下载不同版本参数的同一图像。

## 检查范围

使用匿名材料审阅六个页面的桌面与手机呈现，并检查320、390、820和1440像素宽度下校名、按钮和校徽的实际边界。沿用数据回归、导入/合并/恢复、逐层下钻、报告下载、手机布局及可视化导出的已有检查流程。

本轮 `npm test` 21项、`test:browser` 29组、`test:polish` 5组、`test:evidence` 4组均通过；39个应用模块静态检查无错误。页头检查发现320像素时按钮贴边，收紧该档字号及间距后，四档宽度的校徽加载、文字/按钮边界检查全部通过。完整校名继续可见。
