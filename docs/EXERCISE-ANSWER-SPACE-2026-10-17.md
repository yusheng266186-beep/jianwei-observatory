# 逐题作答留白与分页修复

选择题后出现大空隙，除了旧版客观题留白偏大，还因为导出把下一题的完整题干和作答区域整体绑定。下一题较长时整块移到下一页，前页留下大面积空白。

## 当前行为

- 选择、多选仅保留6点的额外间隔，填空10点；不额外添加推导草稿区。模型即使错误建议客观题大面积作答区，排版也保持紧凑。
- 新练习在同一次出题中逐题返回 `answerLines`。按手写行数建议主观题面积，每行18点，约6.35毫米；提示词结合小问、计算推导步骤、公式占高、字数及学生是否需要自行作图，不按长题干或统一用时分配。
- 旧练习没有该字段时，按题型、小问、参考答案和评分点估计，不重新调用模型。编辑题干、答案、选项或评分点会移除过时的模型留白建议，重新估计并要求重新审题。
- PDF 将题文与完整作答区域分开排版；短题保留题文完整，长题正常流动，留白按手写行跨页延续。页尾保护题号及必要引导，表头至少和一行数据一起移动。
- Word 使用相同留白高度，短选择题选项分两列；不靠空段落的大段后距把下一题挤到下一页，也不生成仅由不必要间距造成的尾页。学生文件只有干净留白，不加作答标签、行号或装饰横线。
- 导出缓存更新为 v23，PDF Worker 为 v55，避免沿用修复前文件。

## 前后端兼容

新提交请求带 `answerSpaceVersion: 1`，云端 Schema 才要求模型提供 `answerLines`。历史任务及旧前端请求不增加此字段要求，已提交任务仍按原请求执行。结果校验兼容缺少建议的旧练习。云端先上线兼容契约，再发布前端；仅更新专属训练服务代码，模型选择、密钥、环境变量、TOTP、额度和北辰服务均保持原值。

## 实际校检

- 教师反馈对应的原始生物八题保留全部题文和数值。学生 PDF 从6页调整为5页；第1题和第2题现在同页，选项正文到下一题标题约26点，不再留下半页空白。
- 真实调用现有模型，生成选择、填空、解答各1题：实际返回建议行数为0、0、8。已实际下载 PDF 与 Word，核对客观题小间隔及解答作答区；不发送学生身份或原始成绩。
- 原始八题学生与教师 PDF、Word 均实测导出，并检查表格、上下标与分页。新增回归覆盖模型建议优先、客观题紧凑、旧文档估计、逐行流动和新旧协议兼容；完整 Node 基线452项。

已有练习重新打开后下载即可获得新版间距；模型逐题建议适用于本次更新后新提交的练习。已下载到设备的旧文件需要重新下载。
