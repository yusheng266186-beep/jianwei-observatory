# 全场景控件与显示检查 · 2026-10-11

## 本轮修复

- **历次图节点点不到**：同一考次的被动基准点与主动节点重合，被动点遮住主动点。绘制顺序改为曲线、被动点、主动点；重合提示保留各条序列信息。实际点击重合考次后可切换。
- **空图表导出没有反应**：没有SVG的占位状态仍显示可点击导出。现在禁用按钮，显示没有可导出图表的说明，并保留导出函数的错误提示。
- **模态面板中的撤销点不到**：研究夹内删除后，外部通知被原生模态框置为不可操作。通知现在跟随最上层打开的面板，关闭后回到合适层级；导入内的通知关闭也可以操作。
- **宽表打印截断**：56列成绩表超出横向A4纸宽。打印/PDF与Word把宽表分成每组最多10列，重复考试、姓名、班级等识别列，保留全部字段。PDF固定列宽、跨页重复表头、避免拆开行或把标题单独留在页尾；Word使用横向纸张及重复表头。
- **玻璃面板数字消失和色块遮挡**：本环境Chromium中，面板内容与背景重复模糊出现绘制异常，改变宽度后可看到大块遮挡，部分统计数字不可见。内容层不再叠加背景滤镜，保留背景、顶栏、Dock和粘性工具区的玻璃层次；截图复现中的遮挡和缺字消除。
- **手机条形图行距过密**：整体缩小导致班级标签和点击行过窄。现在按实际显示宽度展开行距，字号按显示比例计算，点击行至少28px；图表随窗口变宽恢复紧凑布局。
- 被动柱形和趋势节点补齐统一悬浮提示，具体数值更容易读取。独立 SVG/PNG 下载保留文字字号、字体、颜色和实际图表尺寸。

## 复跑方式与证据

先在仓库根目录启动静态服务器，再运行：

```sh
python -m http.server 4173
```

在另一个终端运行：

```sh
npm test
npm run test:browser
npm run test:surface
```

可用 `SURFACE_RUN=名称 node tests/full-surface.cjs '17 '` 单独复跑对应组。完整运行还会核对108种当前点击命令是否全部覆盖。检查记录和匿名材料保存在被Git忽略的 `.audit-output/`，不随网页发布。

发布前01–16组连续复跑全部通过，记录1,106次布局检查、2,748次点击，覆盖108种当前点击命令及九类表单，无未捕获页面异常或HTTP资源错误。手机条形图改动后的第17组单独复跑通过，另有九次布局检查、11次点击，包含实际SVG/PNG文件验证。

原有37项数据与浏览器回归再次通过（八项数据测试、14项主流程、六项边界流程、九项连续使用流程）。41个JavaScript文件语法检查和 `git diff --check` 通过。以上次数包含同一控件在不同范围、宽度和材料状态下的重复检查，不等于这些数量的独立按钮或人工逐图审美验收。

## 范围边界

当前环境没有先前上传的原始工作簿，以上检查使用51名匿名学生、五个班级、三个覆盖不均的考次及六张试卷的构造材料。保留英语/日语的统一外语比较、17/18班所属科类、实际0与缺失的不同含义，但没有逐格核对真实四张sheet或身份证联结。

使用当前环境Chromium与模拟窗口检查，没有把它声明为Safari、真实手机、实际打印机或Word桌面版的测试。PDF实际生成并查看；Word检查压缩包中的文档结构与全部字段。布局与操作检查不能证明所有设备的帧率或主观视觉满意度。
