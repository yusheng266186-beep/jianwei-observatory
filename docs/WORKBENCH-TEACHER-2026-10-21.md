# 工作台与教师设置页维护 · 2026-10-21

本轮是可见的布局和账号管理改进，承接前轮小范围的教师文案调整。

- 模型工作台依次展示官方账号、职责配置、服务/模型/思考强度、配图与额度、历史诊断。账号卡片参考 Cockpit 的当前账号、已保存账号、添加与重新授权交互，不读取或迁移它的凭据。
- 出题、图示、校检仍独立应用；切换职责不会保存未应用的选项。各类选中状态保留原尺寸，以材质、颜色与勾选表达状态。
- 出题页按“范围与依据、训练内容、练习设置”组织。宽屏并排选择区与设置区；窄屏顺序阅读。教师已选范围、知识点、重点、题型、数量、时长、难度和配图常显可核对。保留滑轮、玻璃材质和动画。
- “题型”明确为答题形式；具体阅读、实验、写作任务由知识点、重点和补充要求决定。独立选择小题每题计一题；语法填空和主观材料题可按题组计。
- 官方账号验证成功后才激活；失败保留原账号。已知续期终止显示重新授权，不把访问令牌到期误当成账号失效。新增/切换需要桌面本机助手，手机继续使用现有云端账号。

提示词版本 `subject-templates-20261021.13` 改进教师要求优先级、语言题计数、难度和用时冲突、区分分项累计与互斥等级评分。格式修复可补缺失评分点，已有评分点保持不变；补齐后进入内容复核。完整导出范围见 [导出说明](PROMPT-EXPORT-2026-10-21.md)。

验证采用匿名界面夹具、授权状态与网络模拟单元测试、构建和生产部署核对。320px/390px 工作台无横向溢出；320px 图示职责按钮选中前后 86.67×64、模型按钮 264×54.09、生图服务按钮 270×60，尺寸不变。320px/390px 教师设置页无横向溢出；桌面图示职责按钮选中前后 379.73×58。没有在本轮替用户完成新账号的官方同意授权；账号界面截图使用匿名演示数据。真实线上验证只新建/领取/取消短期授权尝试，并使用无效测试授权码检查官方 token 传输返回明确拒绝，绝不导入或切换真实账号。

API 新增授权功能需要同样的代理环境与 Xray 层，部署时保留其余函数配置。若 JWKS 持续不可达，未验证 candidate 在原授权期限到达后结束等待；清理工作台持有的弹窗引用，避免失败发起残留空白窗口，助手区分到期和传输结果未知。

本轮本地 936 项单元测试通过；共享契约、构建资源图、字体、PDF worker、下载包与发布入口检查通过。浏览器中手动补充范围和选择单选题后，常显摘要立即同步。

线上授权接口实测：账号列表可读，创建/领取/取消正常；无效测试授权码经 API 私有代理取得官方明确拒绝，传输约3.5秒，原账号与模型配置保持一致。未建立新的官方授权、未切换真实账号。两项云函数各66文件与部署包一致。
