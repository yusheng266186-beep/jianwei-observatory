# 代码与实际使用复查 · 2026-10-13

本轮在上一版光影和得分色阶基础上检查数据、导航、输入、保存和导出，保留现有学校蓝白设计与六个独立研究场景。发布资源版本为 review-v23，固定访问入口继续使用 https://yusheng266186-beep.github.io/jianwei-observatory/ 。

## 已复现并修复

| 问题 | 复现方式 | 修复后的行为 |
| --- | --- | --- |
| 旧作答观察覆盖新操作 | 点击学生作答得分后立即点 Dock；或随后选择另一个学生/作答 | 小题与作答共用观察请求序号，并核对导航序号；只响应最后仍有效的请求。其他浮窗、关闭和导入取消旧观察请求 |
| 中文确认后未写入教师记录 | Chromium真实输入法组合输入产生 `input(isComposing=true)`，最后以 `compositionend` 确认，没有追加非组合输入 | 跟进、报告判断和资料仓判断都在确认时同步最终文本，沿用现有即时保存和刷新草稿恢复 |
| 跟进报告带出旧文字 | 修改跟进教学记录后立即导出或摘录；页面已有最新文字，报告仍是旧渲染快照 | 导出/摘录前重新生成当前跟进证据；预览、Excel与保存的摘录使用最新记录，导航变化仍取消旧操作 |
| PNG尺寸被后来的窗口大小改写 | 生成图表字体时缩窄窗口，全卷自动换行改变SVG的实时 `viewBox` | 点击时固定数值尺寸和图形快照，PNG不再使用随后变化的DOM尺寸。生成期间按钮显示状态并防止重复点击，失败后恢复，可直接重试 |
| Excel长表名截断后重名 | 两个报告表名具有相同的前31位，或包含非法字符、空名、大小写重名 | 工作表名统一清理、截断并生成唯一后缀，保留所有原始表格内容与顺序，不截断Unicode字符 |

记录输入仍在本浏览器处理。修复不更改成绩、排名、有效线、题目满分或原始作答，不向仓库提交私人工作簿和学生材料。

## 检查方式

- 代码审阅覆盖 Atlas 查询、解析/合并、工作区事务、草稿、导航、观察栈、表单、图表及文档出口。
- `npm test`：59项数据与边界检查；新增工作表名称保持唯一、合法和完整的回归。
- 静态检查：48个模块，包含新增的工作表名称工具。
- `npm run test:usage`：8组真实浏览器复现，包含自然/减少动态两种模式、最后观察生效、CDP真实中文输入法、即时刷新、最新跟进证据、PNG导出期间窗口变化、字体失败后重试与完整工作簿读取。
- `npm run test:code`：11组保存、并发、事务回滚、导入取消、资源重试与草稿恢复故障检查。
- `npm run test:surface`：19类全场景检查，逐项操作各视角、图表导出、题目卡片与作答格、观察窗、名单筛选、跟进拖动、九类表单、研究夹、导入与导出，在桌面和窄屏下检查布局。补充全卷研究起点的三个入口，覆盖本轮之前遗漏的 `paper-focus` 操作。
- 关闭与整页切换回归用于确认新的观察请求管理没有锁住浮窗或导航。

最终全场景回归通过19类检查，记录1139个版面状态、2853次点击、118种操作和9类表单；没有记录到页面脚本异常、失败资源或新的布局/交互问题。新增复现、保存故障与关闭回归分别通过8、11、8组。

初次全场景检查有一项PNG下载超过旧脚本5秒等待上限；脚本当时仍允许字体下载等待8秒。最终将下载等待与异步资源流程协调为20秒，保留失败检查，并增加生成反馈和字体故障后重试验证。这个等待上限调整不代表网站提速，也不将检查超时直接归因为产品故障。

浏览器材料均为匿名合成记录，测试所覆盖的操作与版面不等同于逐个核对使用者原始工作簿的全部单元格，也不构成真实设备帧率保证。
