# v44：学生身份、教学摘要与复核闭环

本轮目标：学生资料正确关联，常用报告先呈现教学重点，训练实施与实测结果可以连续回看。保留蓝白玻璃、既有动效和宋体打印规范。

## 身份与导入

以前按姓名建立或合并档案，同考次不同班的同名记录可能共用学生对象。现在优先使用学生识别码；没有识别码时结合考次与班级匹配，冲突档案按班级区分。唯一姓名跨考次的转班历史继续关联。有识别码的同班同名、改名与转班保持独立身份。

旧工作区同时调整成绩、小题，以及有明确班级与考次的训练和研究上下文。未提供识别码、又无法唯一确定归属的同名历史不凭成绩相似度猜测。导入中同班同考次的同名数值冲突要求提供识别码或整理重复行，避免静默覆盖。

分析表输出学生识别码和考次代码，保留前导零；已知考试名称可以对应原考次。四表分析包的字段映射与正式读取共用工作表选择规则，优先识别单次成绩表，不把有效人统计当作学生成绩。分析包可补回成绩，完整 JSON 备份继续保留全部题库、作答及教师记录。

匿名基线修复前后归一化成绩均为 8,687 条、小题作答均为 24,379 条；分数、排名、题目数值逐项一致。两个同名档案拆分后学生对象从 873 个变为 875 个，其余唯一姓名转班历史不变，再次合并不重复累计。

## 报告与首次阅读

增加教学摘要组合并用于新建常用报告。班级摘要保留全员成绩、校内与班级排名、本科距线、优先学科；重点对象和题目另列。学科摘要说明薄弱学生总数，按学科距线排列前 12 名优先对象；题目按得分率列出前 12 项，限定范围写入章节说明。

默认减少历史重复表、全卷长表和多列重复名册，完整材料仍可一键加入，恢复全部字段、历史与原始逐题附录。只有小题而没有总成绩时，摘要保留完整可用题目证据。个人报告仍清楚区分校排名与班排名，识别码存在时进入报告信息。

同套匿名材料的 1 班摘要为 5 页，全部含原始逐题附录为 55 页；全部参考班数学摘要为 5 页。页数由资料与所选内容决定，不以删除学生或缩小字体压页。

PDF、字体和阅读组件准备期间，先显示所选报告的真实关键内容；标明内容速览及纸面排版状态，成功后由实际 PDF 接管。速览使用现有材质变量，不替代导出文档。这里改善首次可读体验，不承诺所有网络环境的 PDF 完成时间。

快速关窗、重开或暂停阅读时，生成任务按所属阅读状态释放。旧任务完成不得解除新任务的占用状态，已销毁的 PDF 加载任务也不会永久阻塞下一份预览。下载任务继续独立持有自己的生成结果。

## 教学跟进

可填写实际答对题数、总题数、复核日期及结论。实际正确率独立于训练目标，实际 0 分有效；不修改原考试成绩、原题快照或自动判定达成训练目标。题数与日期在保存时校验。

看板与名单显示复核实测和结论，编辑已保存计划保留学生与考试，跟进中及已完成计划直接定位到复核区域。刷新、重开、备份及报告输出保留结果。逾期筛选优先依据复核日期。
