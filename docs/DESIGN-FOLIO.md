# 衡迹 · 研究图册

> 当前色系和内容密度以 [校徽色系记录](CREST-THEME.md) 为准；本文保留独立图册的形态设计过程。

用户希望保留温暖、通透、多样化的体验，同时要求独立设计。衡迹的形态从教学研究流程出发：把材料展开，建立对照，再形成判断。参考页只用于理解用户对氛围的偏好。

## 形态与阅读顺序

| 对象 | 呈现方式 | 用途 |
| --- | --- | --- |
| 空白工作区 | 三片折页、注册线、材料—对照—判断 | 表达流程；不出现样本人数或成绩 |
| 本场概况 | 开放数字构图、两条独立达线标尺 | 先看规模，再看本科/特控各自的达线位置与分母 |
| 四表入口 | 达线刻度、题目得分、阶段轴、分布预览 | 进入具体研究前先理解材料内容 |
| 班级研究 | 并排图表剖面、左侧批注线、学科条签 | 连续比较同一班的分布与学科结构 |
| 试卷研究 | 编目卡、实际题号坐标、得分率题目块 | 从试卷快速进入题目与作答 |
| 学生研究 | 档案卡、首字索引签、成绩明细折叠 | 从范围筛选进入连续个人档案 |
| 教学跟进 | 三阶段栏目、01—03顺序签、独立状态数量 | 把观察转成做法并回看进度 |
| 资料报告 | 六种编号索引入口、结构化材料页 | 修改口径、备份与整理证据报告 |
| 侧边抽屉 | 带页边线的证据页 | 查看局部资料、保存判断、回到来源 |

暖纸与浅金承担环境和主要操作；灰蓝用于另一组刻度；墨灰承担正文。数据颜色继续有图例。不同卡片的形状由对象决定，减少重复的大圆角、圆球与装饰光晕。

`assets/folio-sheet.svg` 在本项目中绘制，无外部图像与参考页脚本。它的横线不代表成绩。导入前仍为空白工作区；真实学生资料与附件不进入仓库。

## 数据与交互约束

- 本科和特控标尺分别使用自身的可判定人数。比例未知时保留“—”，真实0保留0与相应标记，不添加假进度。
- 试卷封面的题号直接来自该卷前24道题；进入试卷后保留完整题目。首页预览明确说明所预览的部分材料。
- 六个研究场景保留各自范围。17、18班仍归入物理/历史；外语比较仍使用表内折合分，具体作答题库分别保留。
- 任务卡片、名单下钻、完整明细、报告、图表导出及返回位置沿用原功能。手机将人数与标尺上下排布，避免四位数规模发生重叠。

## 动效

达线标尺使用有限时长的横向伸展；导航指示器、局部切换与抽屉继续使用可中断的真实DOM动效。移除空白页的持续漂浮和卡片跟随鼠标的光球/倾斜更新。Dock保留轻微靠近反馈。静读与系统减少动态效果时关闭标尺入场；不存在持续运行的背景动画。

## 验证范围

使用匿名材料检查六个场景、手机与桌面宽度、真实零值和未知口径、四位数规模、任务下钻与返回、SVG/PNG导出和正常动效下的连续切换。自动检查只能确认这些条件内的布局与行为；视觉体验继续以实际使用反馈为依据。
