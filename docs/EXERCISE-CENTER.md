# 试题中心（预览分支）

入口：资料与报告 → 试题中心。教学跟进继续作为按学生安排训练的入口。中心汇总当前浏览器保存的练习、生成任务和复杂插图任务，按状态及学生、班级、学科、目标检索；直接打开原练习，沿用教师审题与学生/教师 PDF、Word 导出。

## 任务恢复

- 先把完整匿名请求和 UUID 写入 IndexedDB，再提交云端。学生身份快照仅留本机，不进入出题请求。
- 云端 COS 元数据触发独立 worker；网页关闭、网络中断和查询端重开不取消已被接收的生成任务。
- 页面内始终跟踪待完成任务，不依赖辅导对话框是否打开。重新打开网页时，轻量 pending 提示触发后台恢复；没有任务的默认首页不加载辅导模块。
- 重连先 GET 原任务。只有从未收到接收确认、且 GET 明确不存在的任务，才按保存的原 UUID 和原请求恢复 POST。云端按原 ID 创建一次、运行一次和预留一次额度。已接收但过期的任务不会自动重生成；验证到期时保留任务，验证动态码后同步。
- 正常前台每 4 秒查询；隐藏、离线或未验证时延长间隔。联网与切回页面立即同步。失败任务不自动重新调用模型。
- 当前中心是本浏览器工作区，不宣称跨设备云端目录。云端对象仍保留 14 天；应及时审阅和导出。

## 状态和用时

“确认提交、排队、模型生成、待审题、已审题、未完成”均由本机提交状态或后台结果决定。GET 返回 createdAt、startedAt、finishedAt、serverTime、deadlineAt；连接状态单独显示。预计时间是范围，不伪造进度百分比或倒计时；有至少三份相近题量的同学科历史耗时后采用历史中位数估算，否则用题量估算。超过通常用时仍继续查询实际状态。

## 验证

`node --test tests/*.test.js` 包括真实时间戳、API 停止后 worker 完成、原 ID 重放不重复生成的隔离测试。`tests/exercise-center.cjs` 在 Chromium 和 WebKit 下检查 1440 / 390 / 320 宽度、搜索/筛选、直接审阅导出入口，以及丢失确认、离线重开、过期、验证到期恢复。另回归首次打开、原提交异常路径和手机 PDF/Word 缓存导出。测试使用独立匿名数据与模拟上游，不产生付费模型请求。
