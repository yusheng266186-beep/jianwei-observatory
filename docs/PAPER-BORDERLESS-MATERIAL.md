# 试卷研究：全部大小卡片的无边框材质

用户明确“小题方块”指试卷研究全部卡片，不只逐题地图内部的得分卡；大小卡片都不要装饰性边框。此次范围包括试卷档案与筛选区、卷面卡片及微型预览、全卷题序及其 SVG 小方块、概况与研究线索、逐题卡和内部题号/统计/操作区、知识点路径卡、六种视图的面板，以及单题和知识点抽屉的相关容器。

`styles/paper-material.css` 统一页面层、浮起的面板层与内嵌层；`styles/question-glass.css` 的得分材质继续在不同位置共享。常态、悬停和选中都去掉描边，也移除假边框式的细线 inset shadow。用透明度、柔和透光渐变与扩散阴影表示层级；选中通过小标记与局部材质变化表示。保留真实颜色深浅、未知文字与全部数据。键盘通过题号/操作文字强调显示焦点，高对比系统模式保留其必要可辨识性。

全卷 SVG 移除边缘路径和矩形 stroke，增加柔和透光层与当前位置点。`refreshPaperProfiles` 同步修改，调整两层矩形和标记尺寸，避免依赖已删除的描边节点。SVG/PNG 输出和窄屏自动换行保持完整。

验证：`test:paper-surfaces` 在1440、820、390、320宽度检查资料架、六视图、单题/知识点抽屉、悬停/选中、键盘操作、完整题号与实际计算边框；`test:material` 检查色阶、对比和跨场景口径；`test:workbench` 检查异常值、题序、快速导航、五宽度几何及真实SVG/PNG下载。资料均为匿名合成记录。

此次没有更改报告的打印表格线、A4分页或报告预览滚动布局。不要把浏览器分析界面的无边框装饰规则应用到黑白打印表格的数据线。
