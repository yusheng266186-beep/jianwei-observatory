# 分类打印报告与结构化专项训练

固定网站：https://yusheng266186-beep.github.io/jianwei-observatory/

## 报告入口和架构

“资料与报告 → 打印报告”有四个独立入口，各自选择范围。班级、试卷、学生页面和对应观察窗也有上下文入口。

| 报告 | 内容 | 跨报告关系 |
| --- | --- | --- |
| 班级诊断 | 本场概况与有效线、历次概况、特控和本科攻坚对象、各科评估、班级全部小题、临界生优先薄弱题、全班学生表现 | 同班同场训练；可附所有学生逐题原分 |
| 学科教学 | 概况、薄弱学生、各班比较、全卷小题、知识点训练优先级、待补材料 | 同场同学科训练；可附全部个人原分 |
| 学生学习 | 本场概况、完整阶段、学科分差与原排名、所有个人小题 | 该生跨考次训练、教师记录与复核 |
| 教学跟进 | 日程、责任教师、原题快照、任务、方式、题量、再测目标、复核记录 | 跟进页按当前筛选导出；报告中心按班级导出所有考次计划 |

特控、本科攻坚名单分别按有效线下的可调整观察带列出；不是概率预测，两名单可能交叉。学科薄弱名单明确采用本人的当场学科本科有效线，包含总分已达线而本学科未达线的学生。缺成绩、缺线另列。

英语和日语成绩统一用已折合的外语成绩，不再次折算；试卷和原题分别呈现。17/18班在各自物理/历史科类内统计。只使用原表校排名，没有校排不推断。

## 打印与文件

PDF为本机直接生成、可检索中文的真实PDF，首次下载才加载本地字体与pdfmake。Word为可编辑DOCX文本和表格。浏览器仍可“黑白打印”。全部默认A4纵向、黑白规则、灰色表头、重复表头与页码；宽表按最多6列分组，重复学生/班级定位信息，全部题目保留。PDF表头同时重复所属章节，首个数据行与章节一起分页；极长记录可跨页，不截断内容。

`app/io/print-document.js`是三种出口共用的章节/字段规则；PDF和Word不依赖屏幕玻璃样式。源数据与身份证不会发送到远程转换服务或写入公开仓库。

PDF字体使用完整Unicode字符映射的Source Han Sans子集，删除未使用变体/布局，按OFL要求改名为Rongxian Report。许可在`assets/report-fonts/LICENSE.txt`。pdfmake 0.2.20的MIT许可在`vendor/pdfmake-LICENSE.txt`。字体仅按需下载，不影响打开网站。

## 跟进流程

1. 选择学生、考次、原试卷；按薄弱题或知识点点选题目，也可手动选择未知满分题或补充训练重点。
2. 点选概念梳理、例题、同类练习、变式、订正、再测；选择指导方式，设置题量、目标与负责教师。
3. 选择日期，显示星期；未来两周有快捷日期。课内/课间分别点选第1–9节，可加具体时刻与时长，支持早读、午间、自习及自定义时间。
4. 设复核日期，补充教师记录与结果，保存后可用看板、名单、按日期查看。

原题标签、知识点、得分、满分和得分率作为快照保存。题库换序不会按旧索引错误选中其他题；切换学生/考试/试卷会重置不兼容题目。关闭可保留本机草稿，也可清除；历史简单跟进记录可继续编辑补齐。允许同一学生安排多次训练，完整备份保留全部新字段。

保存时校验题目/重点、任务、题量、日期、课时和复核先后；不把未知分数补0，不把比例异常自动列为薄弱题。

## 验证

- `npm test`：原有口径和新增分类报告、日期、范围、缺失/0分、字段分组测试。
- `npm run test:reports`：真实点选、草稿恢复、刷新日程、4类PDF/Word下载、外语原卷、数学1–19题、报告留存、上下文入口和手机布局。
- `npm run test:report-edges`：从原题直接安排训练、无课时阻止保存、窄屏、PDF首载失败重试、超长记录。
- 原有`test:code`、`test:close`、`test:workbench`、`test:usage`、`test:slides`回归。
- 实际导出文件用PyMuPDF核对A4、单色、文字边界、完整题号、长记录尾部和页尾标题，并抽查栅格版式；DOCX逐包核对XML、重复表头、尺寸和页码字段。测试只使用匿名合成材料。
