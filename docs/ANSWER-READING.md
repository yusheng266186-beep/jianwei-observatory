# 2026-10-12：单题证据与抽屉阅读

本轮重点缩短“看一道题—找到对应学生—沿原路径返回”的操作距离，延续校徽蓝白玻璃与独立研究图册的设计。

## 变化

- 单题观察增加紧凑的得分结构：明确满分时，零分、低分、中段、高分、满分及以上、未填分别呈现；分组互斥，包含本范围全部作答记录。占比的分母包括未填，均分和得分率继续只采用有效分数。
- 点击分组人数直接进入对应名单。结构图使用完整班级范围，名单检索不改写图表；范围、口径和导出都明确区分这两种统计对象。
- 满分未知时只显示零分、已填非零、未填，不制造百分比分段。负分和超满分保留原始数值；小数阈值比较作数值稳定处理，不改写得分。
- 单题名单增加低分、高分、姓名排序与显式清空检索。进入学生再返回时保留条件和阅读位置。
- 单题观察提供“得分结构／班级差异／作答名单”章节栏，随实际阅读位置高亮；可一键回到题目概况和导出操作。窄屏页头换行时，导航按页头实际高度避让。
- 手机筛选按钮压紧为两列，长标签避免单字悬空；千位人数不截断。固定阅读控件使用清楚的底色，减少滚动文字透出，主体继续保留玻璃层次。
- 得分结构条在范围变化时短暂过渡，沿用稳定DOM；静读与系统减少动态效果关闭该过渡。
- 单题导出同时保留整题结构与筛选作答，包含分组口径、姓名检索、排序和浏览来源。
- 单卷导出沿用原始子题号；没有作答时仍保留该卷完整题列。混合试卷保留既有按位置的作答表与题目目录，避免混合列引入虚构题目。

## 检查

匿名材料覆盖真实0、空白、未知满分、负分、超满分、小数阈值、题号和完整导出。`npm test` 的32项数据回归通过；六场景浏览器流程29组、题目地图6组、动效25组、卡片密度4组与阅读偏好5组通过。

新增 `npm run test:answers` 检查全部六种分组、排序、姓名检索、学生返回、未知满分、实际Excel内容、章节跳转和回到概况。布局检查覆盖320、390、820、1440像素与1,203份匿名作答，检查实际文字边界、卡片高度和导航避让。

另将单题观察加入全场景结构检查：252个渲染结果无结构错误，四档宽度下1,008个布局组合无卡片或文字越界记录。静态审核覆盖42个JavaScript模块，无错误。

检查在当前Chromium环境下使用匿名材料，真实工作簿逐项核对与实际设备视觉体验另行判断。模块与样式缓存键为 `evidence-v11`，未改动的校徽资源继续使用 `school-v6`。
