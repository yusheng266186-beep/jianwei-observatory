# 2026-10-12：关闭操作与小题卡片

固定入口：https://yusheng266186-beep.github.io/jianwei-observatory/ 。

## 关闭操作

复现了两类关闭风险。原关闭逻辑只等待退场动画的 finished；动画暂停时研究夹保持模态，缺少动画接口时会报错。另一个实际点击缺陷来自提示条：隐藏后，其按钮仍设置 pointer-events:auto，并且基础 display:flex 覆盖了原生隐藏状态。窄屏上透明的“撤回材料更新”按钮会挡住导出；长研究夹中提示条也可能靠近关闭区域。

关闭动画现在有独立的完成兜底，普通弹窗在 160ms 动画后退出，暂停时在约 220ms 完成退出；观察窗为 180ms / 约 240ms。浏览器后台节流可能延后计时，动画状态不再是关闭的唯一条件。动画接口缺失或失败时仍执行原生关闭。重新打开会撤销旧关闭记录，旧退场不能关闭新的面板；观察窗继续采用现有操作序号保留最后一次操作。

隐藏提示条不显示，也不接受点击；弹窗中的可见提示条移到下方，避开关闭区。宽表的旧 close 事件不能清空刚重开的新表格。报告保存完成后，旧关闭请求不能误关后来打开的另一份报告。报告判断的保存失败仍有明确反馈，不丢弃判断；导入提交期间仍遵守原来的完整保存规则。

新增 npm run test:close。使用匿名材料验证研究夹、阅读设置、报告、宽表、观察窗的真实关闭按钮、Esc、焦点与滚动锁恢复；覆盖桌面、手机、正常/减少动态效果、暂停退场、缺少接口、连续点击、快速重开、取消正在读取的导入，以及长研究夹中仍然可见的提示条。键盘委托和点击委托也处理非 Element 事件目标。

## 小题卡片

逐题地图采用蓝白仪表卡：题号和状态在顶部，得分率用独立数字排版，细比例条辅助比较；均分与满分、有效作答/记录数、平均失分、零分/达满分人数在下方集中排列。知识点完整换行显示，箭头与按压/悬停反馈明确整张卡可以打开观察窗。卡片高度由内容决定；单题在桌面横向组织，多题使用网格，窄屏保留可读字号和完整信息。320px 下同步收紧试卷概况的间距。

不再用大面积深浅底色表达逐题地图的得分率，热力矩阵仍使用既有图例。真实 0 分仍显示 0%；未知满分、空作答和未知失分保留 —。平均比例超出 0–100% 时保留原始数值、标注异常，避免画成正常比例条。达满分人数沿用原统计：得分达到或超过明确满分；未给满分时仍未知。

题目组件位于 app/ui/question-cards.js，样式位于 styles/questions.css。检索、条件、班级范围、排序、连续浏览、知识点研究、完整明细和全卷导出沿用既有逻辑；数据未改写，不添加演示成绩。
