# 中文输入、资料保护与导入复用

本轮围绕日常使用的可靠性改进，不改变统计口径、模型配置或现有玻璃材质与动画。

## 中文输入

`app/ui/committed-input.js` 将一次输入法选字作为一次有效编辑：

- `compositionstart` 后忽略未确认输入，取消相关搜索待执行计时器。
- `compositionend` 提交最终文字；浏览器随后重复发送同值 `input` 时只处理一次。
- 不依赖每个浏览器都准确设置 `isComposing`，也不要求浏览器一定发送末尾 `input`。
- 普通输入、清空、粘贴继续使用原来的响应或防抖机制。

统一用于主界面的搜索和文字记录、试题中心、辅导学生选择与教师设置页。保留已有动效和列表反馈。

## 资料保护

材料页在当前工作区内显示完整备份状态、最近导出时间、比备份时增加的记录份数，以及浏览器存储保留与空间估算。

- `workspaceJournal` 在现有 IndexedDB 事务内记录修订标识及集合计数。材料写入失败、被拒绝的过期提交不会留下成功修订；导出文件缓存不更新资料修订。
- 保存的研究夹、收藏、比较及目录视图另记录轻量本机修订；只浏览产生的研究历史不据此催促备份。
- 修订元数据不复制或序列化整份学生材料，不增加页面启动时的历史扫描。
- 完整备份发起下载后记录本机回执；无法完整读取的“当前可恢复资料”不更新完整备份时间。
- 导出期间其他页面有更新，保守保留“有更新”状态；不会把并发更新误标成已备份。
- 数字为与备份的净增量，不将同份数内容修改说成新增，也不把减少说成增加。
- 回执从本版开始记录，旧版导出文件无法倒推时间；换浏览器后也不继承原浏览器的备份回执。

网页只能发起下载，不能确认用户最后把文件保存在何处。请核实下载文件。完整备份仍是换设备、换浏览器或清理站点资料的迁移方式。

“加强本机保存”仅在点击时调用浏览器持久存储申请。申请是否批准由浏览器决定，未批准时原有保存功能继续工作。空间数值为整个同源站点的估算，不是项目独占空间；持久存储不能阻止手动清理，也不代替备份。

## 列对应模板

通用 Excel / CSV 的列对应界面增加“记住这次列对应”。成功解析后保存，解析失败不写模板。

- 只保存完整表头、列位置、模板名称和时间，不保存学生单元格或原文件。
- 完整表头及顺序一致才套用，仍显示确认页，教师可检查排名范围并修改。
- 表头新增、删列、改名或换序时重新识别，不进行模糊套用。
- 可移除已存对应，或取消勾选保存；普通成绩合并不会复活已经删除的模板。
- 同一表头再次保存更新原模板，保留最近20种表头结构。
- `importColumnTemplates` 纳入完整备份；恢复时按更新时间合并，保留较新对应。
- 多文件一起导入时独立收集模板，避免后续成绩文件冲掉先前备份的列对应。

同时修复导入窗口退出动画未结束即再次打开时，旧退出动作可能关闭新窗口的问题。继续沿用可中断的窗口动画。

Linux WebKit 大数据快速切页触发了 History API 写入频率限制；事件记录确认点击已经送达，本机亦复现第100次调用后的 `SecurityError`。相同研究状态不再重复写入历史；`pushState` 受限时使用原生 hash 导航继续更新地址与界面，保留返回能力，不让历史存储异常中断页面切换。压力测试主动耗尽配额后验证六场景导航和返回。导航装饰子元素仍统一交由按钮接收点击，保留全部动效与命中区域检查。

## 验证与维护

```sh
npm test
npm run build
npm run test:workspace-care
AUDIT_BROWSER=webkit npm run test:workspace-care
```

浏览器测试需要本地静态服务；可使用 `AUDIT_URL` 指向服务地址。测试使用独立浏览器上下文、匿名 CSV / JSON 和模拟浏览器存储授权，屏蔽出题云端请求，不访问真实学生资料或产生模型费用。

`tests/workspace-care.cjs` 在 Chromium / WebKit、1440 / 390 / 320px 检查模板保存、复用、表头换序、移除、跨浏览器恢复、移除后再次合并、备份状态、空间显示、存储保留操作、事务修订、中文输入及横向溢出；截图和结果保存在 `.audit-output/workspace-care-*`。

这项测试已纳入两种浏览器的 CI。真实手机输入法和实际存储授权决定仍以设备行为为准。没有新增 AI 成功率结论或内容限制。
