# 生成全链路误拦截与恢复复查（2026-10-21）

本轮按教师要求检查出题入口、结构解析、内容核对、图示、保存、预览和导出。重点是减少无实质影响的限制，让模型依据完整上下文判断，不添加题干没有的条件。

## 查到并修复的问题

| 环节 | 原问题 | 调整 |
| --- | --- | --- |
| 出题入口 | 底层已接受完整 JSON 围栏，入口的旧前缀判断却提前拒绝 | 删除重复判断，完整围栏直接进入同一解析器，不额外调用修复模型 |
| 分值与估时 | 所有学科统一限制单题25分、30分钟，作文等可能被误拦 | 移除统一上限；预计总用时与难度标签的机械比例不再决定整卷失败，实际内容由模型按教师要求审查 |
| 客观题评分 | 用评分描述数组的条数推断是否符合高考评分 | 不以分行方式判定，保留学科模型对实际评分规则的核对 |
| 插图位置 | 引图句的标点、重复引用或编辑变化导致整题及导出中止 | 合适的原锚点优先使用；失效时安全落在引言段后，保留全部题文，不切开公式，仍可手动调整 |
| 内容与图示 | 用草稿关键词、科目白名单、图示用语或图类推断题意 | 改为上下文核对线索；允许合理跨科图示与等效表达，不因为关键词或类型不同直接否决 |
| 格式修复 | 只识别少数报错文案，其他完整成稿的可修复问题直接结束 | 完整且未触及安全、容量边界的校验问题均可带原稿、原因和候选交回模型；中断、余额、鉴权等服务错误不冒充内容错误重发 |
| 修复保真 | 显示元数据也要求原样保持，导致修复无效难度标签、估时或版位时再次被拒 | 区分题干条件、已有答案、数值、选项与显示元数据；保留可读的实质内容，允许修正显示标签、估时、留白和版位 |
| 任务派发 | 任务已保存但触发事件丢失时可能一直排队 | 对尚未开始的同一任务补发事件，并持久化去重；已存在运行锁、结果或删除记录时不补发，不重复调用模型 |
| 公式初始化 | 脚本下载完成就清除了超时，但初始化 Promise 仍可能不结束 | 超时覆盖整个初始化过程；失败后释放加载状态，可再次正常尝试 |
| 审题与导出 | 一般建议也要求逐项勾选，可能在正式确认前反复阻塞 | 保留普通建议供教师参考，一次正式审题确认后即可导出；给建议标记已阅不再使已确认内容失效 |

教师选择的题量、内容范围、题型以及必要题文、选项与参考答案仍有效。安全的图示元素、实际数值坐标、文件及来源检查、明确的评分合计冲突、已委托的必要图片完整性继续检查。这些用于保障可用性，不补造任何解题条件。

## 验证方式与实际结果

- **854项单元测试通过。** 新增完整适配器→出题入口→内容核对→持久化成稿的组合测试，以及公式初始化不结束、触发丢失、显示元数据修复等反例。
- **十科历史真实成稿回放。** 使用前轮实际生成的60题，各自测试原稿、完整JSON围栏、显示信息及锚点变化三种组合，共30组通过；比较确认解析没有改写题干、选项、答案或图示数据。九科沿用前轮实表知识点，日语沿用教师自定要求，来源不混淆。这是历史成稿的兼容性回放，不是30次新的模型生成，也不据此推算新出题成功率。
- **实际浏览器预览与导出。** 使用数学、语文各6题的真实历史成稿，通过原有预览和PDF、Word模块输出学生版和教师版，共8份文件成功。四份PDF共17页，题号1–6完整；四份Word压缩包与文档XML有效。PDF已渲染复查，图文无裁切或重叠。
- 构建、前后端共享契约、保留资源图、字体、PDF Worker及发布入口检查通过。

保存与续跑继续使用原任务及原稿，不因临时存储错误重新出题；本轮未更改模型选择、授权、使用次数或图像服务配置。
