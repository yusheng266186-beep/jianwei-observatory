# 2026-10-11 校检与修复

本轮依据用户最新指令“现在你自己做一轮校检，看看有没有什么问题或者bug”执行。此前版本遵守不做校检的要求；这次新增的授权适用于本轮校检。检查对象为衡迹独立仓库，不涉及原成绩查询项目。

## 已复现并修复的问题

| 问题 | 原行为 | 修复后的行为 |
| --- | --- | --- |
| 小题独立档案 | 只有小题、没有总成绩的学生点击姓名后没有档案标题，也不能恢复研究线索 | 学生目录、观察窗和完整档案可呈现已有小题；注明缺少总分及学科成绩。材料索引独立于成绩索引，不添加虚构成绩或参与班级成绩统计 |
| 备份合并与学生引用 | 导入的摘录覆盖已有摘录；同名学生内部 ID 合并后，收藏、对比、跟进与研究引用未同步 | 合并双方教师工作并去重；将导入的学生引用、跟进主键、研究祖先路径和题目聚焦学生同步到现有 ID |
| 撤回替换 | 只还原成绩材料，摘录及研究夹仍停留在被替换的备份 | 撤回快照包含材料、摘录、研究夹、收藏、对比、跟进和常用筛选，并同步恢复本机存储 |
| 双上线未知值 | 所有总分或总分有效线缺失时，学科双上线错误显示 0 | 没有任何完整可判定样本时显示未知；存在可判定样本但无人达线时保留真实 0 |
| 区分度样本 | 未填齐的作答按部分合计参与高低分组，缺题可能变成低总分 | 只用全卷得分填齐的作答分组；完整样本不足 6 份时留空，单题均分与作答名单仍保留部分有效数据 |

学生摘录预览同时呈现完整小题记录；试卷合计均值明确标为“已填小题均值”，说明包含未填齐的记录。

## 验证范围

测试使用人工构造的 51 名匿名学生、5 个班级（含 17/18 班）、2 次考试和独立英语/日语题库。没有使用姓名、身份证等真实个人数据作为测试资产。实际使用 Chromium 打开网站，执行 Worker 导入、点击、筛选、下载、刷新与本机存储恢复。

- 原生 Node 数据回归：8 项，覆盖英语/日语折合口径、补习班归属、双上线未知与实际 0、题目零分与缺失、知识点完整作答、区分度分组、小题独立档案及备份引用重联。
- 主流程浏览器回归：14 项，覆盖首次空白、JSON 导入、六个场景、逐层抽屉返回、研究夹刷新恢复、摘录自动保存与返回、Excel/Word 导出内容、学生目录视图、完整备份、390px 移动布局、正常动效下连续操作，以及脚本/资源错误。
- 边界浏览器及模型回归：6 项，覆盖小题独立档案及研究恢复、不同 ID 备份合并、替换撤回、实际 XLSX 成绩/小题导入、双上线全缺及区分度不完整样本。

本轮合计 28 项检查全部通过；34 个应用脚本的语法和本地静态导入路径检查通过。

## 运行方式

应用仍为直接发布的静态 ES Modules，无生产构建依赖。Playwright 仅用于开发校检。

```bash
npm ci
npm test
npx playwright install chromium
python3 -m http.server 4173 --bind 127.0.0.1
# 另一个终端执行
npm run test:browser
```

浏览器脚本优先使用系统 `/usr/bin/chromium`，也可通过 `CHROMIUM_PATH` 指定路径。`AUDIT_URL` 可指定带末尾 `/` 的部署地址。截图、导出文件及 JSON 检查结果保存于 `.audit-output/`，已排除提交。

## 范围限制

原始成绩附件不在本轮执行环境中，因此没有逐个核对真实学生的历史成绩、四个原始工作表或身份证匹配。移动端检查使用 Chromium 的 390px 视口；没有进行真实 iPhone/Safari 或低端设备帧率测量。以上验证证明所列路径和构造数据的结果，不代表所有设备、所有原表变体或视觉满意度已经验收。
