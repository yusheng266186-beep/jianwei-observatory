# 入口、返回与成绩口径

本轮统一四种动作的含义：

- Dock 打开板块入口。年级总览回概况首页；班级研究回当前班的本场剖面；试卷研究回最新试卷档案；学生研究回完整学生目录；资料与报告回材料入口。再次点击当前入口也回到页面顶部。校徽直接打开年级首页。
- 切换学科、考次、班级与视图只改变当前研究范围，不追加一层返回路径。新试卷清理旧题号和姓名检索，保留相容的班级与展示方式；原班级不在该卷中时显示该卷全部参考班。点击已经选中的试卷或考次不会清空条件。
- 从图表进入班级、从名单进入学生、从学生进入小题属于下钻，返回恢复对应来源条件与位置。显式选择 Dock 后开启新的路径，旧板块不混入新板块的返回按钮。新对象从页首打开；恢复研究或沿路径返回保留原阅读位置。
- 抽屉的返回退到上一层观察对象，关闭收起整个观察窗。研究夹与最近足迹用于继续已有条件及阅读位置，入口导航不会隐式恢复某个深层对象。

试卷顶部提供学科和考次的直接按钮，并显示已导入科数。手机展开学科按钮，避免科目切换藏在卷架或横向栏末尾。只有数学材料时说明覆盖情况并提供补充入口，不生成其他学科作答；英语与日语保留各自真实试题，成绩比较仍使用折合外语。

分布图将本科、特控说明放在独立标注行，柱顶人数与标注分开；阈值线在文字下层，人数带浅色描边。窄屏密集分组的人数标签按实际字形边界错开放置，全部人数保留；底部另留坐标标签空间。SVG与PNG保留阈值说明。

学生卡片、名单、观察窗和档案优先显示年级排名，取自表内校排名；市级原排名不会冒充校排名，缺失保持未知，不随当前筛选重新编号。排名轨迹数字越小越靠前，纵轴使用正整数，不出现零名、负名次或重复刻度。原“分位”作为辅助相对位置保留，明确采用已导入同科类有效总分换算为0–100，同分共享位置，导入范围变化会影响它。相关排序、说明、筛选标签及报告口径同步调整。

关闭观察窗后改变学科或范围，会释放旧观察来源；只有来源页面和条件仍相同时，打开完整档案才保留刚关闭的观察窗供返回。导航直接更新地址并开始呈现，不再等待额外的hashchange事件启动页面切换。

专项检查：`npm run test:entries` 覆盖入口、返回、十科学科与考次切换、只有数学时的提示、四档宽度分布图文字边界及交叉、图表下载和学生原表排名。`npm test` 包含原表排名来源、缺失与市排名处理、筛选不改写名次及排名轨迹方向的检查。滚动控件专项见 [滚动与控件细节](CONTROL-DETAILS.md)。使用匿名材料检查，本次发布不包含真实成绩或身份证。

2026-10-12 检查结果：36项数据与排名回归、29组浏览器流程、25组动效检查、5组入口专项及4组滚动控件专项通过。全场景检查与新增控件复核合计19组通过，覆盖117种操作和9类表单；原试卷遍历脚本在返回卷架后改为显式选“全部考次”，随后重跑旧考次遍历。252种完整呈现的HTML结构检查通过，四档宽度下1,008次卡片边界检查无越界。静态检查42个应用模块无错误。Firefox和Safari未在本轮实际运行，浏览器流程使用Chromium。

## 2026-10-12：整页横移与考试名称

不同板块切换时，标题、卡片、图表、章节导航与明细作为一个整体横向离开，新板块从另一侧进入；方向跟随 Dock 顺序，页头与 Dock 留在原位。仅待新内容准备好后启动460毫秒过渡，旧内容使用临时的真实 DOM 退出层，隐藏于辅助技术并禁止交互；主内容立即可用。快速改向从当前可见位置衔接，同一时间最多一个退出层。结束、页内更新、尺寸改变、加载失败或开启减少动态效果都会清理退出层与临时样式，观察器同时释放旧元素。页面竖向滚动和表格位置沿用原来的规则，退出内容保留切换前的阅读位置。没有导入材料时不建立数据页面退出层。

试卷档案最新考次显示材料中的实际名称、编号和单独的“最新”标记，旧考次也显示名称。学生目录及年级阶段对照同步使用实际名称；班级、年级与跟进考次轴完整换行呈现名称，避免仅依靠省略文字或悬停提示。学生目录的“每人最新”仍表示每位学生各自最新的记录，独立于某一指定考试。长名称和特殊字符保留原文本，手机直接换行，没有新增下拉菜单。

专项运行 `npm run test:slides`，使用匿名材料覆盖桌面与手机六个板块正反切换、实际主内容和退出层位移、快速改向、旧页操作防护、滚动位置、减少动态偏好、尺寸变化、无重复ID、图表导出目标以及四档宽度真实考试名称和选择操作。

本轮另修正原表“学生基础”的统考校排名导入：此前按考试类别将校排名置空，导致4册以及入口、1册、2册、3册的明确校排丢失。现在明确的校排名列优先保留，市排名独立保存；统考没有校排时保持未知，校内考试缺专门校排列时才使用原通用排名。平面表新增识别“校排”“年级排名”等等价列名。旧版已经丢掉的数字无法从市排名反推，需重新导入原表并选择“合并补充”；已有学生、其他成绩和教师记录继续保留。

排名复核：使用本机原表历史提取记录核对4册物405条成绩，修正后的导入结果405个校排名均与原列一致，核对只输出汇总数字，不上传姓名、成绩或身份证。`npm test` 新增4项真实XLSX、缺排名、旧资料合并补排与平面表列名回归；`npm run test:slides` 新增浏览器真实工作簿合并，检查目录、观察窗、完整档案与下载备份一致。

本地检查：40项数据回归、29组浏览器流程、5组入口、4组控件、8组横移与命名/排名专项通过。25组既有动效流程中，原学生点击脚本取到了刚入场时屏外坐标；调整为在控件已经可见且主内容仍移动时实际点击后，该项复查通过，其余24组通过。42个应用模块静态检查无错误。本轮浏览器检查使用Chromium，不代表其他浏览器或真实设备已经测试。
