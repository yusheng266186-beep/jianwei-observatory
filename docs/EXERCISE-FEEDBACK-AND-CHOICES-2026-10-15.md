# 练习提交反馈、教学选项与滚轮选择

## 已确认的触发条件

在内置浏览器的真实操作状态中，教师访问已经验证，训练重点已有内容，但教材与教学范围为空。点击生成触发本地校验，没有创建云端任务。旧版错误提示位于当前视口上方约 1435px，按钮附近没有提示，因而表现为无响应。

## 本次调整

- 必填项明确标注；知识点、教材范围、题数和时长分别给出具体错误。提交后自动定位首个无效输入，同时在操作区显示原因。未验证时直接展开并聚焦验证码入口。
- 在本机保存及网络请求之前，立即显示提交状态。云端接收后展示真实阶段、实际等待时长和生成流程，完成后自动进入审题预览。保留同一请求 ID 的查询恢复与防重复提交。
- 修复从教学跟进辅导中心重新进入任务时没有启动自动查询的问题。
- 教材范围提供按学科划分的常用教学模块；知识点优先使用导入材料中的明确标注，提供可组合的学科训练重点。没有表内标签时明确展示常用模块。所有选择均可手动编辑，不推定教材版本。
- 题数 3–12、时长 5–90 分钟使用垂直玻璃滚轮；支持触摸滑动、鼠标滚轮与拖动、键盘上下键及 Home/End，保留精确输入。
- 修复快速切换学科时，正在退出的菜单保留上一学科选项的问题；保留退出动画与玻璃材质。

## 验证

- 173 项单元测试通过。
- Chromium / WebKit：1440、390、320 宽度的输入定位、六科选项、滚轮/拖动/键盘、立即等待状态、重复提交防护、辅导中心任务恢复检查。
- Chromium 触摸事件模拟实际滑动，题数随滑动更新。
- 两个引擎检查额度拒绝及网络提交结果不确定后的同 ID 恢复。
- 复核审题、修改后重新审题、学生/教师 PDF、重复导出缓存和加入教学跟进；辅导中心多考依据、SVG 与独立插图按钮回归。
- 服务健康接口返回 HTTP 200。此次 UI 验证使用匿名测试材料和拦截响应，没有新建付费模型或生图任务。

仅提交功能分支并发布独立预览；正式站、主分支及北辰服务不变。
