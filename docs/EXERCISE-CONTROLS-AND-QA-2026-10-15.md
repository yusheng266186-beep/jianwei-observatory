# 个性化辅导控件与输出复核（2026-10-15）

## 本轮修正

- 考试与图示方式采用玻璃选择浮层，支持方向键、首尾定位、Escape、Tab、点击外部关闭及焦点返回；沿用现有开合动画。快速重开不会把上一轮选择延迟写入另一学科。
- 五档难度保留移动高亮，增强蓝色玻璃选中层、文字层级与“已选”说明；手输题量同步快捷按钮。
- 教师只填写六位动态码。服务地址使用固定发布配置；历史其他地址的会话不被沿用或发送。
- 明确拒绝的任务结束等待，可调整后再生成。提交结果不明的任务用原编号核对；同一学生、考试、学科不能另起重复任务。重查成功后清除旧失败提示。
- 教师答案册和学生答题区使用无边框、零内边距的分页容器，避免跨页后行首遮挡；选择题按宋体实测宽度决定双列或逐项排列，短题干与必要图示一起分页。打印 Worker 更新版本，字体文件缓存继续复用。
- 修正图示中 `a -> b`、`x < 0` 被误判为 HTML 的问题；标签仍转义，脚本与标签内容仍拒绝。
- 云端学科模板更新至 `subject-templates-20261015.3`。加强实验副反应、测量条件和学生图不提前给答案的要求；化学模板增加洗气产生额外气体的复核规则。界面显示精简检查说明。

## 实测发现与限制

首次化学实测返回格式未通过校验，未输出正式练习。诊断确认导管箭头误判后修复；进一步人工复核发现模型样题的实验测量条件和图示答案泄露问题，已据此更新云端规则。更新后的化学任务已通过真实云端调用，返回 SVG 流程图及两类 PDF；核对了理论 4.40g CO2 和标准状况 2.24L 的计算。进一步补充了无量纲相对原子质量与有单位摩尔质量的区分，并禁止无依据的替代实验方案。化学式图示标签改为完整词组换行与数字下标；下标复用已有数字字形，避免引入字体缺字。复核时通过编辑器修正单位表述与无依据的实验建议，重新审题后导出。结构校验通过不等于内容自动审定，教师审题与修改后重新确认的流程保留。

复杂插图按指定的 `gpt-image-2` Web 逆向 Chat 接口实测一次，返回 `IMAGE_REQUEST_FAILED`，未将其记作成功。标准 SVG 与文字练习可使用；复杂插图失败保留原题，且不自动重复付费请求。

全部验证在匿名材料及隔离服务上进行，正式主分支和正式 Pages 保留原版本。
