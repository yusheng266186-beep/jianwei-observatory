# 体验与可靠性修复 · 2026-10-23

本轮修复五项实际可复现的问题：跨标签页继续读旧成绩、无修改同步重写整库并误报备份更新、辅导入口等待样式时没有反馈、失效连接测试持续轮询，以及手机通知遮挡标题。保留原有材料口径、功能、玻璃材质、非线性动效与文档版式。

## 行为变化

| 问题 | 修复后的行为 |
| --- | --- |
| B页保存新材料，A页仍无提示地显示旧成绩 | A页显示持续提醒。点击“备份本页并载入”先下载本页恢复文件，再读取最新材料；备份集合不完整时保留本页，允许恢复后重试 |
| 同步状态即重写全部练习和修订记录 | 没有实际修改时只读取最新记录，不写入练习或工作区修订，不把已备份资料误报为又有更新 |
| 首次打开辅导中心，CSS延迟时界面无反馈 | 点击后立即显示可关闭的加载窗口；组件和样式继续并行准备，关闭后的迟到结果不重开窗口 |
| 恢复不存在的连接测试后一直等待 | 明确404/410、过期或拒绝访问结束查询并恢复测试入口；暂时网络和服务器错误按5–30秒退避查询原任务，可主动停止查询 |
| 手机通知位于标题上方并遮字 | 页面提示位于Dock上方，按可见视口计算间距；弹窗内仍避让保存、导出按钮 |

跨页载入还修复了相关草稿恢复问题：同一学生、考试及训练重点入口可继续未提交计划；不把草稿套用到其他对象。恢复文件包含本页旧材料和未提交草稿，旧材料文件仍明确标注为“当前可恢复资料”。浏览器发起下载后，请按设备下载设置保留文件。

## 保存与并发边界

`storage.update` 的默认写入语义保留。仅显式选择 `skipUnchanged` 且 reducer 返回事务读取的原引用时，跳过写入、修订和保存信号；原地修改的旧调用方仍会保存。

无修改练习复用不可变基线，但仍读取事务中的最新记录；其他页新增、修改或删除的练习会进入本页。实际修改继续走原三方合并、同文档冲突及审题版本保护。保存期间继续输入仍保持为待保存内容。在途进度和生成日志按原约定不进入完整题文快照。

连接测试的提交和查询都检查请求版本及任务ID。停止旧测试后，其迟到的成功或失败不会清除新测试。停止按钮只结束本机查询；不取消云端已接收的任务，也不自动重测产生额外调用。
