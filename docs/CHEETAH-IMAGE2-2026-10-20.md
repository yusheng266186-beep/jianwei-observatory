# 猎豹 Image 2 原生接口（2026-10-20）

工作台将猎豹 Image 2（`gpt-image-2`）与 Image 2.5（`gpt-image-2.5`）分为独立服务卡片。默认生图保持 ByteCat；切换只影响新任务，已提交任务保留原服务、模型和接口快照。

## 接入方式

- 新服务 ID 为 `cheetah-image2-native`，调用猎豹 `/v1/images/generations`，单张 PNG、高质量，不传 `response_format`。
- 使用独立 `CHEETAH_IMAGE2_API_KEY` 引用，在腾讯云私有环境配置。模型工作台与公开仓库不包含密钥。
- 原 `cheetah-image` 聊天包装继续兼容旧任务，界面明确标注“旧接口”。不会将历史任务强行改为原生接口。
- 图片沿用私有候选保存、受限下载、尺寸验证和独立核对流程；下载失败不等于允许自动重付费生图。

部署工具的生图凭据映射同步支持 ByteCat、猎豹 Image 2 原生、Image 2.5 与旧接口；拒绝未知服务、重复项和任意路径，不再把所有新入口误映射为 ByteCat 密钥。
