# runtime-v47：触摸、关注色阶与完整阶段图

本轮修复手机点击的浅蓝矩形覆盖、小题色阶方向和学生完整阶段线索的坐标挤压。启动、后台材料处理、页面复用沿用 v46，全部动画、透明玻璃、原始数据和导出继续保留；数据整理版本仍为 46，本轮样式更新不会触发已有材料重新整理。

## 修复

- 关闭 WebKit 默认的矩形点击高亮。按钮原有按压缩放、选中状态与键盘焦点保留，输入框的正常焦点不受影响。
- 五档得分率共用低分更深的蓝色，从低于 25% 到 90–100% 逐步变浅。试卷封面、全卷、题目卡、知识点、个人小题、班级热力矩阵及学生作答统一映射，图例同步说明“蓝色越深，得分率越低”。真实零分采用最低档；未知满分、缺失与异常值保留独立的中性表达，原始数字不改写。
- 完整阶段图按考次数量与标签长度保留可读宽度，在自己的区域横向滑动；页面和抽屉不随图表向外撑开。纵轴按数字长度留边，首尾考次留边，手机不再把所有标签强行压入一屏。仅在实际溢出时显示滑动提示。
- 校内排名仍使用表内校排名、数字越小位置越高，缺失保持断点。所有考次与有效节点继续保留，点击节点仍进入相应考次；SVG/PNG 导出完整图形，不只导出手机当前可见的一段。
- 图表区域支持键盘横向滚动，抽屉的左右切换学生快捷键避开图表，避免方向键误换学生。

## 验证

`npm run test:mobile-attention` 使用匿名的 13 考次、四位数校排名与两处缺失数据，检查 320、390、580、1440 像素：考次标签顺序、字号、碰撞与边界，纵轴与排名方向，11 个有效节点与 3 段曲线，页面宽度、触摸高亮、自然动效设置、键盘焦点、横向滚动，以及完整 SVG/PNG 的节点、考次、内嵌字体和尺寸。通过 `AUDIT_BROWSER=webkit` 可以复核 WebKit。

数据单元检查继续验证色阶边界、真实零分、未知与异常、各档文字对比度和排名来源。统一材质检查覆盖各类题目/个人/知识点/热力格，正常整页切换检查覆盖桌面、手机、快速改向与动画收尾。

本轮结果：135 项数据单元检查、3 项统一材质检查、8 项正常整页切换检查通过；Chromium/WebKit 各 4 种宽度的触摸/阶段图检查及完整 SVG/PNG 下载通过；两个引擎的轻量首页、JSON 导入、页面复用、已有材料再次打开与旧任务写入保护继续通过。
