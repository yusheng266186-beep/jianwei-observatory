# 全站多尺寸布局复核（2026-10-18）

本轮检查六个研究入口、学生与学科观察窗、报告组合与纸面预览、训练计划、个性化辅导、试题中心、模型工作台和图示库。延续现有字体、透明玻璃和非线性动画。

## 发现与修复

| 问题 | 调整 |
| --- | --- |
| 窄屏图表标题与 SVG/PNG 操作同排，按钮内部溢出卡片，即使整页没有横向溢出 | 共用 block-head 允许标题与操作换行，操作按钮保留自身宽度并按需换行 |
| 移动报告页头将关闭操作压进25px列，标题和操作拥挤 | 标题单列，预览与设置另排，关闭按钮固定40×40px触达区域 |
| 关闭与方向 SVG 包含路径纯文本，没有真正绘制图形 | 共用图标输出 path，统一上移/下移按钮并保留无障碍名称；增加真实路径回归测试 |
| 报告章节名和编辑、定位、排序工具竞争宽度，长名称被压为逐字竖排 | 章节与工具分行，标题占满可用宽度，工具组允许换行 |
| 手机学生目录13次考试占据约422px高度，将学生内容推得过远 | 考次改为横向浏览栏；390px下约46px高，完整保留考次，选中项自动进入可视区 |
| 训练计划长考次选项越界，底部三个按钮整体挤出左侧，题目区过长 | 考次横向浏览；长标签可换行，底部按钮自适应分行；题目区保留全部题目并在限高区域内滚动 |
| 600px模型工作台的次数快捷按钮四列挤入窄栏，三位数字裁切 | 改为两列布局，保留各档位及原滑轮 |
| 调整窗口尺寸后，选中高亮沿旧几何执行跨布局动画 | 同一选项的布局变化直接同步几何，普通点选与切页仍采用原非线性动画 |

## 校检方法与结果

使用原生内置浏览器实际操作，包含320、390、600、768、820、1024、1440、1920px宽度，并补充844×390短横屏。先检查主页面，再展开二级视图、弹窗与设置；最终在当前构建上保存96组页面与尺寸检查结果，未发现整页或可见文本越界、控件内部横向溢出及操作组重叠。

匿名压力材料包含103位学生、13次考试、1339条成绩、24项数学小题、21项外语小题、长知识点和教师名称、10条计划及6份不同状态的练习。查看和修改界面设置后，全部1339条原始成绩逐项未变；浏览器错误日志为0。无材料首页保留默认展示，在手机、平板和桌面宽度正常显示。

节点检查区分受控横向阅读区域、关闭的折叠内容、PDF透明文本层与页面溢出，并通过截图复核。宽表、完整阶段图和大幅图示继续保留全部内容及横向阅读。以上为本机浏览器的视口校检，不代表已逐一测试所有手机系统、浏览器及实际设备。

491项Node测试全部通过，其中新增共享图标真实路径及可读名称的回归检查。本轮没有调用真实出题模型，也没有修改后端、模型配置、统计口径或导出文档内容。

本机校检留存：`outputs/gemini-training/responsive-global-qa/`（截图、初查和最终结果、成绩核对）、`responsive-global-tests.txt`。匿名材料与校检服务不随生产入口发布。

## 维护规则

- 图表标题与操作组应按容器宽度换行，不依靠隐藏溢出掩盖裁切。
- 报告章节名称独占完整一行宽度，章节操作单独组织。
- 长考次集合保留全部选项；横向浏览栏应自动显露当前选中项。
- 布局重排与用户点选分别处理：重排同步几何，点选保留接续动画。
- 修改共用图标时验证实际几何，不能只检查svg标签是否存在。

源码、入口、构建清单及新哈希资源一起提交；保留既有已跟踪运行资源，兼容仍打开的旧页面。
