# 练习表格与科学上下标修复

核对教师反馈的生物八题练习，保留原始内容，不调用模型重新出题。原始记录及学生信息仅留本机校检区，不进入公开仓库。

## 问题与处理

- U+2082 是 Unicode 下标“₂”。原宋体字库缺少部分科学上下标，导致 PDF 导出被阻止。新增科学字符分片，使用同一授权宋体轮廓构造40个缺失字符，保留 Unicode 原文与文本检索，不替换成普通数字，也不依赖系统字体。两个字重合计6492字节，按需加载；旧字体分片地址不变。
- 第8题原始数据完整，使用竖线分列但没有 Markdown 表头分隔行。三端共用表格块解析，同时兼容标准 Markdown 表格和连续等列的旧数据。单行竖线、公式内部竖线、转义符、代码及列数不齐的文本均保留，避免误识别后丢失内容。
- 网页显示真实表格，手机宽表在容器内横向查看；PDF 使用固定列宽、换行表头、重复表头，单行不跨页切断；Word 输出原生可编辑表格。
- PDF Worker 与字体清单更新版本，输出缓存升级为 v22，避免复用旧文件。已生成练习及审题记录不迁移、不改写。

## 校检

- PDF 保留 CO₂、C₃、Na⁺、K⁺、μmol·m⁻²·s⁻¹ 等字符，未再触发缺字报错；对导出页做本机渲染，检查表格、上下标与分页。
