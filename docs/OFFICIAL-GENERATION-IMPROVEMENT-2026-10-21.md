# 官方通道出题优化：本轮目标与验收（2026-10-21）

本轮执行目标已根据教师最新要求同步：保留视觉、动画与现有能力，让教师更方便地选择训练内容，模型准确落实所选要求，生成、纠错、配图、预览及导出连续可恢复。

## 提示词既做精简，也补足必要要求

- 精简重复、互相冲突、与当前环节无关的指令，不能为了省 token 删除命题要求。
- 加强各科适用的高考题型、内容范围、难度、题数、用时和分值说明。允许新情境与迁移应用，知识与方法不超出所选教学范围和四川适用高考范围。
- 教师明确选择的知识点、训练重点、题型、难度、教学范围和补充要求须逐项落实，不能擅自替换。合理组合知识点与题型，不以机械规则代替语义判断。
- 独立小题、材料题组与子问的计分关系清楚；题头、题干、答案与评分依据一致。各学科阅读、写作、实验、计算等题型分别处理，不能套用统一分值。
- 出题、内容复核、格式修复、图示规划、图示检查分别接收适合本环节的指令；修复须带原稿与具体错误，不因显示问题改动题意和答案。

## 教师流程更清楚、更省步骤

- 检查学生、考试依据、学科、内容、题型与难度、数量与时长、补充要求及生成入口的完整流程。
- 使用易懂中文；常用选择直接可见，可选细节按需展开，合理使用已有自动暂存与教学模板。
- 清楚呈现本次选择与需补充的内容，避免隐藏必填项、重复设置、相互覆盖或点选无反馈。
- 保留全部现有能力、玻璃材质和动效，兼顾手机、桌面与键盘操作。

## 稳定性与交付

- 检查提交、传输、格式修复、内容复核、配图、保存、断线恢复及删除行为。
- 移除无实质作用的拦截；保留安全、题意与答案准确性、教师明确要求及文件完整性检查。
- 将原稿和具体原因交给模型修复，保留已完成内容，避免重复生成与重复计费。
- 核对公式、表格、插图、分值和留白在预览、学生版及教师版 PDF、Word 中的一致性。

DeepSeek 负责范围明确的代码审查和教师端改进；主代理核实发现、整合修改并负责真实调用、导出复查与正式发布。区分确定的 bug 与建议。

使用有来源的真实知识点作多科实测，核对选择落实、题型、难度、计分、图文及导出。验证区分新模型调用、历史成稿回放和静态检查，不以有限样本宣称百分百成功。完成适当回归、构建和发布核对后直接发布正式站，并记录实际结果。
