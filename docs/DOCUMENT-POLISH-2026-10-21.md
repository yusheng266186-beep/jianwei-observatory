# Word与PDF排版及学科计分

本轮在全链路兼容性复查之后，统一练习文档的字体层级、公式比例、表格、页脚和自然分页，并细化各科出题及复核中的题型计分说明。

## 文档排版

- PDF继续嵌入本地思源宋体；Word正文使用宋体，并在字体表中提供macOS Songti SC别名。正文11磅，主标题20磅，题目标题12磅，元信息9.5磅，图注及页脚9磅。
- PDF段落在排版前确定字号，公式和文字一起按该字号计算宽度及基线；不再先按11磅绘公式、再只缩小文字。普通公式从原来的12磅视觉比例调整到实际正文比例；PDF行距依宋体实际升部、降部换算，避免把字体完整度量高度重复乘大，普通正文与混排公式行保持相近物理间距。
- Word保留可编辑的Office公式；特殊反应箭头保留矢量表达，并依据公式下降部设置嵌入基线。元信息、图注、表格中的特殊公式跟随各自字号。
- Word正文采用可自然撑高的最小行距并关闭东亚网格吸附，分式、上下标不会被固定行高切掉；只有纯空白作答行保留明确的物理高度。
- 表格保持真实单元格、重复表头、自动行高、居中垂直对齐和浅灰边框。报告表格的字体别名及垂直对齐也一并补齐，已有密度、方向及字段选择设置保留。
- 长阅读的空行改为适量段间距；教师册区分参考答案、解析和评分要点，长评分列表允许自然续页，不再强行整组挪到下一页。
- 页码统一显示当前页及总页数；保留用户调整后的图片尺寸、原题内容和模型建议的逐题作答空间，选择与普通填空维持小间隔，不增加横线或作答标签。
- Word/PDF文件缓存版本同步更新。旧练习再次导出会使用新版排版，不要求重新出题。

PDF使用嵌入字体；Word保留常用字体与可编辑公式，因此不同Office/WPS版本与本机字体可能产生少量分页差异，二者不强求相同页数。

## 学科题型与计分

云端`subject-scoring.cjs`由出题和学科复核共同使用，通过已有学科模板传递，不增加一个新模型调用环节。依据公开的2025年四川适用试卷建立参考口径，不把历史一套试卷的全部结构宣称为未来年份的固定规定。

| 学科 | 计分说明重点 |
| --- | --- |
| 语文 | 阅读与语言运用区分选择、规范填空及简答；完整材料作文参考60分，片段专项单独说明。 |
| 数学 | 单选5分、多选6分、独立填空5分；部分正确的多选得分明确写出，不机械套用物理漏选规则。 |
| 英语 | 阅读每小题2.5分，完形每空1分，语法填空每空1.5分，七选五完整五空12.5分；完整应用文15分、续写25分。 |
| 日语 | 按新课标语篇及写作组织；阅读2.5分、完形1分、语法填空1.5分；应用文10分、主题写作30分。 |
| 物理 | 单选4分、多选6分，选对不全3分；实验及计算明确小问、步骤、结果和单位。 |
| 化学、生物 | 四川单项选择与非选择题口径，选择通常3分；非选择小问按实际任务配分，不混用其他省的多选。 |
| 历史、政治、地理 | 单项选择与材料分析/综合题分别组织；小问和有效得分点清楚，组合式单选不误标多选。 |

专项题量不需要凑成整卷100分或150分。每个题组、每空和每个小问的分值分别说明；题头、题干、参考答案及评分点一致。作文采用维度或分档，不把互斥的不同等级相加。

修正原先只接受整数分的契约，前后端及Schema均支持正常小数分值。删除所有科目统一5分的示例，示例随学科和题型变化。复核只在确认原分值有误时，声明原因并同步修改`maxScore`及评分点；题号、题型、训练点和原题条件仍须保留。普通合理的专项配分差异不触发额外机械拦截。

此次不会批量重写已有练习的题文、分值或教师确认记录。

## 核对来源

以下以政策原文及试卷本身为依据。部分试卷由公开资料站承载，使用其试卷内容，不采用网站自动生成的题型/总分摘要，也不将模拟卷、合格考或旧四川甲卷混作当前选择性考试。

- [四川省教育考试院2025年实施方案](https://www.sceea.cn/Html/202501/Newsdetail_4130.html)：全国统考与选择性考试范围及总分。

- [2025全国二卷英语试题内容](https://kaosj.com/papers/2025/06/2025-national-volume-2-gaokao-english-paper/)：逐节计分，不使用该站错误的“满分30分”摘要。
- [2025全国日语试题](https://www.jhgk.cn/upload/file/20250829/1756449535767007894.pdf)：阅读、语言运用和两节写作。
- [2025四川物理试题](https://www.jhgk.cn/upload/file/20250708/1751939740833016105.pdf)、[物理试题文字](https://kaosj.com/papers/2025/06/2025-sichuan-gaokao-physics-paper/)：单选与多选不同计分。

## 验证范围

- 860项单元测试通过，包含小数计分、十科学科示例及出题/复核一致性、原题保留、声明后的分值修订和作文分档误报回归。
- 使用先前真实生成的数学、语文、英语和生物成稿，各导出学生及教师Word、PDF，共16份，检查题号完整、文件结构、公式、表格、图片和作答留白。
- Word通过技能提供的`render_docx.py`渲染；测试环境的独立Fontconfig指向已有系统宋体，解决隔离运行环境无法自动发现中文字体的问题，未修改用户系统字体或交付文档内容。PDF用Poppler渲染，逐页核对。
- 上述是现有成稿的实际导出回归，不是16次新的模型生成。旧成稿中的题型、分值和内容保持原样，不作为新版命题正确率统计。
- 本机独立Playwright Chromium未安装，`tests/code-audit.cjs`未能启动；本轮浏览器导出通过内置浏览器实际执行。正式发布仍检查CI及Pages状态。
