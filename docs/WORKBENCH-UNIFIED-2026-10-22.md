# 模型工作台整合 · 2026-10-22

## 当前使用方式

工作台按官方账号、模型配置、配图与额度、鹈鹕测智分区，页内导航可直接到达。账号区统一提供浏览器授权、添加、切换、额度和唤醒；“现有计划通道”和本机助手下载入口已移除。普通浏览器 OAuth 的跨设备回调方式保持可用，设备码仅作为备用。

官方模型服务名称为“OpenAI 官方 · 云端账号”。提供实际运行时目录中的8个型号及各自支持的推理档位。原有 SOL 6.1 / high 选择、生图服务、修复次数以及继承关系保持不变。当前配置的旧 provider 在读取与保存时映射到新通道；历史不可变版本不重写。

每次提交同时冻结出题、图示和校检三个职责使用的官方账号。后续内容复核、修图、格式修复和看图核对沿用任务快照；在工作台切换账号只影响新任务。账号刷新链按租约串行使用，凭据轮换先保存再释放。同账号并行出题会在发出模型请求前等待租约，不因占用直接判失败；其他服务错误不自动重发，不暗中换账号。

## 鹈鹕测智

在模型配置中选好模型和档位，可直接“加入鹈鹕比较”，也可从比较区加入当前选择。每轮选择1–8个模型，同一绘图要求依次发送给各模型。默认要求绘制骑自行车的鹈鹕，也可补充描述。

结果展示实际 SVG、模型原文、第一段正文的接收时间、总耗时和官方返回的输入/输出 token。缺失统计显示“—”，不会填造零值或智能评分；绘图比较不能代替学科出题质量评估。等待时展示收到的正文，原文展开状态在轮询中保留。可停止后续调用；已完成结果保留。离开页面后云端继续，重新打开可从最近20轮记录恢复。

浏览器只以图片显示 SVG，原文按文本转义。允许注释、内部渐变、内部定义引用，不执行脚本、外部引用或 foreignObject。两份真实 SVG 首次预览暴露了对正常注释的误拦截，已修复，并直接使用原有成稿重新显示，没有再次生成。

## 代理更新

同步本地更新后的 VLESS / Reality 出站配置到现有 API 和 Worker。只取当前代理出站，不迁移本地公开监听端口和其他系统路由。云端继续只监听私有回环端口，保留 Reality 公钥校验和目标 HTTPS 证书校验。

先创建无触发器临时函数进行两轮连接测试：官方 API 均返回预期的未登录401，授权发现接口均为200，TLS通过；临时函数确认删除。随后更新两端代理代码和配置，校验层、角色、内存、超时与网络均未改变。没有把代理凭据、OAuth令牌或TOTP原始码写入仓库。

## 实测与验证

- 本地官方适配器用当前云端账号进行真实 SOL 6.1 / medium 调用，约11.9秒返回正确结果，正文增量和用量可读。
- 腾讯云实际生成数学3题，当前 SOL 6.1 / high，经内容复核完成，无手动续跑。
- 腾讯云实际比较 SOL 6.1 / medium 与 Luna / medium：总耗时约64.9秒和19.7秒，首段正文约17.3秒和9.1秒；两者均返回可预览 SVG。这是单轮样本，不表示长期速度或成功率。
- 旧计划授权接口在正式配置下返回410，公开模型目录不再含旧 provider；旧凭据记录保留在私有存储作审计，未复制到新账号通道。
- 1016项单元测试通过；覆盖全部职责账号冻结、并发租约、比较串行分发、恢复、取消、部分失败和SVG隔离。桌面、390px与320px界面检查，320px无整页横向溢出，切换生图选项前后按钮尺寸一致。
