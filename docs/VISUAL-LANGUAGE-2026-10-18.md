# 全站视觉与交互协调（2026-10-18）

本轮按页面、控件、内容和动效逐层复查，统一研究台与模型工作台、图示库的视觉语言。透明玻璃、页面横移、窗口进退、数据颜色和全部功能保留；不更改原始成绩、排名或云端模型配置。

## 当前视觉规则

`styles/visual-language.css` 是构建顺序中的最后一层共享协调规则，承接原有布局与材质，不替换各场景的信息结构。它也由两个独立页面引用。

| 对象 | 统一规则 |
| --- | --- |
| 文字 | 展示标题保留宋体气质；界面和数字沿用本机打包的阅读字体。辅助文字、指标说明、表头与表格数据有明确层级 |
| 材质 | 主内容用清楚的浅色阅读面，选中态用同方向浅蓝透光；页头、Dock与浮窗保留原玻璃层次 |
| 形状 | 面板18px、内嵌12px、常规控件10px、窗口22px；数据图示本身不强制改形状 |
| 输入 | 搜索、日期和自定义下拉共用轻边缘与内侧光，不新增外部粗框。数字步进沿用相同边缘 |
| 操作 | 关闭图标及表格方向使用共用SVG线条，保留可读名称；禁用状态不触发按压或悬浮移动 |
| 展开 | 移除原生三角、加减号与字符箭头叠用，统一旋转细箭头及260ms可中断展开过程 |
| 表格 | 表头与固定标签保持不透明；文字与数字12px，整行悬浮反馈一致，完整字段继续保留 |
| 移动端 | 页头纯图标操作与混合文字操作分两种稳定布局；控件自然换行，主要图标40px，内容不挤入标题 |

学科得分色阶仍独立承载数据，不使用通用选中底色覆盖分数块。静读、系统减少动态、纸面及减少透明度偏好继续尊重用户设置。

独立页面增加同源字体许可与本机字体样式，不引入字体CDN、图标库或其他远程依赖。空白首页仍用关键样式直接绘制，不等待完整研究模块；其校徽蓝、按钮和页头玻璃与研究台协调。

## 本轮修复的细节

- 试卷封面原来只有两三个得分项时会将色块拉得很宽；现在保留空轨道，按紧凑格显示，题号、比例及知识点分层，不删除得分项。
- 资料索引原来标题、编号、数量的次序与空间不稳定；改为标题与编号同排、数量与说明顺次排列。修正旧绝对定位残留，编号不会飘出卡片；桌面减少无意义大留白，手机保留说明。
- 窄屏页头混合操作不再压向标题；学生目录的数量与视图选择分行组织，避免“找到103位学生”的末字被挤到下一行。
- 学生观察窗把教学出口独立成组，整理次级操作的留白；320px时最后一个教学出口占满整行，避免留下半行空缺。功能全部保留。
- 输入、日期、自定义下拉、步进、滑轮、图表小操作和表格箭头的圆角、边缘及反馈协调；触屏不保留鼠标悬浮位移。
- 模型工作台每日次数卡片不再收窄到栏目的一侧；卡片与同列对齐，滑轮仍保持紧凑，六位数不被挤压。
- 图示库的标题、筛选、图示卡、搜索及大图浮窗与主站协调；手机大图保留640px精细画布和内部横向阅读，不压缩结构或使整页溢出。
- 数据口径的长标签允许换行，窄屏单列阅读；展开后的旧减号也移除，不与新箭头叠用。

## 共用展开生命周期

`app/ui/disclosure-motion.js` 接管普通details的用户展开操作，研究台和独立页面共用。原实现仅动画第一个内容节点，多段内容可能瞬间跳出；现在根据整块区间高度展开或收起，完成后恢复自动高度。

快速重复点击以最新意图为准，旧动画结束不会重新打开或关闭区块。程序调用 `openDisclosure` 会取消过时的关闭；收起时将内容内焦点移回摘要。摘要中嵌入的按钮、链接、表单与可编辑区保留自身操作。缺少动画接口、异常或减少动态时仍可正常开关。需要原生行为的特殊区块可标记 `data-native-disclosure`。

没有缩短或删除既有页面切换、窗口进退、滑轮或图表动效。页面横移仍为400ms，主站页头和Dock实际保留透明模糊。
