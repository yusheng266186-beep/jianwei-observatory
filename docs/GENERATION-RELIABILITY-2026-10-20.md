# 学科复核、三维翻折与失败恢复

## 针对上一轮问题的修复

上一轮十科实测的数学空间图不正确，物理图示核对发生已接收响应头后的断流；另有多科答案与评分问题。不能把这些都归为中转稳定性，也不能仅凭格式通过保证内容正确。

新练习的流程为：出题并保存原稿 → 必要的格式保真修复 → 独立学科复核 → 必要的图示规划/绘制/图题核对 → 教师审题 → PDF或Word。学科复核默认使用提交时冻结的出题模型及强度；工作台的格式校检模型配置保持原有职责。已有任务保持其原版本，不后台改写已生成的题文。

### 学科复核

- 十科分别核对可求解性、答案、选项、评分与材料证据，重点涵盖限字与多解、物理相对运动端点/量纲/电阻率、化学指示剂终点与守恒、生物对照实验与机制归因、地理方位和昼夜、历史政治分小问评分。
- 窄范围程序规则复查明确分值合计、含标点限字、海岸方向与已知电阻率倒置式；未知模式不猜测、不自动改写。规则结果先交给复核模型，修订后再检查。
- 复核与格式修复是两套独立职责。格式修复不能改题；学科复核可给出明确的局部内容修订，但不能改变题号、题型、难度、训练点、分值和训练用时，不能删掉必要图示。每处修订有原因与实际改动字段，并重新通过相同文档契约。
- 最初原稿、复核响应及修订记录分别保存。网页显示审稿阶段、模型实际返回的内容和最终修订说明，不把模型批准当作教师已审题。
- 复核也使用独立事件和截止时间。断流、关闭页面或保存暂时失败不会要求重出题文；明确继续时只重试当前复核。已收到的完整候选可只恢复存储，避免重新调用模型。
- 无法确定、尚无明确错误的建议保留供教师确认；确定影响作答且未能修订的问题阻止交付。不编造条件，不把失败标记成可交付。前次诊断与失败候选只作为后续复核上下文，始终保留最初原稿为基准。

### 三维图示

新增 `geometry.model.id=spatial-frame`：`dimensions:[]`，4–12个三维 `vertices` 与同序 `labels`，`links` 使用从0开始的顶点下标及明确的 `hidden` 虚线标志。程序验证有限坐标、非共面性、重复/退化棱、图连通性及标签，再统一投影成SVG，网页、PDF、Word共用。

这避免了只调整二维三角形坐标来冒充翻折。三维坐标仍须符合原题条件，遮挡标志仍须正确，图题核对继续执行；非共面检查不能单独证明长度、角度、命名和答案正确。

### 修图与连接错误

以前图题核对对任何失败都可能附上“JSON格式错误”并自动再发，现仅对明确的 `FIGURE_REVIEW_INVALID` 做一次核对格式重试。断流、鉴权、限流、超时不走此分支。已发送请求后的网络断开无法确认上游是否计费，不能无限静默重发。

矢量图有最多两次自动定点修正，次数与核对格式重试分开；之后仍可由教师明确继续。不是生成次数限制，也不会修改每日额度。每次修图同时提供上一版失败图及累计反馈，原题条件保持不变。核对连接失败后继续时复用原图，只重新核对。需要付费重画位图的情形仍要求明确操作。
