# 练习跨页面一致性打磨

本轮聚焦多标签页、返回页面与文件导出的版本一致性。保留玻璃材质、动效、字体、模型原稿和现有功能，仅发布独立预览分支。

- 练习改为按载入基准、当前修改和数据库最新记录进行三方保存。未修改的旧记录不会整批覆盖其他页面的新题干、图示排版、审批或练后结果；新建和删除也在同一 IndexedDB 事务中核对。
- 题目、请求、图题复核、质量确认与审题状态作为同一文档版本。两个页面同时修改这一版本时停止覆盖，保留当前修改，提供“另存修改副本”和“载入已保存版本”。副本有独立编号，显示副本标记，必须重新审题；保留原始来源以供后续单独绘图，不把副本当成新的云端生成任务。
- 删除前同步记录，跨页面保留完整删除队列与12秒撤销期限；其他页面的后台同步不能提前删除仍可撤销的云端任务。修改副本不重复删除原云端任务。
- 后台任务按分组版本和终态核对，旧的进行中快照不会回退已完成状态。流式输出仍留在内存，不扩大本地持久化体积。
- 保存完成时保留记录对象身份，维护异步轮询的引用；事务等待期间继续输入的内容保留原基准，下次仍能正确检测冲突。
- 重新进入已保存练习、同步试题中心和关闭窗口时核对最新内容。Escape 遇到保存冲突时保留窗口与修改，不能把失败当作保存成功。
- 同源同工作区标签页使用不含题目和学生信息的修订信号。关闭的窗口刷新列表，打开的窗口只在当前文档或练后结果变化时提示；其他任务进度更新不打断当前审阅。
- 审题前、导出前、导出完成准备下载时均核对文档版本。只有当前实际预览过并已审定的版本可输出；出文件期间又改题则要求重新核对，不能下载混合版本。练后保存同样使用当前题目与反馈版本检查。

验证：370项 Node 检查；匿名双页面实际验证旧页关闭不覆盖、并发修改保留原稿和副本、审批与导出禁用/恢复、重新打开与同步。实际导出的学生PDF和Word均为两页，逐页渲染核对，并确认包含当前审定题干。移动端边界、截图和实际导出核对记录保存在工作区 outputs/gemini-training，使用本机隔离端口4198的合成材料，不使用真实学生信息或外部模型调用。
