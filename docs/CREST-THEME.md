# 校徽色系与内容密度

页面身份、交互状态与统计图使用统一的蓝白色系。校徽原图保留，界面撤掉原有浅金、米黄、棕色、灰绿及额外橙色。材质继续使用透明玻璃，文字与数字保持清晰。

## 颜色与状态

- 深蓝：校名、标题、主要操作、当前考次和选中班级。
- 浅蓝与白：背景、玻璃面板、选中底板、数据刻度。
- 灰蓝：辅助文字、负向变化、低得分率；负号与标签仍明确表达语义。
- 缺失与真实零保留各自的数值和颜色说明，不用缺失材料补齐视觉。

三个样式层同步更新，避免下层规则残留旧颜色。主要操作与选择状态使用共享CSS变量。`app/ui/palette.js` 提供图表色板，趋势、分布、比较、达线标尺和逐题预览沿用一致的颜色；SVG内写入明确颜色，独立SVG/PNG导出保留配色。

## 密度和布局

- 卡片按实际内容确定高度；学生、学科、题目与摘录网格不因邻居展开而拉高所有卡片。
- 试卷档案使用自适应列宽，三个或两个卡片填满一行；单张试卷将基本信息与逐题预览并排，在手机上回到纵向布局。预览最多展示前12题，题号、有效作答、均分与满分来自当前试卷实际记录。明确满分时显示得分率，满分未知时明确标注均分；真实0、未填作答和未知满分分别保留。
- 空跟进取消大号装饰及强制高度；手机将状态和提示并排，已有跟进记录继续使用看板与拖动。
- 资料导入与当前工作区合为同一玻璃面板，两侧按内容排列，收紧导入标题、统计与操作之间的距离；增加当前成绩记录、有效线口径与试卷题库覆盖数。
- 班级单张任务卡占满当前空间，并在桌面将班级身份与两类任务并排。完整原表继续保留。
- 班级小地图与小题地图自适应列宽，取消固定空卡高度；四表入口、学科卡片和总览间距收紧。

空白工作区仍只展示导入入口与独立折页图形。真实成绩与学生身份资料只在当前浏览器处理，检查材料使用匿名数据。

## 检查范围

逐页审阅六个研究场景、四表入口、学科观察窗、试卷与逐题卡片，以及通透/纸面模式。320、390、820与1440像素宽度检查整页溢出、单张试卷重排、卡片内部最大间隔与展开邻居是否被拉高；检查真实0、全空作答和未知满分在预览与完整试卷中的一致性。沿用完整界面、动效中断、逐层返回、报告和图表下载的检查流程。

本轮数据回归23项、浏览器流程29组、响应式细节5组、证据与图表导出4组、目录3组均通过。40个应用模块静态检查无错误。布局专项使用匿名材料检查六页在四档宽度下的内部间隔、单张试卷宽度与展开邻居高度；新增预览的0分、缺作答、未知满分与完整试卷一致。完整界面检查覆盖18个功能组，并补齐材料快捷筛选与总分填写状态的按钮覆盖。

最终独立动效回归25组全部通过，覆盖快速导航、抽屉中途退出、弹窗连按Escape、卡片连续展开及图表导出。完整界面和补充目录检查合计1301个观察视图、3076次点击、109种命令、9类表单，应用处理的命令无遗漏；各次检查均使用匿名材料。
