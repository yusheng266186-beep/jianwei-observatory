# 教学跟进：训练与复核日程（2026-10-18）

本轮修复日期筛选漏掉复核、逾期误报和页面/报告排序不一致，保留原有玻璃材质、动画、教师计划状态与原始成绩。仅调整前端，不变更云端模型或认证配置。

## 原有问题

- “今天／本周”只检查训练日期，较早训练、今天需要复核的学生不会出现。
- 日程仅按训练日期分组，复核日期只能在卡片内寻找，无法按复核当天安排工作。
- 逾期判断未排除已有实测或复核结论的计划；没有复核日期时又借用训练日期，容易误报。
- 日程先比课节、再比时刻，报告使用另一套规则；旧时段残留的课节字段也可能干扰排序。
- 日期缓存使用设备时区，与页面中国时区不一致；跨午夜或休眠返回后没有主动更新今天。

## 当前行为

`engine/training.js` 统一生成训练与复核两类安排，筛选、日程和时间标签使用同一份判断。

| 入口 | 判断与展示 |
| --- | --- |
| 今天／本周 | 任一训练或复核日期匹配即选中计划；本周按周一至周日 |
| 按日期 | 不同日期分别出现，同一天的训练与复核合并为一张卡片；日期筛选只列匹配日期 |
| 待安排 | 未完成计划缺训练日期，或跟进中、未记录复核结果且缺复核日期 |
| 逾期待跟进 | 待开始训练日期已过，或未完成且尚未记录结果的复核日期已过 |
| 已记录复核 | 有合法实测题数（包括0/5）或教师复核结论，不再按未复核逾期提示 |
| 已完成 | 不列入待安排与逾期；全部时间中保留历史记录 |

缺少复核日期不推算逾期日期。跟进中、复核约定在未来的计划，不因训练日期已过误报逾期。计划状态继续由教师设置，不会因填写结果自动变为“已完成”。

每个日期内先列有具体时刻的训练，按实际分钟排序；未定具体时刻的训练按早读、课内/课间、午间、自习等顺序排列，课间接在相应课节之后；复核列在当日训练后。未提供复核时刻，不编造学校作息。日期上方明确说明排序规则。

筛选数量按唯一计划计数，尊重班级、状态、检索条件；日期组数量按当日安排计数。同一计划在两个日期出现时，备注编辑即时镜像到另一张卡片，保存仍只有原来一条计划。不同日期卡片使用独立动画键，避免重排认错节点。

手机筛选自然换行，保留44像素点击区域；卡片用轻量标签区分今日训练、今日复核和待跟进事项。日期组已有日期时，训练卡片只强调课时、时刻与时长，减少重复文字。无匹配结果可“一键查看全部跟进”，不改变下方临界名单条件。

打印报告使用同一训练排序，在原有六列表格的“训练与复核日期”中同时保留两类日期。章节明细、PDF 与 Word 共享报告数据。保存计划补充时刻合法性检查。

页面缓存和日期刷新统一按中国时区：午夜更新，重新聚焦或从后台返回也重新检查，仅在日期改变时使页面缓存失效。正常切换动画和材质保持不变。
