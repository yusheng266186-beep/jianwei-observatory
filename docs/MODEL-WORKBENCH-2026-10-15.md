# 模型工作台

独立入口为 `model-workbench.html`，资料与报告右上角也有入口。使用现有 TOTP 动态验证码，访问会话保存在当前标签页会话中。正式站与北辰服务均未修改。

## 已接入配置

从北辰私有交接库当前 `tools/api-providers.json` 与 `tools/model-profiles.json` 同步 9 组服务、135 个模型选项，保留各模型的请求协议、思考参数与输出预算；加上本项目现有 Kimi Code K3、ByteCat Gemini，共 11 组服务、137 个选项。复杂插图继续独立使用 GPT Image 2 的 Web 中转接口。

工作台支持服务切换、模型搜索、模型对应思考档位、连接测试、云端保存、最近 8 次切换记录及选回历史配置。Kimi 保持已验证的 max，Gemini 保持已验证的 high，北辰模型按原适配表提供相应档位。

所有实际调用均在隔离的训练 worker 内完成。HTTP 函数与网页只持有“服务已配置”清单，不持有上游 API Key。服务地址和凭据引用不能由出题请求指定。真实应用 User-Agent 保持不变。

## 保存与任务行为

- 控制数据位于私有 COS `training-control-v1/`，不进入试题对象的 14 天清理规则。
- 每次配置写入下一个不可覆盖的版本对象；预期版本不一致或并发竞争失败返回 409，页面重新同步。
- 接受出题任务时冻结服务、模型、档位、协议、适配参数与凭据引用；工作台后续切换不影响原任务，不触发自动重试或跨服务回退。
- 连接测试是独立云端任务，刷新页面可恢复查询；最近测试结果保存在控制区。测试每日默认 20 次，与正式出题额度分开。
- 预计生成时间按服务、模型、思考档位分别学习，不混用不同中转站的速度历史。
