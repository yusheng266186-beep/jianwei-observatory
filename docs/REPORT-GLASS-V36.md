# 报告、排名和玻璃材质修正

校内排名是同一考次、同一科类在学校范围内的原表名次；班级排名和联考市排名分别展示。排名不因网页筛选重新计算。

参考质量慧析的 `校赋名／校原名`、`市赋名／市原名` 列名约定，补齐排名识别与赋分名次优先级。交接表的历史块复用了总排名表头，第十列在部分考次实际上存放班级名次；针对这份表格的明确模板恢复对应列，独立的平面表及明确标注班排的表继续按自身列名读取。保留的原始记录核对了 3655 条匿名示例成绩，修正资料通过不含姓名、学号或识别码的行位置、考次、班级、双总分指纹匹配。更改成绩或行位置后不套用另一记录的名次。

学生研究、原始视图、报告与导出采用一致的校内排名。已有教学报告打开或汇总导出时从当前成绩重建，保留教师备注、保存身份、日期和内容选择。未能与原始材料关联的名次使用空值，技术排查文字不进入读者报告。

PDF 采用开源思源宋体 SC，内嵌实际字形；Word 的中文、英文、数字均指定宋体。报告常用字库约 292 KB，其余字形按 256 个 Unicode 位置分片，并且只加载实际使用的字重。空闲时提前加载常用字，报告入口提前准备后台排版组件。跨页面和工作线程共享缓存与下载锁。小字库统一使用标准 CFF FDSelect 格式 3，修复合并题号连接符在后台排版器中的兼容问题。

学生报告首屏以六项指标突出总分、校内排名、班级排名、特控与本科距线及重点训练题。阶段表分列校排和班排；正文使用宋体、统一章节标题、重复表头和页码，临界分差保留黑白可打印的重点标记。Word 也使用重点指标区。

透明玻璃用于顶栏、Dock、观察窗口和范围控制区域；阅读卡片采用透光底色与同方向高光。批量证据卡片不重复添加实时背景模糊。清晰纸面偏好、减少透明度和系统高对比模式继续可用。

手机报告入口使用允许收缩的网格，报告窗口同时约束宽度与最大宽度，工具栏和底部操作允许换行，纸面适宽使用实际内边距计算。已检查 320、360、390、430、820 像素宽度的入口、设置、纸面与全屏阅读。PDF 输出维持 A4。

字体源：Adobe Source Han Serif 发布分支，授权保存于 `assets/report-fonts/LICENSE.txt`。构建脚本从 `.audit-output/report-font-sources/` 读取 Regular、SemiBold 原始 OTF，发布内容只含子集。原始字库、工作表、姓名及身份凭据不进入新的修正资源。

验证：100 项单元测试；实际 PDF、Word、罕见字、合并题号、下载与预览字节一致性；五档移动布局；六板块玻璃材质、数据色阶与阅读偏好；后台字体等待时关闭窗口和继续操作。
