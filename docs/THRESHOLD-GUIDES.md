# 分数线与分布图

2026-10-12，年级和班级的总分分布同步使用新的分数线样式。网站入口始终是 https://yusheng266186-beep.github.io/jianwei-observatory/ 。

本科使用中蓝虚线，特控使用深蓝实线，两者保持校徽蓝白色系。分线增加白色衬边，以固定屏幕线宽呈现在柱子前面；柱顶人数另置于最上层，避免被线覆盖。分数线后的淡蓝区间提供边界参照，不使用额外的橙色或红色。

标签按照实际分数从低到高排列，并用连接线指向真实坐标。相邻标签根据实际字形排开，空间不足时分行。每个标签同时显示当前图中有效总分的达线人数，计算包含恰好达到有效线的成绩，不把缺总分当作0。分数保留小数。有效线超出本图分布范围时显示说明和边界方向，不在画面内伪造分线；两条有效线同分时指向同一坐标。

手机保留13像素主标签、12像素人数和固定线宽，柱图维持可阅读的高度。全部区间的人数保留，包括真实0人；密集数字采用不同高度排开。横轴只收疏重复刻度，区间及对应学生范围继续完整保留。点击柱子、分线上柱子的区域或人数，以及键盘激活，都进入同一个分数区间的学生目录。标记层不拦截柱子的点击。

SVG和PNG下载保留实际布局、分线、区间底色与达线人数。未导入材料或者没有有效总分时继续显示空状态。
