# 全局非线性动效 · 2026-10-23

本轮按用户要求统一打开、关闭、切换、滑动、点击、停留和选中的动效。从已有的整页横移与选中底片弹簧出发，把其他交互纳入同一套节奏，补齐过程中断、异步内容和浏览器差异的边界。

## 设计语言

动作有明确的起步、推进与收束。位移采用临界阻尼：从静止出发不弹跳，接近目标时平缓减速；连续改向继承当前状态。按钮、菜单、窗口按尺度安排时间，不让所有东西同时漂移，也不延后内容、输入或提交反馈。

| 场景 | 节奏与行为 |
| --- | --- |
| 按钮按下/松开 | 按下快速压实；松开用弹簧自然收束。普通按钮约1.4%压缩，大卡片更轻，图标稍明确；不改原字号或布局尺寸 |
| 悬停、颜色与焦点 | 160–220ms公共曲线；保持原有玻璃层次，触屏不依赖悬停；键盘焦点保持清楚 |
| Dock、标签选中 | 底片移动与大小接续，文字原生尺寸；连续改向承接当前位置和速度 |
| 整页切换 | 保留整页水平运动、方向和可见退出层，最后一次操作决定结果；结束回收全部临时层 |
| 局部内容切换 | 220ms轻量进入，仅处理当前可见内容；导航和输入保持可用，不重播整页动画 |
| 窗口、抽屉 | 通常340ms进入、180ms退出；抽屉沿水平方向，普通窗口轻微抬升。共享生命周期处理关闭、重开、焦点及暂停回收 |
| 日期、选项菜单 | 220ms进入，保持触发位置关系；退出完成后隐藏，重开可接续 |
| 折叠 | 280ms高度过渡；反向从当前高度开始；内容长高或换行时重新测量，以220ms接向新高度 |
| 图表提示 | 鼠标停留140ms后出现，键盘立即反馈；160ms显隐；无关导航滚动不打断正在阅读的提示，Esc可关闭 |
| 通知 | 220ms进入、160ms退出；退出前不先隐藏顶层；替换通知承接当前帧，旧回调不能隐藏新消息 |
| 程序滚动 | 章节、回顶、抽屉定位、宽表与趋势图共用阻尼模型，最长900ms保护；连按累计目标，主动滚动立即接管 |

匀速旋转的加载标记保留匀速运动，等待呼吸使用对称节奏。真实触摸/滚轮、图示拖动和数字滚轮吸附继续直接跟随输入，不人为拖慢手势。数据值不做虚构的计数增长，PDF/Word成稿及模型HTML内部的教学动画保留自身含义。

## 实现与边界

- `styles/motion.css` 汇总正式曲线、时长、按压和减少动态规则，主站与独立页面共用；空首页直接复用这份CSS，不新增启动脚本请求。
- CSS支持 `linear()` 时使用阻尼采样曲线，旧引擎使用三次贝塞尔回退。原生页面/选中/按钮弹簧采样实际轨迹；匀速关键帧时间轴不等于视觉匀速。
- 修复WebKit可能在主题样式就绪前固定动效参数的问题：交互挂载后重新读取正式参数，双浏览器直接核对实际动画曲线与CSS定义一致。
- 按压使用事件委托和独立scale，与既有hover、Dock位移组合；取消、失焦、后台和静读变化会清理状态。正常静止时不保留临时缩放或图层提示。
- 重绘排除按压标记对命令身份的影响，保留同一控件、焦点和持有中的压缩值；声明式样式更新仍正常生效。
- 折叠只观察内部元素，避免观察正在动画的外框导致尺寸反馈循环；过期动画不能提前完成新的高度过程。
- 内层文字、节点或样式变化会主动复核布局尺寸，补齐首次ResizeObserver投递前的变化；按压缩放不改变布局尺寸，不会反复触发高度动画。
- 章节定位会接管目标及祖先折叠的状态，取消正在进行的关闭，避免刚定位的内容被旧动画再次收起。
- 程序滚动只在活跃期间使用共享帧队列。其他恢复操作改变位置、内容离开、窗口变化或用户输入会取消旧意图，结束后没有常驻帧回调。
- 窗口退出期间不可误触；重开从当前可见帧继续并恢复交互。独立预览在退场完成后才释放iframe，避免内容先消失留下空壳。
- 系统减少动态和本机静读偏好覆盖首页、研究页及独立页面；过程中启用偏好也能正确完成状态。保存失败时仍保留窗口与最新输入。
- 不动画化背景模糊，不关闭现有玻璃。位移、透明度和缩放主要交给浏览器合成；高度变化只用于必要的折叠布局。

## 验收

新增 `npm run test:global-motion`，在Chromium与WebKit使用正常动画、匿名材料与模拟服务，覆盖320/390/1440宽度和触屏。检查实际曲线、按压/松开/取消、键盘操作、场景快速改向、选中底片、局部切换、折叠重定高度、程序滚动及中断、各类窗口、通知替换、悬停/键盘提示、独立预览和静读。

单元回归补充主题延迟到达、折叠异步高度、滚动连续意图/制动/中断/共享队列/范围与释放。另执行原12步流程、键盘视口、备份恢复、前三轮可靠性专项、完整练习流程、1236人/14832条成绩/5000份练习的压力场景，以及十科学生/教师版40份PDF/Word固定成稿回放。CI加入双浏览器全局动效专项并归档失败截图与检查结果。

`npm run profile:motion` 使用510人、3060份小题作答和146题的匿名材料，对旧构建与本轮工作构建的桌面和手机模拟做受控对照；记录帧间隔、长任务、内容可见时间、收束时间和连续导航接受情况。它描述本机无截图录制的Headless Chromium表现，不代表所有真实设备的帧率。最终数值、逐项回归和同提交CI/Pages/线上文件结果保存于本轮发布回执。

本轮不调用真实模型、不部署云函数。线上发布继续直接维护main，将已部署且核对线上字节的构建登记为兼容资源图，保留旧哈希依赖；最终CI验收另以对应提交的检查结果为准。
