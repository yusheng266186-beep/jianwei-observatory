# 首页与表格导入优化 · 2026-10-16

首次打开先呈现可以使用的首页，保留透明玻璃、原有字体轮廓和动效；在需要研究功能时才加载完整主题与分析组件。用户确认暂时没有域名，本轮只发布现有预览分支，不创建镜像或新的云资源。

## 首次打开

- 首页关键 CSS 直接随 HTML 返回，消除首页样式的一次请求等待。完整主题保留，首次操作或恢复已有材料时再加载。
- 网页校徽使用 192 像素版本：1,198,718 → 19,817 字节。报告使用的原始校徽保留。
- 首页使用原有 OFL 显示字体的公共界面文字子集（5,684 字节），完整研究字体、打印字体不变。
- 首次访问不提前下载报表字体、PDF 组件或所有研究页面；导入时优先准备当前页面。研究页面的后台预热和交互动画保留。
- 按需打开时并行预加载主程序的静态依赖，减少高延迟网络下逐层发现依赖的等待。
- 首页增加三步研究路径、文件选择与恢复进度提示。慢网提示保持首页可见，不再以短计时器替换整个首页。

## 表格导入

- 单文件、带内容哈希的读取 Worker，避免逐个请求解析器依赖。
- File 直接交给 Worker；文件字节不再先在 UI 线程读取和复制。
- Excel 目录只读取一次；通用表格的列对应复用已解码行，不再次解压工作簿。
- 同批多文件复用同一个读取 Worker 和已加载表格库，批次结束后释放。
- 学生姓名与考次班级使用增量索引，替代每条小题对所有学生及成绩历史的重复扫描。匹配范围与同名冲突规则保持一致。
- 合并完成后的 Atlas 索引在 Worker 内生成，交接时保留与数据的记录引用。
- 加入工作区时明确显示索引与本机保存状态；再次打开直接恢复本机数据，不重新解析 Excel。

## 验证与边界

350 项 Node 检查通过，包括 JSON 零分/缺失、CSV/Excel 映射复用、错误重试和多文件隔离。浏览器完成空白首页、320/390 像素小屏、JSON 导入、875 人/13 考次 Excel 导入、保存与重新打开；重新打开没有请求 XLSX 或导入 Worker。

同一份 2,889,611 字节匿名工作簿（875 人、13 考次、11,375 条成绩与 11,375 条小题学科记录），本机三次解析中位数由 1,155 ms 降为 327 ms，结果逐项一致（排除导入时间戳）。这仅是本机解析阶段测量，不是国内网络或手机端完成时间保证。

空白首页实际请求清单按唯一资源去重，并计入 HTML，未压缩资源体积由 2,438,659 降为 59,367 字节，减少 97.6%。统计不含本地验收面板，也不将缓存命中重复算为下载。这是资源体积，不是测速带宽或公网首屏时间。

验收记录位于任务输出目录：entry-browser-checks.json、entry-import-benchmark.json、entry-resource-profile.json、entry-desktop.png。

## 后续国内镜像

可在具备域名后配置独立的腾讯云 EdgeOne Pages 前端镜像，复用现有腾讯云出题服务；按实际部署域名增加精确 CORS 来源。大陆节点按腾讯云当前要求需要已备案的自定义域名。官方说明的默认 Pages 项目域名存在地区及预览有效期限制，不能把临时链接当作长期国内镜像。COS 新建存储桶的默认域名同样不能作为直接呈现网页的长期方案。

切换域名后浏览器本机存储相互隔离，需要通过完整备份迁移已有材料。出题任务私有存储桶不用于公开托管前端。
