# 跟进控件、滚动稳定性、小题材质与自选报告

固定网址：https://yusheng266186-beep.github.io/jianwei-observatory/

## 跟进控件

日期、复核日期和具体时刻全部使用本地自定义面板，不再调起浏览器原生日期/时间菜单。

- 月历按周一开始；自定义年份和月份选择，跨月、闰年、今天/明天、清除、手动填写和数字键盘8位输入均可用。
- 复核日期以训练日期为起点，早于起点的日期不可选；非法日期不写入草稿。
- 24小时时间选择支持小时、5分钟快捷项、任意精确分钟和清除。仅“应用时间”后更新计划，关闭不会误提交。
- 题量、目标得分率和时长使用自定义加减控件；键盘可直接填入，边界值受限制。
- 面板按可视窗口定位，避开边界；支持键盘、Esc分层关闭、焦点回到触发按钮、点击外部收起，以及减少动态/透明度和纸面偏好。
- 旧简单记录只在编辑草稿中补建议题目、任务和训练默认值；保存前不改写原记录。
- “安排题目与课时”是卡片内有对比度的学校蓝主按钮，名单中的编辑按钮同步强化。

## 滚动

复现脚本在40次文档滚动中记录到40次重复`data-scrolled`写入。现在按动画帧合并，只在状态变化时写入，相同路径为1次。导航定位属性同样只在当前章节变化时更新。

背景移除`background-attachment:fixed`，固定玻璃导航保持稳定合成层。大块阅读面板入场不再整体降低透明度，避免滚动时出现明暗跳变；小卡片保留轻微位移。实际浏览器的GPU/绘制表现仍可能随设备变化，这些检查针对可复现的重复更新与视觉路径。

## 小题玻璃材质

五档得分色阶、未知/异常、原分和比例保持原口径。封面、全卷、逐题卡、个人与知识点卡共用渐变、高光、深色折射和透光边缘。小题不额外叠加逐卡模糊层，以免长卷滚动建立大量合成层。高得分率深蓝使用受控高光和浅色文字；选中、悬停不改变数据颜色。纸面与减少透明度模式仍简化显示。

## 自选报告

报告进入组合与预览后，可以：

1. 选择概况与对照、分层补弱、试卷与知识点、训练跟进等快捷组合。
2. 勾选任意章节，调整章节顺序；班级/学科原分附录可随时加入，默认不勾选。
3. 选择每章字段，按姓名或内容筛选要导出的记录。
4. 修改标题，选择是否附加教师判断和材料信息。
5. 实时查看全部所选内容的黑白纸面，或分页检索章节明细。

PDF、Word、Excel与打印共用`selectedReport`投影。明细检索只用于浏览；导出行筛选明确标记并用于文件。选定字段、筛选记录和章节顺序不会偷偷扩回原始材料；自定义标题也用于文件名。PDF/Word真实分页，纸面预览显示完整内容，屏幕分页并非逐页PDF渲染。

保存摘录时保留原始材料及选择配置，之后可恢复取消的章节/字段。合并摘录导出会先应用每份报告的选择，再允许进一步组合；取消的教师判断不会混入文件。

## 验证

- `npm test`：日期/时间边界、组合投影、原数据不变、旧记录编辑兼容、跨出口一致性，以及原有数据口径。
- `npm run test:plan-controls`：1440/390/320像素的实际点选、月份/年份、闰日、无效输入、键盘、焦点、清除、外部点击、保存、窗口边界与滚动写入计数。
- `npm run test:report-composer`：章节、字段、记录、顺序、标题与判断同时更新；实际PDF/Word/Excel下载、保存恢复、合并与窄屏。
- `test:reports`、`test:report-edges`、`test:material`、`test:slides`、`test:usage`、`test:code`覆盖原有主要流程和样式回归。
- 用PyMuPDF与DOCX XML检查实际文件：取消的章节、字段、学生和判断均不出现，所选顺序/标题与预览一致，中文完整、A4单色及边界正常。所有检查材料为匿名合成数据。
