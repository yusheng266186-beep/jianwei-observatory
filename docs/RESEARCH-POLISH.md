# 2026-10-12：题目研究与操作衔接

本轮回顾此前要求，围绕“定位一道题—连续查看—留下线索—返回继续”完善已有设计。保持校徽深蓝、冰蓝、白与灰蓝，继续使用独立的研究图册、玻璃 Dock 和证据抽屉。

## 本轮变化

- 逐题地图可以检索题号、知识点，支持全角数字与多个关键词。检索和学生姓名查找各自保存，不共用状态。
- 题目条件使用四个带题数统计的按键：全部题目、低得分率、作答未齐、满分待补。计数随检索和当前班级范围变化；低得分率采用既有研究规则，界面明确阈值。
- 作答未齐只统计已有作答记录中的空白，真实0分仍有效。未知满分不推算得分率或平均失分；失分排序将未知值放在最后。
- 从地图进入的上一题/下一题沿匹配题目的排列顺序浏览；观察窗明确来源范围，也能切回全卷题序。知识点、班级热力、个人作答等其他入口继续使用全卷题序。
- 研究夹与备份保留来源地图的题目序列，重新打开时移除已不存在或重复的题号。沿班级展开和逐层返回仍保留来路。
- 地图卡片显示有效作答数与本范围作答记录数，满分待补和作答未齐直接可见。少题继续采用紧凑行，多题继续采用密集网格。
- 桌面检索、计数和四种条件并排，减少控制面板内部留白。手机班级按键改为横向多选条，选中班级保持可见；收紧本卷概况的内边距。页头返回按钮移除文字中重复的箭头。
- 修复输入检索后立即导出、摘录或留下研究线索可能采用旧结果的问题；离开研究对象时取消旧检索的延迟更新，避免新试卷被旧输入抢走焦点。
- 地图导出新增观察条件与匹配题目；全卷逐题指标、知识点和原始小题作答仍完整保留，不因地图筛选而删除。研究夹记录视图条件，证据摘录保留当时结果。
