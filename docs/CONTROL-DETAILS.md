# 滚动与控件细节

整页、观察窗、报告、表格、文本框及横向栏使用统一的校徽蓝灰滚动条。整页提供较宽的拖拽区域，横向栏使用紧凑轨道；此前隐藏横向滚动条的规则已移除。滚动、惯性、键盘翻页及拖拽仍由浏览器处理，未增加模拟滚动层或逐帧脚本。

支持标准滚动条属性的浏览器使用 `scrollbar-color` 和 `scrollbar-width`；支持 WebKit 滚动条部件的浏览器使用圆角滑块及内侧留边。系统高对比模式恢复原生滚动条和控件符号。

同时统一搜索清除符号、单选选中色、文本框拖拽角、输入光标和键盘焦点；禁用按钮不再触发悬停或按压反馈。触屏窄屏输入使用16px字号，保留数字步进和原生单选操作。查询与数据存储方式保持原有实现。

`npm run test:controls` 使用匿名材料，真实操作整页/抽屉/宽表滑块、滚轮、键盘翻页、搜索清除、数字步进、单选切换、长文本滚动及禁用状态。六个场景覆盖320、390、820和1440宽度，并检查触屏布局与系统高对比模式。检查启动时移除 Playwright 默认的隐藏滚动条参数，确保实际绘制和拖动了滚动条。浏览器检查使用 Chromium；Firefox和Safari的规则保留兼容实现，未声称已在这两种浏览器中实测。

本次资源版本为 `controls-v12`，校徽及本机已有材料沿用原资源与存储标识。
