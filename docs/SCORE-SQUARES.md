# 小题方块与得分率

按使用者要求恢复方块卡片，以得分率为主要数字，题号、知识点、均分/满分及样本指标按层次排列。移除小题比例条、作答结构细线和试卷预览柱条；完整逐题指标、作答结构与班级对比继续通过原有明细、观察窗和导出查看。

方块使用校徽蓝与浅色半透明渐变、细边高光和轻阴影。选中描边、悬停、键盘焦点、触屏、减少动态、纸面及系统高对比模式分别适配；卡片不叠加多层背景模糊。全卷概况与档案预览同步使用数字方块，SVG/PNG图表仍能导出完整题号与实际字体。

数学1—19题、12—14合并记分以及原始分数口径保留。未知满分显示 —，真实0分仍显示0.0%，异常原值保留。题目筛选、排序、连续浏览、研究夹恢复和固定网址发布继续使用已有逻辑。

检查包括54项单元、46模块静态检查、6组试题流程、4组密度、4组全卷与Dock流程，以及原表六科标签在五档宽度下的30组排版检查。浏览器使用匿名作答检查，不发布原始成绩或工作簿。本轮资源版本为 squares-v21，字体资源保持 type-v16。
