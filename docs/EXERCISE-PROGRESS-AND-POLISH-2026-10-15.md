# 导出基线、试题清理与实时进度

本轮仅更新 `feature/gemini-training`、预览站及训练开发函数，正式站和北辰服务保持原状。云端当前选择由用户工作台决定；验证时为 DeepSeek 官方 `deepseek-flash`，部署没有覆盖该选择。

## 文档与输入

PDF 原先将公式 SVG 与中文按外框居中，公式的上下标和分式改变外框后便出现浮高。现在读取现有宋体打印字体的 ascent/descent，与 MathJax SVG 原点统一基线，再排每一行。沿用本地字体缓存，不新增字体请求；PDF 缓存升级为 v4，避免继续命中旧排版。Word 继续使用原有原生 OMML 公式。

全站文本输入、搜索、数字编辑及多行编辑统一玻璃表面、边缘、焦点、禁用和错误态。带标签的 `.field` 合为一个完整写作面，内层编辑器透明，避免双层框；保留滚轮、步进器和已有写作卡片的布局。模型工作台使用同一层材质。动画和玻璃效果没有删减。

## 学生与考试

辅导入口默认可看全年级，班级筛选可选；输入姓名时跨班搜索。可在选择学生前指定任意考次，也可按每人最近一次有效考试进入。超过60人时继续加载，不丢弃后续学生。进入后保留单考选择和2–6次考试共性选择，旧考次严格使用该次材料。

## 删除与缓存

试题中心每项均可删除，包括进行中、已生成和失败任务；另有清理失败任务和清理导出缓存。删除同步清除该练习的内存文件与 IndexedDB 文件缓存，防止正在制作的文件回写。12秒内可撤销本轮删除；之后在联网并已验证时同步云端删除标记，离线队列重开后继续。

删除标记按所有者隔离、幂等，同一任务 ID 不会被恢复或重新提交。排队任务跳过执行，正在生成的文本任务尽可能在下一次状态保存时中断；已发出的上游请求不承诺停止计费。云端对象沿用14天保留规则。教学跟进中已安排练习的独立副本继续保留，打开它不会重新加入试题中心。

## 实时生成

后台读取真实 SSE 流并每5秒保存进度；前台正常每4秒同步。分别显示连接、推演、正文、最终校验，已输出题数、正文/思考字符数、上次模型响应时间，以及逐步返回的题干、答案和解析。后台心跳与上游片段时间分开；即使后台仍在线，上游长时间没有新片段也会明确说明。

仅展示服务明确公开的思考摘要；原始隐藏推演只计数字符，不写入进度对象或界面。当前 DeepSeek 服务未提供公开摘要，因此显示推演活动与实际正文。部分 JSON 仅用于草稿预览，最终文件仍使用原始完整结果的严格校验，不修补或改写模型成稿。进度草稿不重复写入本机整个练习列表，恢复时从云端查询。

## 本轮验证

- 单元测试223项通过，覆盖真实 WOFF 字体指标、SSE 分片/UTF-8、公开摘要与隐藏推演隔离、任务删除及取消、缓存晚到回写、全年级搜索与历史考次。
- 实际隔离云端任务 `2e5d0d63-e6b1-490d-ab03-4ee956fcd7c3` 完成匿名数学3题：排队、连接、推演与完成状态均可查询，累计18566个思考字符、1906个正文字符；题数和最终结构校验通过。人工核对导数、单调区间、参数范围与评分均正确。
- 同一匿名公式样例修复前后分别导出PDF，修复后两页均经渲染检查，中文、分式、上下标及分页没有浮高或截断。
- 原生内置浏览器验证跨班搜索、指定第一场历史考试进入、多考选择，以及已完成任务删除和短时撤销。390px下对话框宽378px、页面宽390px，没有横向溢出。
- 进度界面另用匿名真实任务的历史片段检查草稿公式、已输出题数和45秒无新响应提示；此界面排版回放不计为第二次实时模型调用。

所有界面验收材料位于独立本机端口，不写入用户预览站的本地成绩库。
