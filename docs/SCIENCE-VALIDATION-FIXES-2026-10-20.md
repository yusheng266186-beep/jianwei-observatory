# 数理化生实测中的程序修复

本轮用实际工作簿的数学、物理、化学、生物知识点和匿名逐题成绩发起四份六题练习，保留 Sol 6.1/max 与猎豹 image 2.5 设置。本文记录实测发现的程序问题，内容评分与生成成功情况分别核对，不能相互替代。

## 评分点与格式修复

化学原稿某题有十条评分点、合计十一分。旧契约最多允许八条，修复模型合并条目又会触发正确的保真拦截，形成约束冲突。

移除评分点数组的固定八条上限，前端、后端与模型 Schema 同步。保留文档总容量、非空文本、题型、分值和客观题单一评分规则。所有轮次仍以最初原稿为基准，禁止通过合并或删除评分点通过校检。匿名真实原稿纳入回归测试；仅修换行能通过，删除或合并条目仍被拒绝。

## 上游余额错误

实测收到 HTTP 403，业务错误为 `insufficient_user_quota`，正文说明预扣费额度不足。旧逻辑将其归为鉴权失败。

HTTP 非成功响应与 HTTP 200 内嵌错误共用分类器，明确余额、预扣费与订阅信息优先于通用状态码；真正的权限拒绝仍判鉴权失败。各协议诊断统一脱敏并限制长度。HTTP 200 内嵌错误继续不提供可触发自动重发的 `diagnostic.status`，传输中断不被当成格式错误反复调用。

## 三维翻折运动弧

原空间线框不能表达翻折委托中的弧形箭头，图示模型为补箭头退回二维 drawing 后被非共面校验拒绝。

`spatial-frame` 新增可选 `motionArcs:[{from,to,center:[x,y,z]}]`。起止顶点与圆心采用三维坐标，程序在圆弧所在平面采样后统一投影，终点绘方向箭头。半径须相等且非零，索引、坐标和角度须有效，最多四条，不接受退化或半周及以上的歧义圆弧。曲线采样点纳入画布边界；旧线框与标准立体保留原输出。没有放松精确图、非共面或安全绘图要求。

## PDF 与 Word 分页

Word 中相邻两张数据表可能被阅读器合并，跨页后重复错误表头。现在在相邻表格之间加入紧凑分隔段落，每张表保留自己的表头、列数和数据。物理直径表与电压电流表已实际导出、渲染核对。

短表格保持连续，教师版评分点采用紧凑行距，并将末两条一起分页，避免只有一条评分点另占整页。生物教师 Word 由九页收敛为八页，正文与评分内容保留。

生物复杂插图后的长单列选项，曾在 PDF 页尾将 A 项切成两段。符合单页容量的四项现在作为独立选项组一起分页；长篇材料选项仍能流动，避免将整道带图题捆成大块。Word 与 PDF 共用短选项组的判断。

## 学科提示

模板版本更新为 `subject-templates-20261020.8`。物理要求题干、答案与评分点使用相同的时间区间；生物复核模拟数据的单位前缀与数量级；化学避免在鉴别题中提前对应未知物身份，并用未舍入中间值计算。提示能减少遗漏，不能取代独立解题和教师审阅。

## 导入提交反馈

代码审计发现导入提交先禁用按钮、随后重绘进度时，新的关闭按钮又处于可点击外观。现在先绘进度，再禁用当前按钮；保存失败后的新关闭入口仍可使用。审计脚本等待真实的首页准备事件，并在合并前完成来源确认，不以固定延时猜测初始化结束。
