# 生成审核与定点修复调整（2026-10-21）

本轮按教师要求降低无实质影响的拦截，接受模型合理的表达与绘图选择。通过标准是内容能否正确、清楚地支持作答；科学错误与可选的显示建议分别处理。

## 放宽的规则

- 三维线框允许直角标记等辅助控制点使用空标签；不强迫虚构点名，也不输出空文字。真正有名称的顶点仍须能正确对应题干。
- 翻折图优先使用三维模型，也接受受控 `drawing` 的空间投影。是否正确由图题关系核对决定，不再仅因图示类型不同就拒绝。
- 参数化图库为推荐选择，不强制取代模型更合适的自定义矢量表达。
- 题干已明确的直角、等长关系不强制在图中重复标记；合理简化、等效解法、投影视角、措辞与排版偏好只保留建议。
- 完整 JSON 代码围栏可直接读取，保留全部字段值和公式；不猜补截断 JSON、改写转义或重新整理文档。图示可省略空说明、空连线标签及默认可见标记；审核结果可省略空意见数组，额外的顶层说明不进入题文。
- 模型明确批准图示时，附带建议作为可查看的备注；学科审核只有 `severity:review` 的建议不会阻塞成卷。

安全的矢量元素、图片来源与文件校验、必要题文和参考答案、已确认的教师要求及明确影响作答的错误检查继续保留。

## 错误回传与恢复

- 图示修复携带原候选、累计具体错误及上一轮核对的原始输出和原因；核对格式出错只修复核对响应，不重新画图。
- 新任务的学科核对若收到完整但未通过的回复，自动进行一次带诊断的定点修订。输入包含原题、具体意见、失败输出和候选；不重新命题，也不重新调用出题阶段。第二次仍未解决则保留原稿及可继续状态，避免无限付费循环。网络、鉴权、余额等服务错误不伪装成内容错误自动重发。
- 旧任务点击继续后重新获得本轮自动修图机会，历史错误和已完成题组保留；旧规则用尽的次数不再永久禁止后续定点修复。
- 已保存的失败图在新规则下重新解析成功时直接复用，只运行后续核对，无须再次规划。

## 验证

- 846 项单元测试通过，包括原始辅助点故障、前后端契约、格式兼容、安全拒绝、诊断回传、自动内容修订、手动继续后的修图及重复事件保护。
- 构建、运行资源、前后端契约和发布入口检查通过。
- 使用云端反复失败的数学翻折候选在本地原样解析并实际渲染：三处无名辅助点及直角符号正常保留，前后两幅分图、长度标签和空间坐标未改写。

- 正式云端 API 与 Worker 的63项部署文件均下载回读一致，既有函数环境、模型及授权配置保留。
- 发布后续跑此前经历7轮规划的真实8题数学任务：直接复用旧候选，仅执行图题核对，约10秒恢复全部8题；第5题核对通过且无意见，前4题和原题文未重新生成。这是该次旧任务的恢复耗时，不代表完整新出题耗时。

本轮不以跳过学科错误或假称已核对的方式提高通过率。
