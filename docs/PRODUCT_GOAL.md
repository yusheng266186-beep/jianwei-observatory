# 荣县第一中学高三成绩分析的持续打磨目标

让教师迅速看清值得研究的线索，用很少的操作追到学生和小题，写下判断后能顺畅回到原来的研究位置。视觉应当安静、有辨识度，长时间阅读也舒服。

这是一项产品目标，不是已通过验收的结论。“第一眼有吸引力”和“实际操作顺畅”仍由使用者亲自判断。此前版本按委托要求未进行校检；2026-10-11 用户追加校检授权，已执行的检查范围见 [校检记录](AUDIT-2026-10-11.md)。

## 用这些原则决定取舍

1. 第一屏有清楚的重点。先给概况和可追的线索，完整证据可以继续展开；不把所有数字并排堆到首屏。
2. 寻找证据要有多条路径。班级、考试、阶段变化、学科、小题、临界状态与名单筛选都能作为入口，不强迫每次先输入姓名。
3. 操作只影响眼前的研究。各场景保留自己的条件，不用一个班级或类别选择器控制全部分析。
4. 看细节不丢来路。抽屉、完整档案和跨场景跳转，能返回原范围与位置；有价值的线索可以留存，下一次继续。
5. 证据与判断各有归属。研究夹保存条件；摘录保留当时结果和教师判断。更新材料不改写原摘录。
6. 缺失明确可见。没有的数据、有效线和明确满分保持未知，不制造0或虚假的确定结论。外语直接使用原表折合成绩，补习班仍归入相应科类。
7. 视觉服务阅读。当前配色以校徽的深蓝、冰蓝、白色和灰蓝为准，移除额外橙色；参考页启发内容形态的多样性，采用独立的研究图册设计。玻璃层次用于区分空间，关键数字和文字保持清楚；卡片按内容密度安排尺寸，避免大面积无用留白。动作小幅、连续、有收束，静读偏好与系统减少动态效果都受尊重。下文暖色设计为历史记录，以本条最新方向为准。
8. 未导入就保持空白。研究夹入口、已有研究内容与具体统计不出现在空白材料页。

9. 入口和恢复分开。Dock 打开各板块入口；局部切换不追加返回层级；下钻返回对应来源；研究夹恢复已有条件和位置。年级排名优先使用原表校排名，辅助相对位置写明导入范围与0–100口径。最新规则见 [入口与返回](ENTRY-CLARITY.md)。

## 2026-10-11：从使用者走完一条路径

实际浏览器中按“找学生 → 看变化 → 追小题 → 写判断 → 返回研究”操作，使用匿名材料复现并修复了翻页停在名单末尾、个人小题无法深入、预览判断关闭丢失、旧考次观察进入对比时切到最新成绩、提示遮挡对比按钮等问题。

- 翻页把新名单入口放到顶栏下方，同时转移键盘阅读焦点。
- 个人小题的三种展示都能进入当前班级的同题观察，再展开全部班级，返回时恢复来源与表格位置。
- 预览中写判断即留存，同份未改变的预览继续原判断；空白预览保持临时阅读。
- 手机范围面板可收起，学科条件仍能从筛选抽屉组合，导出保留直接入口。收紧标题、线索、查询与排序的间距，让学生更早出现在首屏。
- 生效班级与科类可直接撤销，颠倒的分数范围明确提示并可原处修改。
- 通知从底部操作区移开，加入关闭入口，避免挡住对比操作。

新增9组浏览器流程检查，连同原28项回归检查共37项。原始附件不在当前环境中，以上操作使用匿名构造数据；真实原表、Safari和实际设备流畅程度仍须分别验证。

按“发现线索 → 查看证据 → 留下判断 → 返回继续”逐段完善。优先处理影响这条路径的阅读和操作问题，其次深化现有图表与完整明细的关联，再增加有明确用途的新内容。每一轮围绕一个完整流程推进，避免入口、卡片和控件持续膨胀。

## 2026-10-12：以用户满意的参考页完善层次

把用户提供的《向上 · 第14版》作为视觉参考，提取暖白空间、墨绿正文、宋体标题、独立数字字体、细边玻璃和柔和阴影。成绩研究采用更紧凑的局部控件与证据布局，金色只作少量章节与基准提示。参考文件内的学生、奖励数据和脚本没有成为应用资料或部署资源。

年级/班级首屏优先呈现当前范围与主要成绩，章节导航置于主证据之后；学生目录减少重复边框。达线人数打开同考次、同班级的实际名单，本科名单含特控；缺有效线引导补充，真实0人仍可查阅。手机班级按钮可横向滑动，选中班级自动保持可见，班级资料可以展开。回到前一研究时先完成图表布局再恢复滚动，避免位置漂移。

这些改动与本轮检查见 [页面层次与参考设计记录](VISUAL-POLISH-2026-10-12.md)。视觉满意度仍以实际使用反馈为依据。


## 2026-10-12：阳光配色与多样化内容

用户指出上一版虽然统一了字级与玻璃材质，内容块仍过于相似，且更喜欢参考页的阳光暖色。本轮进一步采用暖金光感，开放的总览构图、达线环形图、四种真实数据预览、任务进度卡片、卷册、学科刻度和学生首字头像，以不同形态表达不同研究对象。

新增可视化仍遵守缺失和真实0的区别；本科/特控分别按自己的可判定人数计算。预览只展示明确标注的部分材料，完整小题、历史和明细继续存在于原入口与导出中。任务卡片可横向查阅，人数直接进入名单，返回保留卡片位置；手机无需先翻过所有卡片再读明细。具体实现与检查见 [阳光视觉记录](SUNLIGHT-2026-10-12.md)。

## 独立设计：研究图册

用户进一步明确“不是照抄，需要自己的想法”。当前版本从教学研究流程组织形态：开放的成绩规模、独立达线标尺、并排班级剖面、题号编目、个人档案、三阶段跟进和资料索引。保留温暖与通透的体验，以暖纸、浅金、墨灰和灰蓝构成统一语言。移除太阳、圆环、轨道和持续漂浮，空白页展示独立绘制的研究折页。数据功能与各场景范围继续保留，具体约束见 [独立图册设计记录](DESIGN-FOLIO.md)。
