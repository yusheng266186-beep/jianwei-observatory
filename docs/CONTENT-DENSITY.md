# 内容密度与空列修复

用户指出“各班的达线位置”右侧有大面积空白，试卷研究中也存在内容少而卡片过大的问题。

## 达线位置

根因是分区模板缺少闭合的 `</section>`：历史类分区被嵌在物理类分区内，两幅图共同落在双列网格的左列。原先仅检查整页溢出、卡片底部间隔与操作，不足以发现这个错误。

补齐分区闭合标签后，达线卡片改为占满当前研究宽度。物理、历史在桌面与平板上并排，在窄屏上按顺序展开；教学范围和材料信息独立放在下方。卡片高度由图表内容决定。18班匿名材料在1440像素宽度下，卡片高度由约819像素降为507像素。

## 少量材料

- 试卷封面缩短标题、预览、明细与操作之间的距离，仍保留真实题号预览与满分说明。
- 逐题地图已进一步改为蓝白仪表卡，集中呈现得分率、均分/满分、有效作答、平均失分、零分与达满分人数；单题在桌面横向组织，多题采用网格，窄屏保留完整信息。未知满分不计算失分或得分率，卡片高度随内容变化。详见 [关闭操作与小题卡片](DIALOG-AND-QUESTION-POLISH.md)。
- 知识点的关联题目、个人得分卡片在少量题目时也使用紧凑行，保留同题作答与逐层返回。
- 知识点路径、少量个人知识点和班级相关试卷并排组织已有信息。
- 单班/两班地图与一科/两科学科剖面按少量对象重排，取消只有一项时被拉宽的大方卡。普通学科网格恢复桌面三列、平板两列、手机一列。

统计口径、参考班级、17/18班归类、外语合并比较与历史联结保持原有实现。没有用虚构内容填充空白。填写判断的文本框继续保留写作空间。

## 前轮验证（仪表卡改版前）

结构专项覆盖六个研究场景及学科、知识点、学生抽屉的240种渲染组合：完整材料、少班、缺线/满分、仅小题、单学科、长知识点名称与满分作答。对上述组合在320、390、820、1440像素宽度下检查960个呈现，包括卡片子元素边界和实际文本字形边界，无越界。

`npm run test:density` 增加四组回归：达线图表分区与三指标/六档宽度、少题与知识点逐层返回、个人零分/缺失小题、十二题密集网格。结构检查直接断言两科类为独立的同级分区，避免只检查页面能否打开。

本轮数据回归23项、浏览器流程29组、目录3组、响应式细节5组、证据导出4组、密度专项4组、动效25组通过；40个应用模块静态检查无错误。

本轮仪表卡回归沿用四组密度专项，检查卡片底部与知识点之间没有多余留白、新增指标完整、少题/十二题地图，以及知识点与个人作答的逐层返回。未重跑此前960个组合，不将历史范围视为本轮结果。
