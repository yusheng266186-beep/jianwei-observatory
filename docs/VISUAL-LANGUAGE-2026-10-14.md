# 全站视觉与动效统一

本轮目标：六个研究板块、导入页、观察窗、阅读设置、研究夹、教学安排和报告工作区使用协调的材质与运动节奏。各板块保留适合研究对象的布局；看起来属于同一个工作台。

版本为 `runtime-v36`，继续发布到原 GitHub Pages 网址。

## 统一的设计语言

- 保留校徽深蓝、蓝灰辅助文字、宋体主标题、黑体正文及独立数字字形。背景更安静，内容靠透明度与柔和阴影形成层次。
- 四种角色：背景画布、内容阅读面、内嵌控件、浮动窗口。阅读面不使用装饰外框；输入字段、表格分隔和键盘焦点保留必要边界。
- 使用一致的左上光照及155度透光方向。面板、学生卡、试卷、班级剖面、跟进卡、资料和报告从同一组材质变量取值。
- 同一类控件共用选中底色与内嵌层。标题、控件、指标与证据的主次通过字号、字重、间距和层级表达，减少重复套框。
- 桌面面板圆角18px，手机16px；内嵌层、窗口、小得分块各有固定角色。大部分内容间距按24/16px组织，手机与紧凑偏好相应收紧。
- 资料导入区作为一个完整面板，内部用轻分隔组织两栏。报告类型、阅读选择、日期时间面板及报告设置沿用同样的材质。
- 得分深浅继续表示原始得分率；未知和异常保留独立颜色。小块继续按内容确定高度，不恢复空白占位。

## 动效的共同规则

`styles/material.css`保存时间与曲线，`app/ui/motion.js`读取这些变量。悬停、选中底板、图表变化、明细展开、页面与窗口均从这里取得节奏。

| 动作 | 时长 | 表现 |
| --- | --- | --- |
| 颜色与轻反馈 | 160ms | 快速确认操作 |
| 控件和局部切换 | 220ms | 短距离连续衔接 |
| 明细展开 | 260ms | 从当前高度继续 |
| 卡片排列与图表变化 | 300ms | 保留原位置作为起点 |
| 窗口进入 | 320ms | 轻移，减少缩放幅度 |
| 跨板块横移 | 400ms | 整页连续进退，页头和Dock稳定 |
| 窗口退出 | 180ms | 及时释放关闭操作 |

使用单调收束的曲线，减少弹跳。普通卡片悬停抬升2px、按钮1px；Dock邻近反馈进一步减弱。触屏关闭鼠标位移，静读与系统减少动态效果同时关闭悬停移动和动画。

弹窗和研究抽屉的遮罩共用进入/退出生命周期，改变方向时读取当前透明度。关闭过程中重新打开不会闪回初始状态；暂停或不可用的动画仍会按有界等待释放关闭。

手机考试轴不再把许多名称挤成竖排。每张考次卡保留足够宽度，名称正常换行，所有考次可以横向浏览；当前选择立即进入可见区域。

## 后续修改的边界

材质从`--surface-panel`、`--surface-inset`、`--surface-control`、`--surface-selected`及`--surface-window`取值。组件文件负责自身布局；新卡片和控件先选角色，再调整内容，避免重新定义一套阴影、背景或动画曲线。试卷专用变量是这些公共材质的别名。

新增`npm run test:visual-language`检查六板块的阅读材质一致性、长考试名称、当前考次可见、遮罩中断连续性、CSS/原生动画共用参数，以及纸面、减少动态和高对比偏好。使用匿名示例与构造材料，不以此替代真实成绩核验。

## 验证记录

- 95项数据与模块单元检查通过。
- 全站材质及得分色阶3组、自然动效25组、场景横移8组通过。
- 新的设计语言检查覆盖1440、820、390、320px四种宽度；六个试卷视图及题目/知识点窗口也通过四宽度检查。
- 日期、时间、键盘及数值控件通过1440、390、320px检查；长PDF阅读、末页定位、滚动、阅读对象释放通过四种尺寸检查。

本机Edge/Chromium以510名匿名学生、12次导航对比原线上版本和本地版本。测量时没有并行运行其他浏览器检查或录屏；手机列表示手机尺寸的浏览器视窗。

| 390×844 | 47.6→49.8ms | 529.5→471.9ms | 16.7→16.7ms |

四组采样均无50ms以上长任务，连续6次实际鼠标点击均被接收且最后选择正确。收束时间变短，内容可用时间基本相近；这组测量不代表所有设备的固定帧率。
