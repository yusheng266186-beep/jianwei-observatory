# 全站光影层次与得分色阶

本轮资源版本 cohesion-v22，补充并取代此前材质记录中的对应视觉规则。固定访问地址继续使用 https://yusheng266186-beep.github.io/jianwei-observatory/ ，字体仍使用 type-v16 的三种阅读角色。

## 空间层次

同一方向的高光、蓝灰阴影和边线用于区分四种表面，而非给所有内容使用相同透明度：

| 层次 | 用途 | 表面处理 |
| --- | --- | --- |
| 页面底层 | 六个研究画布 | 克制的蓝白光场，低对比背景 |
| 阅读层 | 主卡片、卷面、跟进卡、资料面板 | 较清楚的白色阅读面、边缘高光、轻接触阴影 |
| 内嵌层 | 班级范围、筛选、卡内操作及任务通道 | 更冷、更透明的浅蓝底，窄边和内侧阴影 |
| 浮窗层 | 页头、Dock、研究夹、观察窗及提示 | 透明玻璃边缘与更明显的投影；Dock和页头保留背景模糊 |

桌面主面板统一18px圆角，内嵌12px，操作9px，窗口22px；手机相应收紧。班级并列图表仍共用一个阅读面，资料导入和工作区仍共用一个面板，内部不再额外叠加独立卡片投影。六个场景保持各自布局与信息密度。

旧样式中图表组合面板、资料面板和学生筛选的非对称圆角、单题观察窗的独立底色及控件高光已协调。表格固定表头和固定首列保持较实的底色，避免滚动文字透出。提示条和图表浮动提示同步使用浅色浮窗。

模糊集中在浮动导航和窗口的背景遮罩，正文卡片不新增独立模糊，观察窗内部不叠加滤镜。已有整页横移动效、减少动态效果、键盘操作和关闭回退逻辑保留。

## 得分率颜色

保留方块、得分率、均分/满分与作答证据，恢复五档由浅至深的学校蓝：低于25%、25%至不足50%、50%至不足75%、75%至不足90%、90%至100%。越高越深，深色方块使用浅色文字。未知满分、无有效作答、负比例和超100%的比例使用中性状态，不误表示为真实零分或正常满分。

封面、全卷SVG、逐题方块、个人得分、知识点关联题、资料预览和热力格共用 `app/ui/score-tones.js` 的色阶。悬停与选中不覆盖数据颜色；原始负分和超满分仍保留数值。色阶图例与“低得分率”筛选口径分别说明，颜色分段不改写教师设置的研究阈值。

深色块的次要文字及未知状态数字一并调整对比度。纸面模式和系统减少透明度偏好去掉表面高光，继续保留数据色阶。打印与SVG/PNG导出保留方块颜色和完整题序。

## 检查范围

`npm test` 包含色阶边界、未知/异常处理、明度顺序和透明底/高光处的文字对比度检查。`npm run test:material` 在真实浏览器中覆盖跨视图颜色一致、选中/悬停、实际文字颜色、四档屏宽、六场景材质角色、纸面偏好及空白工作区。

本轮另检查六场景的子页面与主要弹窗，共48个桌面/手机视图，未发现页面横向溢出；沿用试题流程、密度、全卷与Dock、各类关闭操作及整页切换回归。测试使用匿名合成作答；工作簿和私人学生数据不进入发布仓库。浏览器检查说明所覆盖的行为与版面，视觉满意程度仍由使用者评价。
