# 练习审阅中的图示缩放

审阅全部题目时，每个已生成图示右下方提供缩放手柄。拖动按原图比例改变宽度，方向键微调，Shift 配合方向键按 5% 调整；Home/End 选择边界。原有紧凑、标准、宽幅继续作为快捷排版，重新选择预设会清除自定尺寸，切换图示插入位置则保留尺寸。

教师调整保存在题目的 `figureLayout.widthPercent`，不改写模型原稿或图示数据。修改后取消原审题确认，PDF/Word 和教学跟进入口需重新确认后使用。导出缓存包含完整题目和图示布局；不同排版不会命中旧文件。缩放过程只更新当前图示样式，松手才保存和刷新审阅内容，不在拖动过程中排公式或生成文件。触控手柄独立捕获指针，题目正文仍可正常滚动。

自定宽度以 A4 正文宽度 507.28pt 为基准，20–100%，高度保持原图比例并在 420pt 内适配。预览与两种导出共用尺寸边界；自定尺寸优先于圆锥曲线及地图的默认打印收紧规则。位图也按教师设置输出，包含需要等比放大的情况。控制手柄与尺寸说明只出现在审阅界面，不进入练习文件。旧手机 SVG 最小高度/最大高度规则不再作用于可缩放图示与手柄图标；缩小后的图注及尺寸说明保持可读。

本次不修改云端配置、模型选择、凭据或生产 main。模型图示委托仍只使用原来的三种宽度；单独重绘提交前去掉教师本地的自定宽度，兼容当前云端接口，返回图示后仍保留本地排版。共享后端源契约同步支持未来持久化自定布局。

验证：353 项 Node 检查通过，包含新布局契约、数值范围、图示委托隔离、前后端契约一致与默认打印布局回归。隔离的匿名工作区验证桌面和 390px 视口拖动、键盘调整、重新打开后保留尺寸、预设恢复、重新确认审题。按 45.7%、100%、20% 导出学生 PDF 和 Word，Word 图示宽度为 231.83、507.28、101.46pt；两种文档逐页渲染核对。修复最后一题底部外边距在临界分页时产生空白尾页的问题，PDF 与 Word 均为两页。未调用模型重新生成、未使用真实学生数据。
