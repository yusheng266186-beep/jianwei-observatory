# 全仓冗余代码审查与等价清理

日期：2026-10-23。清理前基线：`5861bdf7022e6c016ac27067f0b2585bb140f23e`。

目标是减少已证实的无用代码与重复实现，保留原有功能、数据口径、样本、玻璃材质和动效。此次分三轮审查；没有重设计页面、增加出题限制、改动排名计算或删除测试用例。

## 范围与判断方法

基线共1,800个受Git跟踪的文件。建立源码引用图，对排除第三方和运行包后的489个JS/CJS文件做语法、作用域和引用扫描，再核对动态加载、事件委托、Worker、测试、运维脚本和文档入口。共享后端MJS通过项目打包校验，与浏览器契约一起维护。

DeepSeek分别只读审查前端/样式及后端/工具/测试。主审对建议重新检查调用链，执行删改和回归；没有照单删除。静态扫描只能提供候选，不能证明所有动态路径都不可达。CSS需要考虑选择器、级联顺序、媒体查询与独立页面，不能只凭一次关键词搜索清理。

第三方依赖、字体、匿名样本、原始教材/考试契约和历史文档保留。运行包按既有资源保留规则构建，没有手工删除旧哈希文件。

## 复核后明确保留的代码

| 项目 | 保留依据 |
| --- | --- |
| `server.cjs` 的 `jobEnvelope` | 子审最初报为无调用；主审确认GET任务查询实际使用，属于误报 |

| `assets/workbench-accounts.js`、旧Worker入口 | 当前入口已变化，但仍涉及旧缓存页面、历史兼容或测试入口；本轮不删 |
| `close` / `surfaceclosed` 监听 | 覆盖原生和托管表层生命周期，清理逻辑幂等 |
| 首页静态内容和欢迎模板 | 分别服务首屏立即显示与清空/恢复流程 |
| 旧哈希包和CSS | 由发布登记及完整依赖图保留，避免已打开的旧页面动态加载失败 |
| 字体构建、部署、授权和专项测试脚本 | 部分为手工入口，不属于线上依赖图；不因未接CI而删掉 |
| 历史文档、第三方文件及匿名样本 | 用于追溯、许可证与回归；不作为重复业务源码处理 |

因此本轮没有整批删除模块、兼容层或历史资源，也没有把所有看起来相似的函数抽到公共文件。仍存在可继续评估的维护债务；这次完成的是有证据支持的保守清理。
