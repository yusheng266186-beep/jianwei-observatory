# 学生报告的排名、纸面分块与试卷知识点

当前资源版本 `runtime-v36`，继续使用原 GitHub Pages 网址。

## 排名以明确的来源范围为准

以前有两条不可靠的路径：标准工作簿固定把第10列作为校排；没有校排时，校内考试的通用 `rank` 被回退为年级排名。这些数字可能实际属于班排。

标准表现在根据表头分别定位校排、班排和市排，学科排名也按其表头定位，保留列名来源。平面表可单独对应班排。`Atlas.gradeRank` 不再采用通用排名的回退。

学生打印报告的总分、年级排名和班级排名分开呈现。阶段及学科表写明排名范围；范围未注明的原始排名不冒充年级排名。旧标准导入没有保存表头的数值继续保存在材料中，在报告中标为待核实。重新合并含明确表头的原表，可以校准旧的字段映射；不能从一个旧数字反推出真正的年级名次。旧版保存的报告快照保留原数值，但再次导出时将未经核验的年级排名改标为历史排名待核实，可从当前材料重新生成。

## 让纸面先呈现教学重点

学生报告默认包含关键概况、阶段、学科短板、最多8项优先训练题、跟进及材料说明。完整个人逐题原分仍在内容设置中，可单独勾选，也可用“完整材料”加入。报告中心也可以选择直接附完整逐题原分。

PDF概况采用成组的黑白指标块，证据表使用轻线、重复表头及淡灰交替底色。姓名、排名及线下观察带内的分差加粗，关键分差使用灰底。完整数据、未知值、原始0分和合并计分项继续保留。PDF与Word共享内容选择和重点标注；Word仍允许本机排版重分页。

## 字体按实际文字加载

原来的两份完整打印字体合计17,485,240字节。现在优先使用6000个常用字符的两份无损WOFF，合计1,688,800字节，首次基础字体减少90.3%。其余字符按报告实际文字选择分片；全部分片合起来保留原字体44,853个字符映射，两个字重均已核对。

只有进入打印报告中心才预取基础字体。静态字体在浏览器Cache Storage中复用，切换报告及释放排版worker后无需再次下载。字体预取失败可重试，打印排版继续在本机worker执行；关闭预览仍保留已开始的下载。

## 知识点与题号各有位置

之前卷面封面只展示题号/题型和得分率，已有的知识点没有在这里显示。封面小块和全卷题序现在分别显示题号、得分率及原表知识点。未知标为“知识点待补”，不按题号猜测内容。自适应换列、字号和文字省略，完整内容仍可从提示与题目观察取得。保留蓝白渐变、得分深浅和无装饰边框。

工作簿读取按“知识点/考查知识点”等行标题定位；原表明确合并的知识点单元格可覆盖其合并列。不会把合并的分值复制给多个得分项。

`runtime-v36` 移除封面小块的112px/108px固定最小高度、题号的两行占位和知识点的自动底部间距，统一8px内边距与3px内容间距。小块由实际内容决定高度，同一行自然对齐，长题型和知识点继续换行并保留完整提示。

匿名九科示例的174个得分项在2000、1440、820、390、320px五种宽度实测高度约69–83px，得分率没有横向溢出。另已通过四种宽度的六个试卷视图、题目/知识点抽屉、键盘和材质切换检查。

## 验证范围

- 95项单元检查：含校排217/班排2的列位置混用、通用排名拒绝回退、旧材料待核实、重新合并校准、移动/合并知识点行、原始0分、未知满分及字体分片。
- 实际工作簿导入到学生PDF/Word：桌面和手机，分别核对排名、原题19、知识点、生僻字及真实文件内容；预览与下载SHA256一致。
- 四种尺寸的纸面工作区、长报告阅读和末页定位；六个试卷视图及单题/知识点抽屉的四宽度检查。
- 后台排版在字体等待时可以关闭，下载继续；关闭后的PDF阅读对象同步释放，迟到的原生close事件不清除新报告。
- 真实PDF/Word的组合、过滤、对象切换、保存恢复、首载失败重试与超长记录检查。

验证使用匿名合成工作簿与记录。缺失的三份原始Excel和用户当前浏览器备份不在此工作区，因此没有宣称已逐格核准用户全部真实材料。
