# 生成即成稿与直接导出（2026-10-15）

教师确认的格式前移到云端提示词与输出 Schema，模型一次输出可直接使用的文档源：标题、目标、逐题题干、选项、答案、解析、评分点和必要图示。每次请求的 Schema 固定本次题数及字段边界，云端模板版本为 `subject-templates-20261015.4`。

移除生成后的 JSON 转义修复、字面换行替换和公式分隔符自动补全；解析与检查不改变原稿。模型须按约定一次给出合法 JSON、完整公式和真实换行。完整性与安全检查继续保留，格式缺失明确返回失败，不再用程序猜测修补。

预览直接读取同一份文档源，相同内容不重复构建预览。老师确认审题后，后台准备学生练习与教师答案文件；下载与预备共享同一任务。相同成稿和相同学生信息重复下载时，返回已有文件，不再次做 PDF 排版封装。老师修改内容后重新审题，才准备新的文件。PDF 文件封装仍负责宋体、矢量公式、页边距和必要分页，不改写题意与答案。

文件缓存最多四份、8 MiB，按最近使用淘汰，失败可重试。学生信息和学生/教师版本在缓存键中区分；准备过程保留点击时的内容快照。清空工作区会清空文件缓存，尚未完成的旧预备不会重新填回缓存。

验证：173 项单元测试通过；Chromium/WebKit 手机流程验证后台恢复、编辑后重新审题、两类下载、图示及教学跟进。重复下载字节完全一致，PDF Worker 没有新增构建任务；本机样例重复下载用时分别约 52 ms 和 42 ms，不代表模型首次出题或其他设备的等待时间。

真实调用独立云端服务，模型按新版格式一次完成三道数学题，包含单选、填空、解答及含参分类讨论。已核对导数、参数边界与单调区间，并直接预览、确认、导出学生版与教师版 PDF。生成期间未使用上述格式修复步骤。
