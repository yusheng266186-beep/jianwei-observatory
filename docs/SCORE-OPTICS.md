# 得分块的透光渐变

用户认可试卷封面的大容器，但明确封面小块、全卷 SVG 题序块和逐题证据块仍偏平涂，并给出柔和斜向透光的认可示例。本次保持容器布局与无边框设计，统一这三种得分材料及其关联卡片。

`score-tones.js` 每档明确亮面、基色、背光三种颜色。基色色阶保持高分更深，高分档从整块藏蓝改为雾蓝，用深墨蓝文字维持清晰度。未知与异常仍单独为中性材料；真实0分与缺失不混淆。三个渐变位置的主/次文字均检查4.5:1对比。

HTML卡片采用固定斜向三色位；封面增加低强度静态雾面，SVG采用同一三色位和柔光。静态纹理不建立逐张实时背景模糊。SVG梯度的data-score-base只表示语义基色，最亮端不再冒充该基色；尺寸适配与完整图表导出继续保留。

清晰阅读模式与减少透明度偏好保持不透明底层和静态渐变，关闭纹理和实时背景模糊；不再把得分块变回单色。实际打印仍使用平实的数据颜色，报告的黑白A4打印不使用分析卡片装饰。

检查：4个色阶/渐变单元检查；test:material检查数据颜色、文字与两种阅读偏好；test:paper-surfaces检查四宽度、六视图、无边框、真实渐变和普通/清晰阅读；test:workbench检查题序与SVG/PNG下载。对封面小块截图读取两侧像素，四宽度中RGB差值合计为49–54，确认实际呈现的是可见渐变，不只是CSS中写了gradient。

检查数据全部为匿名合成材料，视觉满意度由用户判断。
