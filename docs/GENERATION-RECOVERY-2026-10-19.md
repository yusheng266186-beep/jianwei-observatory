# 生成校检保真、成稿与图片恢复（2026-10-19）

## 本轮目标

完整返回的题目不能因暂时存储失败而丢失；格式修复不能删条件换取校验通过；图片已生成但下载失败时优先恢复下载，避免重复计费。保留原有透明材质、动画、宋体文档、逐题留白和教师审题流程。

## 校检边界

- 每轮修复以最初不可变原稿为基准。每轮候选、错误分别保存，自动和手动继续都不会把失败候选提升为原稿。
- 可读 JSON 即使缺少必填字段，仍逐项保护已有题文、条件、数字、选项、答案、分值、目标和图示委托。仅比较时识别有限的公式分隔、转义和表格分隔行等格式等价；不改写交付题目。
- 完全无法解析或只有部分字段可读时，保真元数据明确为未完整验证，不能据此声称学科内容绝对正确。修正稿仍须通过严格文档与图题校验并由教师审题。
- 历史失败恢复通过同一严格验收入口。“如图”却无图、学科错图、坏标签不能恢复为成稿；有独立图示委托的任务必须完成规划、绘图与核对。

## 成稿交付

`result-delivery.cjs` 在私有任务下保存不可变 `delivery-candidate.json`。最终写入有限重试，并读回核对处理“已写成功但 ACK 中断”；比较使用 JSON 存储快照，不把 `undefined` 字段丢弃误判为题文冲突。模型调用不会因保存失败而重发。

单份题文、图示步骤和校检修正稿有独立保存断点。父任务轮询能接续已完成步骤；组装结果可从子稿重新装配。删除父任务或源题后停止交付。若整个私有存储在模型返回后持续不可用、连候选也无法写入，不能承诺无损恢复；保持明确错误，不自动重放未知计费调用。

## 图片恢复与费用

`image-candidate.cjs` 将已生成的签名 URL 或 base64 保存在私有前缀，绑定教师、任务、题目、图片轮次、服务、模型和委托内容。公开状态、错误和日志不包含签名 URL、密钥或大段图片编码。

- 下载最多 3 次，网络和明确暂时 5xx 退避；保持原始图像字节与高清容量。
- 下载恢复沿用同一候选、同一图片轮次，不重新出题或付费生图。
- 过期、404、无效文件或没有可恢复候选时，明确提示；只有教师选择“重新生成配图（调用生图服务）”才新建图片轮次。
- 像素核对发现实质图像错误时，不自动重付费；明确重画将核对意见传给绘图模型并使用新候选。
- 仅 HTTPS 精确主机白名单、拒绝重定向、拒绝私网 DNS 地址；下载不转发上游 Authorization；验证 MIME、签名、PNG/JPEG 尺寸和容量。
- 候选在私有桶生命周期内保存；应用删除任务是逻辑移除，不物理清除对象。

## 实际像素核对

支持且适配的视觉协议将实际位图以专用图片内容块发送，题干、图示委托与图片分开。结果区分 `pixels`、`brief`、`vector-source`，不会把核对描述说成已核对像素。明确拒绝图像输入的模型可回退为委托核对，教师需核对实际图片；网络中断不伪装为视觉通过。

图像比例、留白等能在预留版位等比放入的排版建议记录为 `layoutNotes`；标签切割、结构错误、数据不清等仍阻止通过。图片不会为了匹配横版而被拉伸。

实际调用：当前猎豹 Sol 6.1 max 接收了先前 ByteCat 2048×2048 PNG，约 47 秒给出具体核对意见，指出方形图片与原横版委托不符。该图片对应教师自定验收样题，不是实表学生生成成功率样本。本次未据此更改全局出题模型或思考强度。

## 使用与验证

针对性回归覆盖：缺字段原稿删除角度、连续两轮与人工继续洗稿、历史漏图恢复、存储 ACK 丢失、持续写失败后恢复、删除竞态、图片 5xx 重下、404 不重付费、像素失败后显式修图、多 MB 图片、协议适配和移动端审题显示。

本轮离线故障测试使用模拟传输和存储，不计入模型实测成功率。真实视觉调用、猎豹生图试验和正式发布回执分别保存在工作区 outputs；仓库不包含密钥、认证器种子、签名图链或学生原始表格。

任何一次小样本成功都不能证明 100% 成功；格式合格也不代表学科答案正确。模型、链路、余额、上游额度和云函数时限仍可能失败，教师审题始终保留。
