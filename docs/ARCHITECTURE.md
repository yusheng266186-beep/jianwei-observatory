# 衡迹：按对象组织研究

## 状态与导航

应用有六本独立的研究状态。年级考试、班级画布、试卷作答范围、学生观察阶段和临界条件各自保存，不共用一个全局筛选上下文。资料编辑使用自己的字段，不改变分析对象。

路由识别具体对象：`#class/4/history`、`#papers/数学%7C52`、`#people/学生标识/52`。显式点击班级、姓名或试卷才发起对象转换；个人档案查询全部阶段，来路中的班级范围不会裁掉历史记录。

材料替换用版本序号防止迟到的初始读取覆盖新导入的数据；场景渲染用序号丢弃迟到的模块响应。经典启动器独立保留恢复导入入口。

## 数据路径

| 文件 | 边界 |
| --- | --- |
| app/data/compat.js | 工作簿交换结构、基础常量和记录去重；不承载页面状态或研究查询 |
| app/data/parser.js | 保留已有标准工作簿与旧 JSON 的读入适配器，输入兼容性与新页面分离 |
| app/data/worker.js | 文件读取与进度消息 |
| app/data/inbox.js | 待读入材料、列对应、合并/替换的独立生命周期 |
| app/data/workspace.js | 材料、上一份材料、证据摘录、本机状态、迁移、空白状态与超时 |
| app/engine/metrics.js | 缺失值、描述统计与两个科类的定义 |
| app/engine/atlas.js | 按考试、实际班级、学生、试卷和个人作答建立索引，暴露对象查询 |
| app/scenes/ | 六个场景各自把对象查询组织为可操作的研究画布 |
| app/ui/ | 新界面原语、时间轴、实体按键、试题色阶和原生 SVG |
| app/io/exports.js | 原始明细、当前研究证据与文件输出 |
| app/main.js | 对象路由、命令、独立研究状态及材料变更 |
| app/launch.js | 主应用启动失败时的独立恢复入口 |

研究引擎不接受旧式通用“考试+班级+科类+届别”上下文：班级快照、班级时间序列、学生故事、试卷观察和临界对象是不同查询。科类由班级与个人记录取得，17班属于物理类、18班属于历史类，不以补习建立第三或第四分类。

## 表达方式

年级用四表入口、研究线索和班级条形，班级用横向对象选择与连续画布，试卷用考次档案与题目地图，个人用可组合目录和横向阶段轴，跟进用独立检索的行动看板与名单。报告由当前证据直接形成，摘录是结果快照，后续筛选不会重算已经留存的摘录。

原有 src/app.js、src/views、旧图表/界面组件与旧样式已退役。保留工作簿读入适配器、SheetJS 和 JSZip，新的查询引擎、路由、状态、场景与视效独立建立。历史匿名资源不作为启动材料。

## 发布边界

浏览器导入的原始材料与身份信息不成为部署产物。页面使用相对路径，可以直接放在 GitHub Pages 项目根目录；未导入时不会加载或呈现仓库中的历史匿名资源。


## 2026-10-11 交互与外语口径

- `engine/directory.js` 为每个 Atlas 缓存观察考次的学生线索，组合条件只作用于学生目录。分位查询在 Atlas 内按考次/科类缓存，筛选时不重复扫描全体学生。
- `scenes/directory.js` 同一结果集生成卡片、完整表格、可点击散点与两科类分布。每页24/48/96人，完整导出包括筛选条件。
- `ui/explorer.js` 提供个人抽屉、2–4人对比与独立的证据导出。`main.js` 管理焦点、Esc、背景滚动锁、打开/关闭动画；完整档案仍是独立对象路由。
- `styles.css` 完整重写为灰白、墨色与冷蓝的单一视觉系统，旧玻璃叠加样式移除。六个页面使用各自的内容布局与局部控件。
- `ui/render.js` 对当前对象的 DOM 按字段、命令和记录键协调更新，保留输入与展开明细。同一研究中的重新筛选不替换整个页面。Dock DOM 保持稳定，活动底板通过位置变换移动；卡片与表格行使用位置动画。场景支持 View Transition 与 Web Animations 回退，连续切换会跳过上一场过渡。
- `scenes/overview.js` 独立组织四表直达、临界/阶段线索、可点击班级条形、材料覆盖和考次增量。首页没有全局班级选择器。
- 学生目录新增学科达线与双上线组合条件、可撤销条件标签及四组明细列。图表分数区间保留不含上界的范围，进入指定考试/科类/班级名单。
- `ui/question.js` 组织单题抽屉、各班得分、全体作答分页及独立证据导出。热力单元格带入对应班级。抽屉保存浏览栈，可从学生观察返回试题研究。
- 班级有效页按总分与学科的双上线、仅总分、仅学科、双未上线四种组合进入学生目录；缺成绩或有效线单独保留。
- 教学跟进支持看板与名单，跟进班级/状态/记录检索独立于临界发现条件。资料与报告使用六个功能入口，直接说明各入口的材料数量与用途。
- `Atlas.comparisonSubjects / subject / line / teacher` 提供“外语”投影视图。原始英语、日语成绩与题库不改写；比较直接使用表内折合成绩，旧有效线按英语线优先映射，手工统一外语线可显式留空。语种只作个人元信息，不设语种筛选或分组比较。
- 班级卡片、学科横向、阶段指标、临界短板、学生比较和分析导出均使用外语投影。外语综合原分均分留空，个人原分在档案与备份中保留。
- 材料备份新增收藏与对比选择；旧资料、存储和跟进记录保持兼容。纸面报告与原始小题导出继续保留完整记录。

本次按用户要求不执行页面验收、数据校检或自动业务测试，只跟踪 Pages 发布状态。


## 2026-10-11 连续研究与阅读

- `ui/interactions.js` 集中管理表格溢出、ResizeObserver、视野内呈现、明细高度动画、图表提示与键盘提示。提示在 DOM 更新前释放，避免旧图表元信息覆盖新节点。原生标题在提示结束后恢复。
- `ui/reading.js` 管理信息间距、玻璃/纸面和减少动态效果；读取偏好独立于成绩资料，动态偏好同时影响 CSS 与 Web Animations。
- `ui/explorer.js` 的个人抽屉拆分为三个内容区域，原始成绩和小题保持完整。名单队列使用当次真实考试记录，切换阶段不裁剪故事，也不改变其他模块的范围。
- `engine/directory.js` 提供筛选快照与名称建议，快照不保存结果副本。保存后的筛选可重新查询，JSON 工作区包含 `directoryViews`。
- `ui/html.js` 为表格提供稳定标识、行列数、横向导航及只读展开入口。可编辑表格保持原表单与字段归属。横向位置按研究对象、区块和表格分别保存。
- `ui/report.js` 提供材料分类、检索与50行分页，完整报告仍作为导出源；预览状态不修改已保存的证据快照。
- `main.js` 保留研究对象的滚动位置、学生抽屉名单队列和浏览栈，处理输入法完成事件，分离各区域的检索延迟。移除本机跟进、筛选或摘录后保留一次通知撤销；通知与图表提示使用原生 popover 进入顶层，能在模态抽屉中读取。

本轮按用户持续要求不执行网页验收、浏览器检查、数据校检或自动业务测试，发布只跟踪 GitHub Pages 流程。


## 2026-10-11 导入前的空白工作区

- `ui/welcome.js` 只提供文件入口、模板和简短说明，不提供样本或零值分析。六个场景在没有材料时共用这一入口，分析场景模块此时不加载。
- `workspace.hydrate` 不再请求默认样本；读取已有资料时忽略未带 `userImported` 标记的旧默认匿名数据，保留真实导入材料的恢复。普通导入与经典启动器的恢复导入都写入这一标记。
- 未导入时，页头隐藏学生检索与具体对象名称。清空或撤回到空白材料时，关闭成绩抽屉和报告并恢复导入入口；原有本机阅读偏好保持独立。
- 初次导入只有“加入工作区”一个操作；已有材料才提供合并与替换选项。完整备份仍保留导入标记，显式导入的匿名化资料可正常恢复。

## 2026-10-11 整体视觉与研究章节

- `ui/composition.js` 为有多个证据章节的场景生成独立阅读导航。导航只定位证据，不引入全局班级或科类状态；阶段原表可从导航展开。
- 年级总览将本场概况、四表入口、学生线索与完整班级/阶段证据分层。班级本场页提供可继续研究的学科差异和临界线索，有效线缺失时直接进入本考次有效线维护。
- `ui/interactions.js` 对 SVG 使用容器适配的标签字号，长条形标签保留完整提示；图表显示变化不修改数据或导出明细。ResizeObserver 分别管理宽表和图表，阅读进度在 animation frame 中更新。
- `ui/plots.js` 统一图表系列色与小题色阶，试卷及个人逐题区域有得分率图例。缺失值保持无法计算，不把色阶当作成绩。
- `styles.css` 在同一视觉系统中重做钛白/石墨/电蓝、字级、面板层次与响应式尺寸。悬浮顶栏和深色玻璃 Dock 与轻色材料面板分层，抽屉使用透明度和背景模糊。
- 初始入口使用 `index.html` 的静态空白模板，经典启动器先呈现模板；`ui/welcome.js` 复用相同模板，防止首屏和清空后出现不同入口。玻璃纸张只表达导入，不伪造任何数据。
- 场景过渡区分前进、返回与同场景变化；卡片悬停光泽及 Dock 邻近反馈只用于鼠标与允许动态效果的环境，触屏及静读不执行。
- `ui/html.js` 的阅读口径保留为可展开说明，正文不重复堆放全部统计口径。
