# 衡迹：按对象组织研究

## 状态与导航

应用有六本独立的研究状态。年级考试、班级画布、试卷作答范围、学生观察阶段和临界条件各自保存，不共用一个全局筛选上下文。资料编辑使用自己的字段，不改变分析对象。

路由识别具体对象：`#class/4/history`、`#papers/数学%7C52`、`#people/学生标识/52`。显式点击班级、姓名或试卷才发起对象转换；个人档案查询全部阶段，来路中的班级范围不会裁掉历史记录。

材料替换用版本序号防止迟到的初始读取覆盖新导入的数据；场景渲染用序号丢弃迟到的模块响应。经典启动器独立保留恢复导入入口。

研究引擎不接受旧式通用“考试+班级+科类+届别”上下文：班级快照、班级时间序列、学生故事、试卷观察和临界对象是不同查询。科类由班级与个人记录取得，17班属于物理类、18班属于历史类，不以补习建立第三或第四分类。

## 表达方式

年级用四表入口、研究线索和班级条形，班级用横向对象选择与连续画布，试卷用考次档案与题目地图，个人用可组合目录和横向阶段轴，跟进用独立检索的行动看板与名单。报告由当前证据直接形成，摘录是结果快照，后续筛选不会重算已经留存的摘录。

原有 src/app.js、src/views、旧图表/界面组件与旧样式已退役。保留工作簿读入适配器、SheetJS 和 JSZip，新的查询引擎、路由、状态、场景与视效独立建立。历史匿名资源不作为启动材料。

## 发布边界

浏览器导入的原始材料与身份信息不成为部署产物。页面使用相对路径，可以直接放在 GitHub Pages 项目根目录；未导入时不会加载或呈现仓库中的历史匿名资源。

## 2026-10-11 整体视觉与研究章节

- `ui/composition.js` 为有多个证据章节的场景生成独立阅读导航。导航只定位证据，不引入全局班级或科类状态；阶段原表可从导航展开。
- 年级总览将本场概况、四表入口、学生线索与完整班级/阶段证据分层。班级本场页提供可继续研究的学科差异和临界线索，有效线缺失时直接进入本考次有效线维护。
- `ui/interactions.js` 对 SVG 使用容器适配的标签字号，长条形标签保留完整提示；图表显示变化不修改数据或导出明细。ResizeObserver 分别管理宽表和图表，阅读进度在 animation frame 中更新。
- `ui/plots.js` 统一图表系列色与小题色阶，试卷及个人逐题区域有得分率图例。缺失值保持无法计算，不把色阶当作成绩。
- `styles.css` 在同一视觉系统中重做钛白/石墨/电蓝、字级、面板层次与响应式尺寸。悬浮顶栏和深色玻璃 Dock 与轻色材料面板分层，抽屉使用透明度和背景模糊。
- 初始入口使用 `index.html` 的静态空白模板，经典启动器先呈现模板；`ui/welcome.js` 复用相同模板，防止首屏和清空后出现不同入口。玻璃纸张只表达导入，不伪造任何数据。
- 场景过渡区分前进、返回与同场景变化；卡片悬停光泽及 Dock 邻近反馈只用于鼠标与允许动态效果的环境，触屏及静读不执行。

# 连续研究层（2026-10-11）

`ui/research.js` 负责研究视图的描述、对象可用性、条件签名和研究夹呈现。`main.js` 负责留存、恢复与导航，不把研究夹变成全局分析筛选器。每条研究视图只带一个场景的状态、阅读位置，以及可选的学生/题目/对比抽屉上下文；不复制成绩数据。最近足迹最多24条，收藏可命名与检索，放在本机偏好存储并进入完整 JSON 备份。

恢复时先确认材料中的对象、指定考次与题目可用，再恢复该场景的条件、页码、明细展开与表格位置。抽屉名单根据当前材料和原范围重新建立。跨场景返回使用本次页面内的研究路径，不依赖仅含对象的 URL 还原全部筛选。

证据报告仍是结果快照，并附带研究视图作为返回入口。研究夹重新查询当前材料，原摘录的表格与时间不会被重算覆盖。报告判断编辑状态区分预览、保存中、已保存和保存失败；非摘录预览可以显式留存，带判断返回时先保存为摘录。

# 证据观察层（2026-10-11）

`engine/lenses.js` 将班级学科、知识点和单题的名单条件集中为纯查询；视图、学生队列和报告使用同一查询结果。`ui/lenses.js` 呈现学科和知识点观察窗及报告，`ui/question.js` 呈现单题观察。观察条件存在抽屉状态中，不改变其他研究场景的条件。

学科均分及基准使用当前班级、考次与同科类范围，双线名单另行明确可判定记录。知识点个人完整得分率要求关联题全部填写且满分明确；缺作答与缺满分不参与完整率比较，也不被补成零分。知识点加权概况保留原有有效部分口径，并与个人完整作答口径分别标明。

新的 subject/knowledge 抽屉类型加入研究夹描述、材料可用性判断与上下文留存。单题及知识点的班级下钻保留原范围作为父观察窗，路径按键可以回到任意保留的父级。作答格子只补充焦点学生，不改变本题概况的班级范围。筛选名单、上一位/下一位及摘录导出共享过滤与排序条件。

## 2026-10-11 代码审核后的保存与合并

`parser.mergeDatasets` 对成绩逐字段补充，对作答逐题补充。空白不删除已有值，0属于明确更新；题库顺序改变时先按唯一题号重排旧作答与新作答。成绩变动会使未重新提供的对应排名失效。不同姓名的内部ID冲突先分配新ID，再通过 `context` 重联教师工作。

`workspace` 在调用时复制写入内容，通过同一模块的队列保持调用顺序；失败被传回调用方，后续写入仍能执行。材料、撤回快照、证据摘录使用同一个 `saveWorkspace` 事务。`main` 的材料更新锁防止并发导入、清空和撤回，并阻止更新中的资料表单保存；数据库失败时保存结果提示失败，保留当前页面和内存撤回。

`NoteJournal` 在输入判断时同步写入本机草稿。已存摘录只需保存文字差异，未落库的新摘录保留完整证据快照。数据库保存成功只确认与该次快照一致的草稿；新的文字继续保留。启动读取后恢复草稿并再次尝试保存。材料更新成功后重置旧草稿，删除摘录时移除对应草稿。

`Inbox` 的读取序号覆盖文件缓冲、Worker、列对应与结束清理，取消使整条旧读取失效；提交时锁定全部提交和关闭入口。`main` 使用导航与渲染序号共同检查研究恢复，迟到的同场景操作不能重新打开旧抽屉。DOM协调对重复键采用未使用节点匹配，防止同一学生的两条跟进互相覆盖。

复现、故障注入和边界见 [代码审核记录](CODE-AUDIT-2026-10-11.md)。

## 2026-10-12 统一材质与连续动效

`styles/glass.css` 在布局与研究控件样式之后统一材质、字级、色阶和手机尺寸。正文保持高对比，透明层用于顶栏、Dock、卡片和观察窗。抽屉只模糊页面背景，滚动内容及其内部面板不重复应用背景滤镜。

`ui/motion.js` 集中定义进入、排列、退出的时间和曲线。页面切换不创建截图覆盖层，标题和排列使用独立 `translate`，与 CSS 悬停的 `transform` 分开。排列前的位置以实际 DOM 节点为键，避免同一学生在两条跟进记录中的位置互相覆盖。

`ui/interactions.js` 在更新前读取标签底板和图形的当前几何，在更新后继续过渡；ResizeObserver 处理标签容器首次显现与尺寸变化。关闭的原生 dialog 不产生可用的尺寸，底板等待可见布局后再定位。移除的节点释放观察器，减少动态效果时不启动原生动画。

`ui/plots.js` 保留真实值节点与缺失断点，趋势曲线限制在相邻端点范围内；底色不跨越缺失区间。SVG 内含唯一的渐变定义，静态文件导出不依赖网页滤镜或远端资源。色阶与图例共用定义，外语比较和各场景查询范围保持独立。
