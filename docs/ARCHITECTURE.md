# 衡迹：按对象组织研究

## 状态与导航

应用有六本独立的研究状态。年级考试、班级画布、试卷作答范围、学生观察阶段和临界条件各自保存，不共用一个全局筛选上下文。资料编辑使用自己的字段，不改变分析对象。

路由识别具体对象：`#class/4/history`、`#papers/数学%7C52`、`#people/学生标识/52`。显式点击班级、姓名或试卷才发起对象转换；个人档案查询全部阶段，来路中的班级范围不会裁掉历史记录。

材料替换用版本序号防止迟到的初始读取覆盖新导入的数据；场景渲染用序号丢弃迟到的模块响应。经典启动器独立保留恢复导入入口。

## 数据路径

| 文件 | 边界 |
| --- | --- |
| app/data/compat.js | 工作簿交换结构、基础常量和记录去重；不承载页面状态或研究查询 |
| app/data/parser.js | 保留已有标准工作簿与旧 JSON 的读入适配器，输入兼容性与新页面分离 |
| app/data/worker.js | 文件读取与进度消息 |
| app/data/inbox.js | 待读入材料、列对应、合并/替换的独立生命周期 |
| app/data/workspace.js | 材料、上一份材料、证据摘录、本机状态、迁移与超时 |
| app/engine/metrics.js | 缺失值、描述统计与两个科类的定义 |
| app/engine/atlas.js | 按考试、实际班级、学生、试卷和个人作答建立索引，暴露对象查询 |
| app/scenes/ | 六个场景各自把对象查询组织为可操作的研究画布 |
| app/ui/ | 新界面原语、时间轴、实体按键、试题色阶和原生 SVG |
| app/io/exports.js | 原始明细、当前研究证据与文件输出 |
| app/main.js | 对象路由、命令、独立研究状态及材料变更 |
| app/launch.js | 主应用启动失败时的独立恢复入口 |

研究引擎不接受旧式通用“考试+班级+科类+届别”上下文：班级快照、班级时间序列、学生故事、试卷观察和临界对象是不同查询。科类由班级与个人记录取得，17班属于物理类、18班属于历史类，不以补习建立第三或第四分类。

## 表达方式

年级用班级地图，班级用连续画布，试卷用题目空间地图，个人用阶段轴，跟进用行动看板。报告由当前证据直接形成，摘录是结果快照，后续筛选不会重算已经留存的摘录。

原有 src/app.js、src/views、旧图表/界面组件与旧样式已退役。保留工作簿读入适配器、匿名样本、SheetJS 和 JSZip，新的查询引擎、路由、状态、场景与视效独立建立。

## 发布边界

GitHub 仅发布匿名样本和应用文件。浏览器导入的原始材料与身份信息不成为部署产物。页面使用相对路径，可以直接放在 GitHub Pages 项目根目录。


## 2026-10-11 交互与外语口径

- `engine/directory.js` 为每个 Atlas 缓存观察考次的学生线索，组合条件只作用于学生目录。分位查询在 Atlas 内按考次/科类缓存，筛选时不重复扫描全体学生。
- `scenes/directory.js` 同一结果集生成卡片、完整表格、可点击散点与两科类分布。每页24/48/96人，完整导出包括筛选条件。
- `ui/explorer.js` 提供个人抽屉、2–4人对比与独立的证据导出。`main.js` 管理焦点、Esc、背景滚动锁、打开/关闭动画；完整档案仍是独立对象路由。
- `styles/glass.css` 建立新的玻璃材质、色彩、圆角、层次及移动布局。Dock DOM 保持稳定，活动底板通过位置变换移动；卡片与表格行使用位置动画。场景支持 View Transition 与 Web Animations 回退，减少动态效果偏好覆盖全部动画。
- `Atlas.comparisonSubjects / subject / line / teacher` 提供“外语”投影视图。原始英语、日语成绩与题库不改写；比较直接使用表内折合成绩，旧有效线按英语线优先映射，手工统一外语线可显式留空。语种只作个人元信息，不设语种筛选或分组比较。
- 班级卡片、学科横向、阶段指标、临界短板、学生比较和分析导出均使用外语投影。外语综合原分均分留空，个人原分在档案与备份中保留。
- 材料备份新增收藏与对比选择；旧资料、存储和跟进记录保持兼容。纸面报告与原始小题导出继续保留完整记录。

本次按用户要求不执行页面验收、数据校检或自动业务测试，只跟踪 Pages 发布状态。
