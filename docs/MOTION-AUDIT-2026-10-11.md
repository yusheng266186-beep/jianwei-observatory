# 动效与页面切换检查 · 2026-10-11

按用户要求检查正常动态效果下的操作和中间状态。此次不只等待动画结束后看页面，重点操作切换尚未完成、模块仍在加载、抽屉刚开始进出时的控件。

## 复现的问题与处理

| 问题 | 复现证据 | 处理 |
| --- | --- | --- |
| 连续导航丢掉最后几次点击 | Chromium 中快速实际点击六个 Dock 入口，旧版本只接收第一次，其余事件目标落在 `html`，最终仍停在学生研究 | 移除截屏式 View Transition，页面直接渐显、标题轻移；导航与卡片在动画中保持实际 DOM 命中 |
| 新内容晚出现 | 原生过渡准备完成时，新学生卡片与试卷卡片自身透明度仍为0；新画面截图捕捉了透明入场状态 | 整页进入时卡片与图表直接呈现完整内容，画布从可见的0.65渐显；局部排列与章节进入各自保留轻量动画 |
| 旧页操作污染新页条件 | 延迟试卷模块后，旧班级页的“历次”按钮把 `papers.tab` 写成 `history`，导航与内容处于不同上下文 | 待加载对象的旧画布设为 inert，并保护命令、输入和表单；迟到响应只允许最新渲染序号生效；超过180ms显示轻量等待提示，Dock仍可继续换页 |
| 抽屉中途关闭跳变 | 在入场前半段按Escape，旧实现退出动画第一帧硬设透明度1、位移0 | 退出从当前计算后的透明度与位移开始；关闭动作合并，途中重新打开使用新的操作序号，旧关闭不清空新观察 |
| 抽屉内部连续切换积累动效 | 内容切换及行排列的动画没有统一取消旧动画 | 每次内容更新取消前一条内容动画；行位置先采样当前画面，再取消旧行动画并协调DOM；层级切换保持正在完成的抽屉入场 |
| 旧跨页跳转覆盖新观察 | 抽屉点击年级比较，退出途中展开学生，旧跳转仍继续执行并关闭新学生观察 | 退出返回是否真正完成；导航、完整档案、应用筛选、恢复研究和快捷查找在退出被新动作取消时停止后续操作 |
| 长画布跨页切换产生额外位移 | 原生动画组将画布从滚动后的约−1020px向新页80px插值，同时插值不同页面高度 | 页面进入只渐显，标题最多轻移8px；应用独立保存滚动，浏览器历史改为手动恢复，避免另一套恢复争抢位置 |
| 重复点击当前入口重播图表 | 当前对象没变时仍调用带动画的整页重绘 | 对没有新对象条件的重复导航直接保留当前研究 |
| 弹窗退出不一致 | 阅读、研究夹、宽表的Escape原本直接关闭，按钮关闭则播放动画 | Escape与按钮共用退出流程；报告继续先保存判断；重复退出共用同一Promise |

Dock跟随缩为320ms，按钮邻近抬升为280ms；画布渐显220ms、标题260ms、局部位置更新240ms、抽屉进入300ms/退出180ms、抽屉内切换200ms。保留系统与阅读设置中的减弱动态效果。离开DOM的章节观察节点及时解除观察。

## 实际验证范围

`npm run test:motion` 共22组，其中十组分别在1440×1000和390×844布局中运行：六页自然进入和返回、快速真实鼠标导航、页内标签与考次、目录卡片/表格/分布、抽屉入场中退出与关闭中重开。其余覆盖慢模块与过期输入、切换中点击卡片、知识点→小题→学生→返回、抽屉跳转途中改变观察对象、加载失败及重新打开、浏览器后退/前进及滚动位置、连续方向键、四类弹窗按钮关闭与Escape关闭、卡片折叠连点、入场时关闭动态效果、浏览器缺少截屏过渡API。

22组通过，所有场景无未捕获的页面异常。原有 `npm test` 的8项数据检查和 `npm run test:browser` 的29项浏览器流程也通过。改动最后涉及Dock时长后，另重跑桌面和手机的实际连续点击组。

使用51名匿名学生的构造材料完成操作检查，使用510名匿名学生、两个考次完成运行环境内的前后比较。未用真实身份证或成绩附件制作公开测试数据。
