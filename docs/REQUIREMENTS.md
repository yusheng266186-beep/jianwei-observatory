# 用户要求与实现对应

这份记录根据历次要求与当前源代码整理，不是浏览器验收或数据校检报告。用户对视觉、动画和研究体验的满意程度不能用“代码已存在”替代；本项目不标记为“已经完美”。

| 要求 | 当前实现 | 边界或本轮改进 |
| --- | --- | --- |
| 使用独立的新仓库发布 | `yusheng266186-beep/jianwei-observatory` 的 main 根目录，GitHub Pages 发布 | 沿用已建立的独立仓库，继续在此更新 |
| 不照搬质量慧析的布局、逻辑和架构 | 六个独立研究场景、对象路由、Atlas 查询索引与各场景状态 | 原工作簿和旧 JSON 仅作为输入兼容；不采用统一分析筛选架构 |
| 班级有效人 | 年级有效账、班级有效与任务、学科有效与双上线、临界学生入口 | 有相应功能与导出，不声称原表每个单元格已核对 |
| 个人学科小题得分 | 逐题地图、知识点、班级热力、学生作答矩阵、单题和学生抽屉、个人逐题明细 | 本轮增加色阶说明与标签可读性；明确满分缺失时不推断得分率 |
| 班级多次考试对比 | 考次多选、共同参考、趋势、逐人纵向矩阵和完整阶段原表 | 不以当前班级截断个人跨班级历史 |
| 班级成绩分析单次 | 原分/赋分/排名/距线切换、班级分布、学科剖面与同科类比较 | 本轮加入能继续打开学科与临界名单的证据线索 |
| 缺少的材料可以来自原项目 | 标准表解析与旧 GradeDataset JSON 的适配入口 | 没有导入的材料不凭空生成；不把缺少数据当作0 |
| 不把选班级、选类别统一套在全部分析 | 年级按考次，班级按对象，试卷按卷及作答范围，学生组合筛选，跟进独立条件 | 章节导航只移动阅读位置，不改变任何分析条件 |
| 不使用难用的下拉菜单 | 班级实体按键、考次时间轴、学科与视图按键、列对应展开面板 | 各控件只作用于对应研究场景 |
| 补习班不单独分类 | 17班计入物理类，18班计入历史类；补习仅保留为备注 | 汇总、同类分位、基准及趋势使用两科类 |
| 日语、英语统一比较 | Atlas 的外语投影及统一有效线，直接采用表中折合分 | 原始语种、个人原分和各自题库保留，不进行第二次折算 |
| 找学生不能只有搜索 | 班级、科类、考次、达线状态、阶段变化、学科状态、分数区间、收藏和常用筛选 | 名单可用卡片、完整列组表格和分布图查看 |
| 数据全面直观，呈现方式多元 | 统计概况、证据卡片、趋势、分布、热力、矩阵、抽屉、报告与完整导出 | 本轮强化首屏层次与章节导航；字段存在不能替代完整性校检 |
| 透明、毛玻璃、配色高级 | 钛白/石墨/电蓝；悬浮顶栏、深色玻璃 Dock、透明材料造型与侧边抽屉 | 高对比数字与轻背景分层；视觉是否惊艳由使用者判断 |
| 丝滑的动画与切换 | 方向过渡、同场景淡入、连续 Dock、卡片位置动画、视野内呈现、抽屉及明细展开 | 本轮统一节奏与鼠标反馈；未执行设备或帧率验收 |
| 数据不繁杂，鼓励继续研究 | 本场概况→四表→线索→完整证据；班级线索直达；章节定位；口径折叠 | 完整内容仍能展开与导出，减少首屏重复说明 |
| 细节和使用体验持续完善 | 保留焦点/滚动/表格位置，名单上一位下一位，抽屉浏览栈，筛选保存，撤销，宽表阅读，报告检索分页 | 本轮改善字级、图表标签、缺有效线引导与长页面阅读 |
| 导入前不显示具体信息 | 初始静态入口与所有场景共用空白材料入口；不自动加载旧匿名样本 | 模板插画没有姓名、分数、班级、考试或虚构统计；已导入材料可恢复 |
| 用户亲自验收，不进行验收和校检 | 不运行自动业务测试、不进行浏览器检查、截图验收或原始数据校检 | 发布只跟踪 GitHub Pages 部署结果 |

之前独立成绩查询项目中的身份证识别码及成绩发布工作，不因本教学研究网页的界面更新而自动重发；本仓库不发布学生原始身份材料。
