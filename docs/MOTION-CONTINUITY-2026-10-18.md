# 动画连续性与非线性缓动（2026-10-18）

这一轮处理实际操作中的起步、收稳、反向和中断。保留整页横移、透明玻璃、窗口进退、图表、卡片和全部功能；不更改成绩、排名、练习内容或云端配置。

## 动画规则

| 对象 | 行为 |
| --- | --- |
| 整页切换 | 临界阻尼位移，轻柔起步、逐渐收稳；1280视口本机记录约400ms、26个位置关键帧。快速连续或反向操作保留仍可见的旧画面，继承速度后制动与转向 |
| Dock与标签 | 同一套物理采样；新目标从当前实际位置和速度接续。只移动及缩放高亮底片，不拉伸文字；重复选择相同目标不重播 |
| 窗口、展开与微交互 | 共享非线性阻尼曲线。现代浏览器使用分段曲线，旧引擎保留三次贝塞尔回退；退出与按压使用独立的加速曲线 |
| 学生观察窗 | 内容快速切换时采样当前透明度和位移；回看前一个标签时方向相应反转，避免每次重置到起点 |
| 数字滑轮 | 按实际滚动距离连续调整数字缩放和透明度，包括原生惯性阶段。原固定字号和44px行高保留，拖动过程中直接跟手；只写变化的选中属性 |
| 玻璃 | 移动中与静止时一致；移除旧的切页时全量关闭backdrop-filter规则，通过裁切合成视口组织画面 |
| 阅读偏好 | 静读及系统减少动态仍可即时落位；滑轮程序移动也尊重静读，纸面/通透设置独立保留 |

这里使用“阻尼”而非夸张弹跳。从静止开始的移动单调接近终点；反向操作允许继承原速度，经过短暂制动后转向，避免速度突然反号。动画只在操作或内容进入视口时运行，不增加循环装饰动画。

## 实现与回收

`app/ui/spring-motion.js` 提供纯函数轨迹、原生时间轴采样、按通道接续和取消。预先算好的非线性位置通过WAAPI关键帧播放，原生时间轴的 `easing: linear` 不代表匀速移动：加减速已体现在每个位置关键帧中。无需每帧运行应用JS。终点同时考虑位置误差与速度，之后恢复最终样式。

`app/ui/animation-lifecycle.js` 共用完成、取消、异常及暂停超时回收，`motion.js` 保留兼容导出。整页切换仅保留仍与视口相交的旧DOM，旧层设为inert并改写ID；结束、减少动态或调整窗口时清理，不阻塞当前页面控件。

`styles/visual-language.css` 仍是最后的协调样式；两个独立页面更新样式版本参数，防止旧缓存保留不同缓动。首屏原有关键样式与默认欢迎页继续独立显示，不等待研究模块。

## 校检范围与结果

- Node测试490项通过，新增6项覆盖非线性起步与单调收稳、反向位置/速度连续、坐标与尺寸、原生时间轴接续、同目标不重播、静读和暂停/异常回退。
- 原生内置浏览器使用103位匿名学生、206条成绩和10条计划，实际1280桌面、390及320窄屏检查六入口。快速连续及反向切换的最后选择正确，完成后退场层为0，未出现整页横向溢出。
- 桌面连续切页采样记录中，约400ms内使用26个原生位置关键帧；本机记录的帧间隔95分位约9.4ms，仅说明此环境的观测结果，不代表所有实体手机或网络条件。
- 窗口、学生观察标签、自定义下拉、折叠和阅读偏好走查通过；手机实际拖动时长由90到89，题量键盘切到4，读数与设置摘要同步。滑轮行高始终44px，数字不会挤压相邻布局。
- 320宽度移动期间，主站页头及退场章节导航均保留20px模糊；桌面页头22px。纸面/静读的模糊为none、无过渡残留，恢复默认后通透材质和自然过渡恢复。
- 无材料首页直接显示“把成绩，读成线索。”默认展示，无运行错误。实际206条成绩逐项未改写，浏览器错误记录为0。没有调用付费模型或改动云端服务。
