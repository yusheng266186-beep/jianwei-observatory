# 学生目录：从材料条件继续研究

本轮把学校版的学生目录作为阅读体验重点，补充材料条件入口与卡片证据，同时审阅六个场景的桌面和手机呈现。

## 条件与人数

- 新增“已填写总分 / 总分待补”条件，独立于有效线是否齐全。实际0属于已填写；只有小题的记录属于总分待补。
- 工具栏提供“总分待补、多次成绩、本场小题”快捷入口。点击保留当前班级、科类、姓名和其他条件；多次成绩与本场小题在同一个材料条件内切换。
- 入口人数按切换到该条件后能匹配的学生计算。只排除该入口自身的旧条件，其余范围继续参与计算；因此切换结果不会与显示人数矛盾。
- 选中入口再次点击可取消。命令携带稳定条件值，点击时读取实时状态，连续点击与快速改选按最后一次操作生效。
- 已选条件可逐项移除；新总分状态随常用筛选、工作区备份、研究视图及导出条件一起保留。旧筛选没有此字段时采用不限。

## 卡片与手机阅读

卡片直接呈现两科已知的距本科线分差，按分差从低到高排序，并注明本科口径。没有成绩或有效线时明确说明暂不可判定；只有小题时说明成绩尚未导入。它是资料入口，不替教师作教学结论；全部学科仍可在卡片明细与档案中查看。

卡片底部增加“展开观察档案”。它沿当前筛选名单打开观察窗，上一位/下一位使用同一队列，关闭后保留范围。

桌面将新入口收进原结果工具栏，保持第一行卡片的起始位置。手机收紧目录标题和卡片留白，清除条件固定在工具栏内，排序选项独立横向滑动。未导入时继续显示空白工作区。
