# 六项系统优化项目

目标：在保持玻璃材质、动效和正式站隔离的基础上，提高内容可信度、运行可靠性与教师工作效率，并形成从考试依据到练后反馈的完整链路。已有能力继续复用；模型原稿不通过程序改写或补造数据。

## 实施与验收

| 方向 | 本项目交付 | 验收标准 |
|---|---|---|
| 内容与数据 | 共用题目质量检查、可核对的简单计算、专业审阅清单；排名/分数口径证据入口 | 不把格式完整冒充正确，不把未提供值补成0；页面、报告、练习导出共用同一来源规则 |
| 稳定与性能 | 模型工作台的真实任务统计、分阶段耗时与错误分类；本地页面/加载诊断 | 不暴露学生资料或凭据；失败与恢复不重复计为新任务；保留材质动画，用记录定位慢点 |
| 练后反馈 | 生成练习的逐题得分、教师标记与复核记录；接入教学跟进 | 满分、缺答、未批改和0分区分；不改原考试成绩；跨练习按同科同知识点比较 |
| 模板复用 | 草稿的用途/标签、搜索与预览、从已有练习复用；多学生训练队列 | 不把原学生姓名、考试与得分复制到另一名学生；每名学生重新匹配自己的依据；队列状态可恢复 |
| 学科图示 | 数学圆锥曲线、物理场/光路、生物系谱、化学装置组合、地理洋流/地质等代表性结构 | 明确支持范围、参数与未知项；结构/数据/黑白打印通过检查；不伪造真实底图或宣称全部类型覆盖 |
| 统一设计 | 共用反馈/状态/字段规则，统一核心流程和工作台；跨端/导出代表性回归 | 新控件沿用现有玻璃与滚轮，不出现原生选择框和重复入口；320/390/电脑边界、反馈与焦点可检查 |

## 轮次

1. 质量、数据证据和诊断基础。
2. 逐题反馈、教学跟进与模板/队列复用。
3. 图示扩展、统一交互、真实调用与导出验证。

每轮记录实际完成与未解决事项。最终仅发布feature/gemini-training与独立预览Pages及训练开发函数；main不变。

## 当前状态

- 三轮实现已完成，进入最终发布核对。
- 内容：网页/PDF/Word共用题目检查与修改失效规则；学生页、观察窗、打印报告共用来源口径。自动计算仅判断完全可解析的数值等式，不把变量推导或近似关系误报为正确。
- 运行：工作台增加1/7/30天最近60项任务统计、阶段耗时、错误分组及本机最近60次页面速度。诊断索引跨并发幂等，历史任务按同教师归属补入；索引与记录有界并发读取。统计不含题干、学生或凭据。
- 练后：逐题分数、未作答、未批改、错因与教师记录；按试题版本检查，旧标签页不能覆盖新记录。试题中心、教学跟进和教学报告均可回看；不改原考试记录。
- 模板：用途、标签、搜索、预览与已有试题保存为模板；多人队列每人重新匹配本人考试。待提交设置持久化，已提交沿原任务ID恢复；未提交项目需在试题中心继续提交，不能冒称已在云端运行。
- 图示：图库26→36幅。新增椭圆/双曲线/抛物线、匀强场、单界面光路、简明系谱、示意洋盆、地层与断层及化学三段装置。六类新语义参数前后端一致，明确未知项和不支持结构，不声称覆盖所有高中图。
- 设计：新增表单复用玻璃字段、滚轮、选择菜单及教学日历；图库增加搜索与共用窗口动效。六个主页面在320/390/1280px检查；横向时间轴、表格与目录轨道保留内部滚动，页面本身无横向溢出。
- 验收：344项Node检查；匿名数学真实生成3题、3图、3次图题核对完整通过，总时长95.7秒，三个标准方程与焦距8、渐近线±2x/3、焦点(1,0)独立核对。两学生匿名队列实际提交、模板用途/标签搜索、逐题0分/未批改/未作答、跟进联动与刷新恢复在界面验证。
- 导出：真实数学学生PDF与Word最终均2页，逐页核对公式基线、锚点、图注和留白；修正曲线图占位与空白尾页。文档源保留原稿，新增提示进一步要求普通理科填空采用自然问句，避免额外下划线。
- 开发API与worker只更新代码，环境、凭据及用户模型选择保持。正式main与正式Pages须在发布完成后逐项核对。
