# 小题材质与报告阅读

小题得分继续使用方块与真实得分率，蓝色深浅沿用统一口径。静态雾面纹理、折射边缘、题号徽标和内嵌证据区组成三层材质；没有增加每张卡片的实时背景模糊。零分、未知满分、异常原分与合并题号均保留，纸面偏好、减少透明度、减少动画和强制高对比各自适配。

旧预览的 sticky 容器高于弹窗可用空间，内部滚动已经到底时，末尾仍可能在弹窗裁剪区外，sticky 下载栏也会覆盖最后一行。桌面改成明确分配高度的编辑区与阅读区，下载栏在文档外占据独立位置；窄屏使用顺序布局，文档滚到边界后允许继续滚动弹窗。

阅读区提供适应宽度、原纸宽度、展开阅读、首尾定位和当前位置。展开模式按当前窗口分配高度，Esc 先退出阅读，再次 Esc 关闭报告；关闭按钮始终关闭报告。更新组合或标题保留阅读位置，重新生成报告从开头开始。纸面预览连续展示完整内容，PDF / Word 下载时自动分页，预览不冒充最终文件页码。

验证：

- `npm test`：77 个数据、边界与导出单元检查。
- `npm run test:material`：数据色阶、跨场景一致性、小字对比、窄屏与纸面偏好。
- `npm run test:report-reading`：1440×900、1280×600、390×844、320×640；长报告滚轮到底、键盘到底、手机触摸、末尾不被遮挡、展开阅读、宽度切换、实时编辑与新报告复位；数学 1–19 题号和 17 项计分均保留。
- `npm run test:report-composer`：实际 PDF、Word、Excel 下载使用当前选定章节、字段与记录，保存与合并组合可恢复。
- `npm run test:report-edges`：训练入口、导出失败后重试与长判断。

浏览器验证仅使用匿名合成材料。
