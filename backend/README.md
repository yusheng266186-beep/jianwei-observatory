## 处理流程

1. 浏览器确认学生、考试和学科，整理匿名目标和有效得分证据；请求与UUID先保存在本机。
2. HTTP函数验证 Origin、教师会话、结构和额度，创建不可覆盖的任务 `meta.json`，立即返回任务ID。
3. 私有COS对象创建通知触发事件Worker，`run.json`保证重复事件不重复调用。题量较多时使用题组任务，冻结目标、题型和模型配置。
4. 题文模型直接输出规定结构；需图题给出已知条件、图示要求及插入位置。图示模型独立规划声明式SVG或复杂插图，进入逐图绘制和图题核对。
5. 结果、部分完成内容和进度保存在私有任务对象；网页持续查询或重连后按原ID恢复。未完成题组/图示提供显式继续操作，不静默从头付费重跑。
6. 浏览器展示并由教师审题、调整和导出。审题确认与文档版本绑定，题文变化后重新核对；练后反馈同步关联计划。

请求只包含学科、年级、教学范围、训练重点、目标、题量、时间、难度、依据模式、题型、图示策略及最多24项匿名有效得分证据。姓名、班级、学生标识、排名和完整成绩留在本机。零分保留，缺分、缺满分和异常分不充当失分证据。

## 接口

除健康检查、会话建立和OPTIONS外，接口都要求教师Bearer会话。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /health` | 服务版本、当前模型公开信息、科目与验证类型 |
| `POST /session` | 六位动态码换取有期限的教师会话 |
| `GET /templates` | 前端学科提示词摘要，实际模板始终由云端使用 |
| `POST /jobs` | 匿名练习任务；`X-Request-ID`为UUID，相同ID须对应相同请求 |
| `GET /jobs/:id` | 状态、时间戳、流式内容、结果、必要失败原因 |
| `POST /jobs/:id/resume` | 显式继续未完成题组/图示 |
| `POST /figures`、`POST /illustrations` | 关联已存在题目的图示重绘/复杂插图任务 |
| `POST /jobs/remove` | 已确认删除任务的云端移除标记 |
| `GET/POST /admin/models` | 模型目录、版本、角色选择、历史与应用 |
| `POST /admin/probes` | 独立模型连接测试任务 |
| `GET/POST /admin/usage` | 每日生成上限、计数与清零 |
| `GET /admin/diagnostics` | 指定时间范围内的脱敏任务诊断 |
| `POST /admin/diagnostics/import` | 将已知任务ID补入诊断目录 |

模型配置和额度使用预期版本检查，冲突返回409，先同步再操作。删除沿用前端撤销/延迟提交流程；云端移除不退还已经产生的费用。试题中心是本浏览器目录，不能据此推定跨设备云端全量历史。

## 学科、模型与图示

`templates.cjs`、`curriculum-boundaries.cjs` 为云端学科规则；要求符合四川高考课程边界与题型，允许原创情境，不局限教材原题，不要求大学或竞赛知识。3–12题、5–90分钟及五档难度由共用契约校验。不同学科分别限制材料、公式、实验、单位、语言、史料、地图和评分依据。

`providers.json`、`model-profiles.json`、`model-adapter.cjs` 管理已授权的服务目录和协议；工作台分别选择题文与图示模型、思考档位。目录数量和可用性会变化，配置存在不代表余额或实测通过。新任务冻结提供方、模型、适配、凭据引用和时限；旧任务不随工作台切换变化，也不自动换服务。

`figure-pipeline.cjs`、`figure-generation.cjs` 管理题图分离，`*-guidance.cjs` 组织各类图示指导。浏览器/后端共享 `exercise-*.mjs` 结构，模型只提供受限数据，不执行任意代码。复杂插图使用用户指定中转的 `gpt-image-2` Web逆向聊天协议，不能按原生图片API假定；图片来源和大小受限，结果进入私有任务及本机备份。SVG优先/允许复杂插图/无图示策略均保留，非必要图示不是必选。

## 认证、存储与限额

TOTP独立Base32种子，SHA1、30秒步长，当前服务允许窗口起点起100秒内验证；同一码只用一次，验证尝试限流使用不可覆盖COS对象跨实例共享。会话有效期七天，HTTP函数只持TOTP种子和会话签名；上游密钥只注入Worker。执行角色读写专属桶前缀，不共享北辰存储权限。

任务前缀保留14天，控制前缀保留模型版本、测试和额度设置，不随试题生命周期清理。本机已下载的完整练习继续保存到用户明确清理或更换资料；定期备份。

应用每日上限可在工作台调节，0为不限，初始环境默认30；清零只切换今日计数时期，保留旧任务。模型连接测试是独立额度，默认每日20。服务、上游输出预算和云函数时限仍存在，不能用应用额度0保证任何题量永不超时。HTTP函数时限60秒，事件函数900秒，适配按模型实际设置执行；题组/图示拆分减少单次调用压力。结构或完整性失败保留原稿和私有诊断，不用事后改写来伪造成功。

## 部署

前端合并不会重部署云端；本次复用已经验证的服务。后端代码需更新时：

```sh
npm run package:training
TRAINING_PRIVATE_DIR=/absolute/private/directory TRAINING_PROVIDER=kimi-code node tools/deploy-training.cjs
```

该命令修改专属角色、策略、桶生命周期、函数代码/配置和触发器，仅在已授权后端维护时执行。先备份云端当前配置和代码包；文件夹必须在仓库外，目录0700、凭据0600。当前工具所需文件包括 `tencent.credentials.json`、`training-private.json`、`kimi-code.key`、`gemini.key`、`image.key`、`bytecat-grok.key` 和授权的 `beichen-live-current.json`。初始默认提供方选项与工作台后续版本不同，重新部署不能清掉控制区或重置教师选择。

`training-private.json` 必须复用，保持原TOTP种子、会话签名和任务归属。部署包、带凭据环境配置及 `training-deployment.json` 保留私有。服务沿用既有Origin `https://yusheng266186-beep.github.io`，两个Pages路径无需分别放行。新增域名需精确增加来源；不开放通配来源。

## 检查和故障处理

`npm test` 覆盖匿名边界、原ID重放、通知去重、并发额度、模型协议、流式响应、输出截断、题图流水线及诊断脱敏。生成最终正确性由教师审阅，格式校验不是答案正确的证明。实际调用和历史专题测试的范围见[文档索引](../docs/README.md)，本次正式验收见[发布校检](../docs/PRODUCTION-RELEASE-2026-10-17.md)。

错误先区分模型认证/余额/限速、传输中断、输出预算/完整性、图示失败和本机存储。查看原任务、工作台诊断和私有日志；先查询原任务，必要时明确继续或新建，不自动换模型、不清空私有存储、不重新生成TOTP来处理普通故障。
