## 处理流程

1. 浏览器确认学生、考试和学科，整理匿名目标和有效得分证据；请求与UUID先保存在本机。
2. HTTP函数验证 Origin、教师会话、结构和额度，创建不可覆盖的任务 `meta.json`，立即返回任务ID。
3. 私有COS对象创建通知触发事件Worker，`run.json`保证重复事件不重复调用。题量较多时使用题组任务，冻结目标、题型和模型配置。
4. 题文模型直接输出规定结构；完整回复若有可修复格式错误，独立校检任务按原要求局部修复并通过同一严格校验（默认沿用出题模型与思考强度，自动一次，可在工作台设置）。
5. 新任务保存原稿并进入独立学科复核，程序窄规则与同一冻结出题模型核对条件、答案与评分。明确修订分别记录，再过相同契约；不确定建议留给教师，确定但未能修正的错误阻止交付。复核连接失败可只继续当前复核。
6. 需图题给出已知条件、图示要求及插入位置。图示模型独立规划声明式SVG或复杂插图，进入逐图绘制和图题核对；折后空间图使用三维模型而非二维图冒充。
7. 结果、部分完成内容和进度保存在私有任务对象；网页持续查询或重连后按原ID恢复。未完成题组/复核/图示提供显式继续操作，不静默从头付费重跑。
8. 浏览器展示并由教师审题、调整和导出。审题确认与文档版本绑定，题文变化后重新核对；练后反馈同步关联计划。

请求只包含学科、年级、教学范围、训练重点、目标、题量、时间、难度、依据模式、题型、图示策略及最多24项匿名有效得分证据。姓名、班级、学生标识、排名和完整成绩留在本机。零分保留，缺分、缺满分和异常分不充当失分证据。

## 接口

除健康检查、会话建立和OPTIONS外，接口都要求教师Bearer会话。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /health` | 服务版本、当前模型公开信息、科目与验证类型 |
| `POST /session` | 六位动态码换取有期限的教师会话 |
| `GET /templates` | 前端学科提示词摘要，实际模板始终由云端使用 |
| `POST /jobs` | 匿名练习任务；`X-Request-ID`为UUID，相同ID须对应相同请求 |
| `GET /jobs/:id` | 状态、时间戳、流式内容、结果、必要失败原因；大响应可带artifacts分件声明 |
| `GET /jobs/:id/trace`、`/trace/:part` | 完整生成记录或带哈希的日志分段，要求同一教师会话 |
| `GET /jobs/:id/images/:questionId` | 取得分件声明中的完整题图，要求同一教师会话 |
| `POST /jobs/:id/resume` | 显式继续原稿格式修复或未完成题组/图示 |
| `POST /figures`、`POST /illustrations` | 关联已存在题目的图示重绘/复杂插图任务 |
| `POST /jobs/remove` | 已确认删除任务的云端移除标记 |
| `GET/POST /admin/models` | 模型目录、版本、角色选择、历史与应用 |
| `POST /admin/probes` | 独立模型连接测试任务 |
| `GET/POST /admin/usage` | 每日生成上限、计数与清零 |
| `GET /admin/diagnostics` | 指定时间范围内的脱敏任务诊断 |
| `POST /admin/diagnostics/import` | 将已知任务ID补入诊断目录 |

同题图示请求先竞争不可变尝试槽，再申请额度、创建任务元数据。重放返回原任务ID及真实状态；失败、过期、移除或额度拒绝后可另起尝试。并发事件Records默认最多2条同时处理，单条失败不阻止其他事件，最终汇总抛错供事件平台重试，已有任务锁阻止重复付费执行。

正常状态响应保持原结构；组合内容超过5,800,000字节预算时，完整trace/图片经认证分件读取。超长trace以60万字符为一段，每段附同一内容哈希；快照变化应重新查询，不能混合拼接。正文与插图各自受验证，不能把单张合法插图误计为正文超长。

模型配置和额度使用预期版本检查，冲突返回409，先同步再操作。删除沿用前端撤销/延迟提交流程；云端移除不退还已经产生的费用。试题中心是本浏览器目录，不能据此推定跨设备云端全量历史。

## 学科、模型与图示

`templates.cjs`、`curriculum-boundaries.cjs` 为云端学科规则；要求符合四川高考课程边界与题型，允许原创情境，不局限教材原题，不要求大学或竞赛知识。3–12题、5–90分钟及五档难度由共用契约校验。不同学科分别限制材料、公式、实验、单位、语言、史料、地图和评分依据。

`document-format.cjs` 提供一次JSON编码的字段示例与数据表规则，尤其约束化学公式转义；该模块只参与前置提示，不改写模型原稿。实验数据表使用Markdown表头、分隔行和等列数据，数学矩阵必须完整包在公式环境内。旧失败和题组读取时从私有诊断产生固定中文原因，不外传原始解析片段。详见[连续失败排查](../docs/GENERATION-FORMAT-2026-10-19.md)。

`providers.json`、`model-profiles.json`、`model-adapter.cjs` 管理已授权的服务目录和协议；工作台分别选择题文、图示与校检模型及思考档位。目录数量和可用性会变化，配置存在不代表余额或实测通过。新任务冻结提供方、模型、适配、凭据引用和时限；旧任务不随工作台切换变化，也不自动换服务。

猎豹词元工厂使用独立提供方`cheetah-gemini`、`gemini-3.8-flash`及Chat Completions流式协议。`CHEETAH_GEMINI_API_KEY`仅注入Worker，HTTP函数只声明提供方已配置。私有部署目录需有`cheetah-gemini.key`供后续维护复用；不能借用GLM或旧ByteCat密钥。详情见[线路接入记录](../docs/CHEETAH-GEMINI-2026-10-19.md)。

`figure-pipeline.cjs`、`figure-generation.cjs` 管理题图分离，`*-guidance.cjs` 组织各类图示指导。浏览器/后端共享 `exercise-*.mjs` 结构，模型只提供受限数据，不执行任意代码。复杂插图沿用已冻结的服务协议：ByteCat/旧猎豹使用 `gpt-image-2` 聊天包装，猎豹 Image 2 原生入口和 Image 2.5 各使用独立凭据与 Images 包装；图片来源和大小受限，结果进入私有任务及本机备份。SVG优先/允许复杂插图/无图示策略均保留，非必要图示不是必选。

## 认证、存储与限额

TOTP独立Base32种子，SHA1、30秒步长，当前服务允许窗口起点起100秒内验证；同一码只用一次，验证尝试限流使用不可覆盖COS对象跨实例共享。会话有效期七天，HTTP函数只持TOTP种子和会话签名；上游密钥只注入Worker。执行角色读写专属桶前缀，不共享北辰存储权限。

任务前缀保留14天，控制前缀保留模型版本、测试和额度设置，不随试题生命周期清理。本机已下载的完整练习继续保存到用户明确清理或更换资料；定期备份。

应用每日上限可在工作台调节，0为不限，初始环境默认30；清零只切换今日计数时期，保留旧任务。模型连接测试是独立额度，默认每日20。服务、上游输出预算和云函数时限仍存在，不能用应用额度0保证任何题量永不超时。HTTP函数时限60秒，事件函数900秒，适配按模型实际设置执行；题组/图示拆分减少单次调用压力。结构或完整性失败保留原稿和私有诊断。完整格式错误允许模型依据错误局部修复，修正稿须通过相同校验；程序不改写原稿伪造成功。断流与未知完成状态不自动重发。详见[成稿校检与修复](../docs/FORMAT-REPAIR-2026-10-19.md)。

npm run package:training

## 检查和故障处理

`npm test` 覆盖匿名边界、原ID重放、通知去重、并发额度、模型协议、流式响应、输出截断、题图流水线及诊断脱敏。生成最终正确性由教师审阅，格式校验不是答案正确的证明。实际调用和历史专题测试的范围见[文档索引](../docs/README.md)，本次正式验收见[发布校检](../docs/PRODUCTION-RELEASE-2026-10-17.md)。

错误先区分模型认证/余额/限速、传输中断、输出预算/完整性、图示失败和本机存储。查看原任务、工作台诊断和私有日志；先查询原任务，必要时明确继续或新建，不自动换模型、不清空私有存储、不重新生成TOTP来处理普通故障。
